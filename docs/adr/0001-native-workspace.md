# ADR 0001 — 原生 UI 与可独立测试的领域层

状态：接受。日期：2026-10-02。

使用 gpui-kit 0.7 facade，避免混入旧 gpui 0.2 类型。应用 UI、业务模型与本地存储、会话传输、AI provider 分为四个 crate。UI 通过消息与后端协调，阻塞的 PTY、文件与网络操作不得占用渲染线程。

应用层管理状态；模型和传输不依赖 GPUI，因此可在无桌面的集成测试里验证。协议状态必须有真实结果，不能由计时器制造成功。资源句柄有显式关闭与清理；会话关闭不会误关其它标签。

Reef 与 reef-template 用作工程参考；是否引入其运行时依赖由实际依赖与生命周期审查决定。桌面主线程事件循环不等同于后台服务入口，不照搬 HTTP server 启动器。

所有直接 registry 依赖使用 x.y，Cargo.lock 提交完整精确解析结果；第三方自身的精确传递依赖保持原样。Rust 工具链精确锁定已安装的安全补丁 1.98.1，最新稳定 1.99 的升级在后续独立验证后执行。
