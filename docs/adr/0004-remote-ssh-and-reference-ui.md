# ADR 0004：远程 SSH 范围、紧凑工作区与 DBX AI 交互

状态：接受。日期：2026-10-03。优先级：用户后续明确要求，覆盖早期本地终端与自由视觉设计。

## 决定

删除产品本地 PTY 后端和入口；终端只能由已建立的远程 SSH transport 构造。启动为空会话；新建标签打开连接管理器；分屏只能为远程连接打开新 channel。增加架构与 UI 回归防止退回本地 shell。

采用紧凑灰白界面、左侧监控、中央终端、下方文件区与独立连接管理器。历史匿名研究观察过本机参考应用的首页、管理器、新建 SSH 表单，以及公开历史会话截图；这里只保留通用操作观察，公开产品定位采用 KeelShell 自身目标。无障碍导航未成功的终端/代理/隧道页不计入已观察证据；不连接用户服务器补齐研究。详见[工作区观察摘记](../research/remote-workspace-reference.md)。

语言作为用户设置，默认 zh-CN、支持 en。静态文案必须同时提供两种语言；异步状态存储双语 Message，渲染时选取当前语言。用户输入、路径、服务器输出和技术错误详情不翻译。切换语言刷新控件 placeholder，不销毁实体或会话。

AI 使用 DBX 的独立配置目录及按会话绑定上下文思路；详见 [参考记录](../research/dbx-ai-reference.md)。供应商配置元数据与凭据分离，多协议模型定义不能被当成已实现 transport。

## 后果

保留历史提交与测试证据，但当前文档明确标注旧范围。控制器和视图拆分为 workspace.rs、workspace/view.rs、workspace/modals.rs；远程生命周期与持久保存仍由控制器管理。功能齐备与跨平台原生验收继续独立追踪，不能以布局改造或编译通过替代。
