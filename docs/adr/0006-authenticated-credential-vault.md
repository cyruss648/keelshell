# ADR 0006 — 完整认证的本地凭据库

日期：2026-10-03。状态：已采用；本记录描述核心文件格式与存储边界。

## 背景

SSH 配置需要可选地保存密码或私钥口令，同时保持连接元数据可导入、导出和共享。只给每条密文分别认证，无法在解锁时证明空凭据库的密码正确，也无法发现整个条目被删除或重排。独立进程同时保存还可能覆盖对方的更新。

## 决定

- `vault.json` 与 `state.json` 分离。配置只保存不透明引用，导入、导出连接时移除本地引用。主密码从临时输入提供，不写入磁盘。
- 使用 schema 2。每条凭据使用随机 24 字节 nonce 的 XChaCha20-Poly1305，加密的关联数据包含独立用途标记、引用、连接 UUID 和认证角色。已有引用不能通过 `set` 更换所属连接或角色。
- 完整 manifest 包含 schema、固定 KDF 参数及盐、所有加密条目和它们的顺序。用独立用途标记与新的随机 nonce 对规范序列化的完整 manifest 认证。空 manifest 同样需要正确密码。JSON 的空白和对象字段顺序不参与语义认证，条目数组顺序参与。
- `unlock` 验证完整认证标签后才返回可修改的对象。错误密码、条目插入、删除、替换或重排不能形成已解锁状态。此前没有完整认证的 schema 1 直接拒绝，不自动转换或覆盖。
- Argon2id 使用固定 64 MiB、3 轮、1 lane 和 16 字节随机盐。先校验参数和输入限制，再执行 KDF；不接受文件任意指定内存或计算成本。主密码最多 4096 字节，单个秘密最多 1 MiB，条目数最多 10000，完整输出最多 4 MiB。
- 每次 `set` 用无分配的 JSON 字节计数器检查总文件预算。超限的插入和替换会恢复原状态，避免积累无法保存的大量条目或在序列化时产生无界分配。
- 密钥、Argon2 工作内存、AEAD 原地缓冲区与返回的明文字符串使用零化所有权。密码学库启用 `zeroize`。UTF-8 校验借用缓冲区，错误不拥有未保护的明文副本。调用方仍负责保护它提供的主密码和秘密输入。
- `VaultStore` 记录成功认证的磁盘字节和不落盘的快照 token。保存时在持久锁文件保护下核对磁盘字节和 token；已有文件未成功读取、其他进程已更新、同一 store 的旧快照或另一个 store 的快照都会拒绝覆盖。成功替换后推进 token，传入对象获得新 token。
- 锁文件和数据文件必须为普通文件。Unix 要求 0600，新目录为 0700；保存先同步临时文件、原子替换，再同步目录。错误解锁会撤销该 store 之前的保存基线。目录同步失败代表替换已经完成，但断电持久性未得到确认。

## 边界

这不是 OS Keychain、Secure Enclave 或防回滚服务。解锁后的进程内存、调用方输入、系统交换区及崩溃转储不由此格式完整防护。完整恢复一份过去合法的 vault 文件无法在进程重启后被识别为回滚。

文件锁只协调遵循同一协议的进程。配置目录必须可信；不宣称抵御同用户恶意进程并发替换路径组件。Windows 继承用户配置目录 ACL，没有额外实现 ACL 审计。核心测试不代表三平台桌面验收或独立密码学审计。
