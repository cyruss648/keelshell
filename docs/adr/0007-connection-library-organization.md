# ADR 0007: 持久化连接目录、回收站与最近连接

- 状态：已实现 core 领域层；界面接入与原生验收单独记录。
- 日期：2026-10-03

## 目标与状态结构

连接组织属于 `keelshell-core`，不依赖 GPUI 或 SSH 传输。`Connection` 的既有字段继续兼容，`AppState` 增加四个持久化集合：

| 字段 | 内容 |
| --- | --- |
| `folders` | 带 UUID、名称及可选父 UUID 的目录树 |
| `connection_folders` | 连接 UUID → 目录 UUID；活动连接与回收站共用；无映射代表根目录 |
| `deleted_connections` | 原始连接元数据和 Unix 秒删除时间 |
| `recent_connections` | 连接 UUID 和 Unix 秒成功时间；最新成功调用在前，最多 50 条 |

目录与连接 UUID 属于独立身份空间。目录重命名、移动均保留目录 UUID。成员映射是权威关系，`Connection.group` 保留给旧配置与搜索使用；移动连接或更改目录树时，同步相关活动及已删除连接的可读路径。移到根目录会清空 `group`。

`update_folder` 将目录名称与父目录作为同一个编辑验证最终结果，避免合法的移动兼改名被临时的同级重名或旧路径长度误拒绝。`rename_folder` 与 `move_folder` 复用相同事务语义。

所有修改只作用于内存快照，调用方继续通过 `StateStore` 的版本与磁盘字节冲突检查持久化。目录变更先在候选树上验证，导入先在完整候选快照上验证；失败不留下部分修改。

## 旧配置迁移

现有 schema 1 采用附加字段演进，未知版本仍拒绝。反序列化时，只有缺少 `folders` 的旧状态才按非空 `group` 迁移目录：每个完全相同的标签成为一个根目录。旧标签包含 `/` 时仍作为一个完整名称保留，不猜测用户原来的层次意图；新树依靠 UUID 与父关系区分真实层次。

迁移不改变连接的名称、UUID、认证方式、私钥路径、标签、收藏或凭据引用。每组取其最小连接 UUID 作为目录 UUID，使相同旧文件重复读取时也得到同一目录身份。目录和连接的身份空间独立，因此这不会合并连接或改变凭据绑定。保存后显式写入目录树，不再根据旧标签推断成员关系。

`folders: []` 明确保留空树，`folders: null` 拒绝。缺少目录树却附带成员、回收站或最近记录的文档不视为旧配置，拒绝不完整迁移。目录树限 10,000 个目录、32 层，完整路径限 120 个字符以兼容原 `group` 约束；同父目录名称按大小写精确比较且不允许重复。缺失父目录、自指和祖先循环均拒绝。

## 删除、恢复与最近记录

软删除将同一连接移动到回收站，保留原 UUID、认证元数据、凭据引用、收藏、标签和目录映射，同时移除其最近成功记录。恢复保留原身份与目录；如果活动列表已有同 UUID 或相同规范化主机、端口、账户，则拒绝恢复且不覆盖任何条目。主机比较统一域名大小写、末尾点和等价 IP 表示。

删除目录仅允许删除真正空的目录：子目录、活动成员或回收站成员均会阻止删除。要删除含已删除成员的目录，先恢复并移动该连接，或者显式永久删除其回收站元数据。永久删除 API 不擦除独立加密凭据库，避免一个元数据动作悄悄改变凭据存储。

最近记录只接受活动连接 UUID，调用方必须在 SSH 认证及会话建立成功后调用 `record_successful_connection`。尝试连接、创建、复制和恢复均不产生最近记录；同一连接再次成功则置顶、更新时间并去重。顺序按观察到的成功调用确定，系统时钟回拨不会破坏置顶语义。列表最多 50 条，不将尝试或失败伪装成成功。

## 导入与导出

导出包含活动连接、完整目录树（包括空目录）与活动成员映射；排除回收站、最近历史、已信任主机、设置、命令片段和本机凭据库引用。认证方式与私钥文件路径是用户明确导出的元数据，继续保留。文档不包含密码、私钥内容或加密库秘密，但仍包含主机、账户及路径信息。

导入兼容旧的仅 `connections`/`group` 格式。新目录按父目录与名称合并或分配新本地 UUID，新连接分配新本地 UUID并清空凭据库引用。对活动与已删除连接的 UUID/端点去重；重新导入不会覆盖现有连接或自动恢复已删除连接。重复导入同一目录树不会复制空目录。导入整体受 4 MiB 限制，活动和回收站合计最多 10,000 个连接；任何成员引用、目录树或连接校验失败都不改变目标状态。

## 验证与边界

领域测试覆盖旧数据迁移、真实磁盘保存/恢复、目录循环与上限、软删除与恢复冲突、有界最近记录以及目录树导入导出。该层不能证明 SSH 实际成功：成功事件来源及异步保存的顺序由应用层负责。目录 UI、键盘交互和跨平台原生验收不是领域测试的证明范围。
