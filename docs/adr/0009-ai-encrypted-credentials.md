# ADR 0009 — AI 密钥的显式加密保存与解锁

状态：采用。日期：2026-10-03。

## 决策

AI API Key 默认仅驻留本次进程的内存。用户在 AI 配置页点击“加密保存密钥”，输入并确认凭据库主密码后，才将密钥写入 SSH 使用的同一 `vault.json`。配置元数据只存 `AiSecretRef::SecretStore` 的不透明 UUID；主密码不进入配置、日志或长期状态。

加密 payload 绑定配置 UUID、完整请求地址、API 风格和 Bearer 认证方式。名称与模型 ID 可以修改而保留关联。改变地址、预设或认证方式会清除草稿密钥及关联；直接修改密钥会解除旧的加密引用，避免重启后解锁回旧值。读取密文时再次验证绑定，不能仅凭改动元数据引用将其他服务的密钥带到新地址。凭据角色 `AiApiKey` 与 SSH 密码、私钥口令隔离。

每次保存新建密文条目，不覆盖旧条目。保存成功只更新设置草稿中的引用，用户仍需点击“应用”完成配置保存。关闭、取消或编辑设置后，已经获准开始的密文写入可能完成并留下孤立条目；它不会自动写入配置或发起网络请求。解除关联保留密文，由凭据维护页清理。凭据文件与配置文件的保存不构成跨文件事务。

## 生命周期与交互

重启后的引用处于锁定状态，用户每次显式输入主密码解锁。解锁结果仅加入本次进程的密钥表；“应用”后助手才使用该结果。清除临时密钥、解除关联同样先作用于草稿，并以文案说明应用后对助手生效。取消设置保留已应用的配置与助手状态。

主密码字段独立于配置编辑字段，不参与配置 revision、序列化或调试输出。开始操作时立即清空输入框；KDF 与文件读写在 Tokio blocking pool 运行，结果通过 `runtime_bridge` 的有界 mailbox 回到 GPUI。关闭或编辑通过取消标记及 prompt UUID、配置 revision、完整配置快照三重检查阻止旧结果回填。KDF 运行中不能被强行中断；取消检查阻止尚未获准的写入。后台凭据工作期间禁用“应用”，且不允许发现模型或测试连接。

发现、测试及助手的预览/发送始终是用户独立动作。支持带 vault 引用的 Bearer 元数据并不解析凭据；没有明确解锁的内存密钥时，请求仍被阻止。环境变量、自定义头、其他 API 风格以及尚未接入的高级参数仍明确拒绝，不静默忽略。

## 验证与边界

专项测试覆盖目的地绑定、名称/模型可变性、真实文件保存与重启解锁、错误主密码、无明文落盘、新 UUID 保存、不接纳已取消操作、设置页真实异步保存/解锁、旧结果隔离、端点改动后输入事件不恢复旧密钥，以及未解锁引用不能生成助手请求预览。

这是本地凭据持久化机制，不是系统凭据存储、设备间密钥同步或模型服务可用性保证。程序使用可清零的密码和密钥容器，并主动清空输入；不声称第三方 UI 文本控件的所有历史分配均可被零化。真实模型服务、平台原生 UI 和三平台 CI 需以对应测试记录为准。
