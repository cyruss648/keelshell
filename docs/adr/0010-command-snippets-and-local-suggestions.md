# 0010 — 命令片段与本地建议

日期：2026-10-03。状态：已实施，集成验收结果按测试记录维护。

## 用户流程

命令工具区可以在尚未连接服务器时打开。用户可以新建、编辑、删除片段，按名称、正文、说明或标签搜索。片段保存稳定 UUID、名称、说明、标签与命令原文，允许多行和 Tab。新建始终为空，不自动复制命令栏或历史。编辑器明确提示本机明文存储；敏感内容不应保存为片段。

选择历史或片段只将命令填入多行命令栏。用户核对完整正文及目标后点击执行。命令栏候选支持上下选择、Enter 填入、Escape 收起；IME 组合输入保留给输入组件，Shift+Enter 可继续编辑多行。片段编辑或删除不追溯修改已填入的正文。

## 数据与并发

沿用已有 `AppState.snippets` 与磁盘格式。领域 API 使用候选快照，完整校验后才替换内存状态，更新不隐式新增，缺失或重复身份拒绝操作。保存沿用 `StateStore` 的 revision、锁和原子替换机制。片段编辑草稿独立于工作区，保存开始立即冻结输入；失败恢复原草稿，保存成功才关闭编辑器。删除需要二次确认。

历史继续按 SSH terminal EntityId 保存在进程内，最多 200 条。片段和历史互不自动转换；保存设置不会持久化历史或未执行的命令草稿。

## 建议与目标绑定

本地建议来自当前会话历史和显式保存的片段，最多 8 项。前缀优先于包含匹配，同级历史按最近使用排序，再按片段保存顺序；精确相同的命令去重。来源显示为历史或片段。该功能不向服务器查询命令、文件名或 shell 状态。

搜索在后台执行，每个工作区最多一个任务。输入变化合并为下一次最新请求。结果发布前验证目标 EntityId、输入 revision、原始输入和来源 generation；目标关闭或变化后丢弃迟到结果。界面重绘复用缓存，上下选择会将选中项滚动至可见范围。

点击候选再次验证目标、输入原文与 revision、来源身份和命令快照。存在已绑定命令时，切换会话不会将其悄悄重新绑定。程序填入通过统一入口更新 revision；不能依赖输入组件的 `set_value` 发出 Change，因为该 API 明确不发出此事件。

## 组件与限制

单行输入组件会删除换行，因此命令栏使用多行 Textarea，保留命令原字节并提供滚动审核空间。片段编辑器与领域、后台匹配、工作区保存和视图分别独立。中文为默认界面，英文切换只翻译界面消息，不改用户正文。

本决策初版只覆盖字面片段与本地建议。后续 [ADR 0015](0015-remote-command-completion.md) 接入显式远端 PATH/字面路径补全，[ADR 0016](0016-parameterized-snippets-and-batch-exec.md) 接入显式模板变量和独立审核的批量 exec；实际验证见各自记录。历史加密持久化、片段同步、交互 shell 可编程补全和完整批量编排仍待实现。
