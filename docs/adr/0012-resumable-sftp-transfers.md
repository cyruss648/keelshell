# ADR 0012：可暂停且经过内容校验的 SFTP 续传

- 日期：2026-10-03
- 状态：已实现；验证范围见[集成记录](../testing/records/2026-10-03-sftp-resume.md)
- 范围：单文件和目录上传、下载；同一任务暂停与继续；重新连接后的显式续传

## 问题

传输中断会留下部分文件。仅按目标大小追加，会把同名的不同文件拼在一起；仅比较修改时间，也不能证明已有内容属于当前源文件。暂停按钮若只改变界面状态，而后台仍有未确认的写请求，会产生“已暂停但文件仍增长”的误导。

现有普通上传保留用户审核后的替换语义，普通下载保留不覆盖已有本地目标的语义。续传作为独立操作，不能将普通上传失败自动转换成无条件追加。

## 决策

### 区分暂停与重新续传

暂停属于当前传输任务。任务继续持有原 SSH 连接、源、目标和已确认的传输位置。界面先显示“正在暂停”，后端在请求完成和分块边界确认停止后，才显示“已暂停”。继续操作只作用于这个任务，不重新读取当前选中路径或活动会话。

取消优先于暂停和继续，暂停等待必须可被取消唤醒。暂停不会消耗活动传输的总时间预算；已经发出的网络请求仍受请求截止时间约束。暂停保留当前 FIFO 队列位置，后续任务不会越过它。未来增加并行调度时，必须重新定义这一行为。

重新连接或重启后的续传需要重新选择源和部分目标，并重新建立计划。旧计划绑定原 SSH 连接，不能直接交给另一个连接执行。本次不持久化正在运行的任务或私有文件内容。

### 检查、审核、执行

1. **只读检查。** 扫描源内容，记录 SHA-256 摘要和可用元数据；逐字节核对目标的完整已有前缀。拒绝目标大于源、内容不一致、类型不明、符号链接及无法确定长度的目标。
2. **用户审核。** 展示完整源、目标、总量和已验证的部分内容。校验字节不能显示成新传输字节。内容检查可能需要读取完整源文件，并非瞬时操作。
3. **执行前复核。** 同一 SSH 连接重新检查计划，拒绝来源、目标或目录集合改变的计划；通过检查后才创建缺失项或写入剩余内容。
4. **完成或中止。** 按已确认的字节报告结果。续传不截断已有匹配前缀，也不自动删除部分文件。出现失败或取消时保留可检查的结果，下一次显式续传重新检查。

文件计划内容由传输层生成，界面不能构造任意偏移来绕过核对。一个目标即使与源等长，也必须核对全部内容才能报告已完成。

### 目录恢复

目录续传要求目标根目录已经存在，检查整棵源树、已有目标树以及每个已存在文件的内容。目标允许是源树的部分子集；缺失文件和空目录在确认后创建。额外目标条目、文件与目录类型冲突、危险路径、符号链接或任一文件前缀不符，都必须在任何创建或追加之前拒绝。

目录限制为 32 层、10,000 项、16 GiB；计划扫描最多 30 秒，执行最多 15 分钟活动时间。文件续传同样限制 16 GiB、30 秒计划检查和 15 分钟活动时间。既有文件通过同一单文件续传机制处理，不能为目录恢复另开一个只按大小追加的路径。全部计划检查通过不代表后续多文件操作是一个事务；执行中途失败仍可能留下部分进展。

显式续传从暂停恢复时，重新检查命名路径、完整源摘要和目标当前前缀，重开文件句柄并核对，避免重命名后继续写旧 inode。目录预检和最终完整树校验必须处于稳定的恢复代次；中途暂停恢复会重做校验。普通传输的暂停和继续保持原有复制语义，不附带显式续传的完整摘要保证。

### 请求与资源所有权

传输通过带偏移的 SFTP 请求处理有界数据块，写入计数以服务端响应为依据，不能把高层缓冲写入完成当成远端确认。任务持有请求和通道的清理责任；等待 UI 接收事件时，也不能让取消永久阻塞。

文件面板只传递审核后的不可变任务及暂停、继续、取消意图。工作线程返回明确的状态确认，界面负责双语状态、进度与目标展示。切换语言或 SSH 标签不改变原任务目的地。

## 边界

- SFTP v3 没有通用的远端文件版本锁、比较并交换或 `NOFOLLOW` 打开语义。路径检查与句柄元数据可以发现已知替换，但不能保证对恶意并发重命名具有原子快照或事务语义。
- 内容校验和执行中的变化检测可以拒绝观察到的不一致；外部程序持续修改同一源或目标时，不应承诺获得一致快照。
- 取消不能撤销已经送达的远端写入。确认暂停表示当前任务不再继续发起数据写入，不表示阻止其他程序修改文件。
- 完成表示已观察到 SFTP 成功响应和关闭结果，不等于远端断电后的持久性保证。
- 本轮的手动续传不等于任务列表自动恢复、自动重连或后台自动重试。这些需求仍在完整路线中。

## 验收要求

- 真实 TCP SSH/SFTP：上传和下载暂停确认后无后续写入，继续后最终内容一致；暂停时取消可结束；队列顺序和关闭仍有界。
- 单文件：空前缀、完整匹配、部分匹配、目标更长、前缀冲突、源或目标在审核后改变、符号链接与错误类型；失败不修改待续传的目标。
- 目录：部分目录和空目录恢复、完整文件跳过、缺失项补齐；额外文件、后面的文件冲突及审核后树变化必须在前置检查中拒绝，不能先修改前面的目标。
- 界面：确认前不写入，暂停请求与确认状态分离，取消和迟到消息不恢复任务，切换语言与会话保持目标，窄文件面板仍可操作。
- 原生 macOS 使用隔离文件和受控延迟演练；单独使用 OpenSSH 服务端核验互操作。CI 编译和协议测试不能替代 Windows/Linux 桌面验收。
