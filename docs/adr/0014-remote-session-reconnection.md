# ADR 0014：远程会话重连与旧任务隔离

- 状态：采用；验收进度见 [专项记录](../testing/records/2026-10-03-reconnection.md)。
- 范围：已认证远程 SSH 标签的手动重连与可选自动重连，不包含远程进程恢复、自动重放命令或传输。

## 问题与协议依据

SSH 连接中可同时存在多个 shell、SFTP 和转发通道。正常 shell 退出不能被当作断网；单独关闭一个分屏也不能关闭其他分屏使用的连接。按照 [RFC 4254 §5.3、§6.10](https://www.rfc-editor.org/rfc/rfc4254.html#section-6.10)，EOF 是单向结束，通道关闭与进程退出状态分别表达不同信息；退出状态并非必传。[RFC 4253 §11.1](https://www.rfc-editor.org/rfc/rfc4253.html#section-11.1) 定义了连接级断开及原因码。因此重连资格不得从界面错误文案或单个 EOF 推导。

## 生命周期与输出

传输层公开 `ConnectionState` / `ConnectionEnd`，shell 独立公开 `ShellEnd` 的 watch 订阅。已观察到的退出码、信号或明确通道关闭优先于后续连接丢失；本地主动关闭、远端显式断开、协议异常和未知原因均不触发自动重连。自动策略仅接受传输丢失与保活超时。监听者退出有兜底终态，不把远端任意错误描述作为用户可信提示。

界面状态为 Starting、Ready、Ended。PTY 和 shell 请求确认后即可 Ready，不依赖欢迎文本；结束状态通过独立 watch 发布，不受界面输出队列背压阻塞。清理失败另行显示，不能改变已知退出分类。输出仍以原有逐帧预算消费，在旧 worker 完成、已接收数据排空后才移交历史，避免快速重连截断尾输出。

## 策略、身份与认证

每个保存的连接默认 `Manual`，仅显式选择后保存 `Automatic`。自动参数：最多 1–10 次，首次延迟 1–60 秒，最大延迟不小于首次延迟且不超过 300 秒；指数退避封顶。预算按完整路线计算，重连内部不再叠加首次连接重试。连续短暂连接共享预算，Ready 稳定 30 秒才重置；手动操作开启新的有限系列。应用重启不会自行发起连接。

标签记录原配置 UUID、完整规范化路线、有序各跳 UUID/认证方式/跳板引用、信任指纹快照。每次尝试与异步回调均重新解析活动配置并核验。改目的地、删除/回收、修改路线或信任、取消与关标签都会撤销旧系列；恢复同一 UUID 不会复活已取消的定时器。重连偏好不属于信任或凭据身份，单独改策略不清除凭据或最近记录。

每次从第一跳重新建立专属路线，包括各跳上游代理。原密码与代理密码不作为重连缓存。需要密码、主密码或服务器身份核对时，后台流程停在可见提示，用户点击“继续认证”后才打开弹窗；不抢占正在编辑的其他界面。指纹变化仍阻止连接，不能绕过审核。

## 同一标签、全新操作权限

保留标签位置、顺序、标题和分屏位置，新连接创建新的 `TerminalView` EntityId。这个新身份也是命令审阅和 AI 上下文的会话边界。旧命令草稿原文保留且继续绑定旧 ID，只有明确“用于当前会话”再审核后才能手动执行；历史迁移不会执行历史内容。

终端移交有界主屏滚动历史；若断线时处于备用屏，另保留最后屏幕的可见文本快照。新 ANSI 解析器、模式、游标模板、事件通道和输入队列均重建，不继承旧的半个转义序列、粘贴/鼠标模式或待发送自动回复。备用屏快照过滤控制字符且尊重隐藏文本。历史仍受用户设置的行数上限约束，可能按原规则淘汰最早行。

助手取消属于旧会话的请求并撤销已审核 payload、响应目标和建议，保留问题草稿；其他会话上下文不受影响。迟到模型响应以 revision 隔离。

## 文件、监控与隧道

旧面板进入会话快照：保留文件编辑草稿、已显示列表、监控数据和任务记录，停止新远端操作，取消旧传输与监听器，释放面板自身持有的 SSH 引用。传输请求取消后等待队列终态与清理，不把“请求取消”显示为“已取消”；已发文件写入保留成功回执或明确未知结果，不自动重放，已发 SIGTERM 继续等待有界结果。迟到文件读取/续传计划或进程身份查询不得覆盖草稿或重新出现确认框。新面板使用新 SSH 连接，不继承旧审核计划、暂停令牌或隧道规则。

每个标签最多保留一个上一会话面板快照。再次重连将替换该快照；其中存在未保存草稿时需明确确认，同意绑定快照面板及草稿原文，完成时再次核验，期间新编辑不能被旧同意丢弃。归档中的本地草稿仍可编辑和复制，远端修改能力已撤销。文件恢复需在新连接重新扫描、审核和确认。

## 边界

自动重连不是远程进程恢复。保活检测依赖 SSH 协议和传输实际进展，不能承诺所有背压或操作系统故障均在固定墙钟时间判定。断线时已发出的命令/写入结果可能未知，应用不自行重试。受控回环协议与 macOS 原生验证不代表生产网络、所有 SSH 服务端或 Windows/Linux 桌面体验已验收。
