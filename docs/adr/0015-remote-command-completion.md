# ADR 0015 — 远端命令与路径补全

日期：2026-10-03。状态：接受；实现和验证状态以对应[验收记录](../testing/records/2026-10-03-remote-completion.md)为准。

## 用户任务

用户在多行命令栏编辑命令时，可以显式查询当前 SSH 服务器的命令名或文件路径，在光标处填入一个候选，再审核整条命令及目标后执行。历史和片段继续提供整条命令建议。终端中的 Tab 仍交给远端交互 shell。

## 目录与环境的含义

SSH 的 shell、exec、subsystem 是各自通道上的程序请求；协议不提供读取另一交互 shell 内部 cwd 或 PATH 的接口。[RFC 4254 §6.5](https://www.rfc-editor.org/rfc/rfc4254.html#section-6.5)

命令候选使用独立 exec 环境的 PATH。路径候选使用界面明确显示的补全目录，允许手动输入、显式取用文件面板目录或读取 SFTP 起始目录。SFTP `REALPATH(".")` 不是交互终端 cwd，也不一定是 HOME。相对路径按该补全目录查询，选入时使用服务器解析后的绝对路径，避免用户在终端执行 `cd` 后指向另一个文件。客户端不解析终端提示符，不修改远端启动文件。

## 分层

- `keelshell-core` 负责有界的 shell 词法分析、UTF-8 光标映射、查询意图和局部替换。它没有网络和命令执行能力。
- `keelshell-session` 接收字面的名称前缀或绝对目录，仅执行一条固定 PATH 探针和只读 SFTP 查询。用户命令草稿不传给该接口。
- `keelshell-app` 管理显式触发、目录、候选列表、取消和会话身份，使用 Textarea 的范围替换保留撤销历史。

历史/片段建议替换整栏；远端候选只替换当前词。界面分别显示两种来源和操作范围。

## 不执行输入的查询

固定探针的格式和正文都是常量；结果使用固定标记和 NUL 分隔，要求完整 framing 与退出码 0。任何前缀、路径或用户草稿都不进入 exec 命令，也不作为 stdin 传入。PATH 目录用 SFTP 枚举，按大小写敏感的名称前缀筛选，保留 PATH 的优先顺序。命令候选来自普通文件的执行权限位和有界的符号链接目标检查，不代表 ACL、挂载策略或解释器已验证可以执行。

SFTP 候选只使用 `filename` 与 `attrs`，不解析服务器自定义的 `longname`。READDIR 返回单个目录成员名，REALPATH 返回绝对路径；handle 是不解释的协议数据。[SFTP v3 草案 §6.7、§7](https://www.ietf.org/archive/id/draft-ietf-secsh-filexfer-02.txt)

查询拥有独立的 exec/SFTP 通道以及覆盖打开、初始化、读取和属性检查的绝对截止时间。正常取消关闭查询通道；未确认 OPEN 或异常关闭超时仍遵守已有通道所有权契约，可能有界关闭共享 SSH。不能把入队 CLOSE 描述为服务器已确认清理。

## 编辑与失效

解析器处理简单命令列表、多行、管道、布尔操作符、前置赋值、常见重定向、单/双引号和反斜杠。查询可发生在命令位置或任意参数位置。光标位于词中间时保留已输入的组件后缀和后续路径；被替换范围之外的字节保持原样。

候选是字面数据，统一进行 POSIX shell 引用。插入路径由 canonical 父目录、原样成员名和保留的后续路径组成；成员本身仍可能是符号链接，不会重新解析整个路径，也不保证执行时目标仍存在。路径中的空格、引号、分号或命令替换外观不能变成新的 shell 语法。复杂展开、here-doc、尚未支持的复合语法、非法 UTF-8 字节位置和非折叠选区返回明确的不支持状态；不为获得补全结果而求值输入。

请求与结果绑定终端 EntityId、命令 revision、完整文本、光标/选区、目录版本和请求 token。编辑、仅移动光标、IME 组合开始、切换目标、断线重连、打开冲突弹窗或取消均撤销旧结果。启动查询、返回结果、插入候选时分别复核。Enter 只填入，执行仍是独立操作。

## 范围与后续

本实现提供独立 PATH 与 SFTP 字面路径补全。交互 shell 的 alias、function、动态 PATH、可编程参数补全和变量展开不由这条查询路径推断；需要这些能力时仍可使用终端自身的 Tab。命令探针要求兼容 POSIX 的远端环境；客户端运行平台与远端 shell 兼容性是两个不同维度。

底层 SFTP 字符串解码会有损替换非 UTF-8 数据，因此候选保守排除 U+FFFD、控制、方向控制、BOM 及部分零宽字符，避免插入与原文件字节不同或难以审阅的路径。这也排除原本合法包含 U+FFFD 或 U+200D（ZWJ，例如部分 emoji）的名称。候选数、扫描条目、路径和名称字节、额外属性请求及时间均有上限；截断和跳过信息必须可见。实际限额与测试证据在验收记录中维护。
