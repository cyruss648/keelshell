# ADR 0016 — 参数化片段与 SSH 批量命令审核

日期：2026-10-03。状态：接受；实现与实际验证状态见[验收记录](../testing/records/2026-10-03-parameterized-snippets-batch-exec.md)。本决策扩展 [ADR 0010](0010-command-snippets-and-local-suggestions.md) 的片段工作流，不改变远端补全或交互终端的输入语义。

## 用户任务与分层

用户可以在明确启用变量的片段中使用 `{{name}}`，填写本次值、审核完整命令，再填入已有命令栏。填入不执行，命令栏仍要求审核目标并明确点击执行。

批量任务是另一条显式流程：从当前已认证的 SSH 会话中选择目标，编辑共同命令、并发数、超时及失败策略，审核所有目标和完整正文，再确认执行。每个目标使用独立 SSH exec 通道，不向其交互终端注入键盘字节。终端当前目录、alias/function、临时环境和已输入内容不构成 exec 环境；需要特定目录或环境时应在审核命令中明确写出。

`keelshell-core` 负责无 I/O 的模板编译、校验和渲染；`keelshell-session` 负责持有已认证连接的有界批量调度及执行回执；`keelshell-app` 负责不可变审核快照、可取消交互、目标复核和结果展示。AI 不参与这两条流程，也不能调用确认操作。

## 显式模板与字面值

`Snippet.parameterized` 默认 `false`，旧文件缺少该字段时保持原意。即使旧正文中包含 `{{name}}`，也不会自动解析。保存模板正文和开关，不保存本次参数值；严格配置模型拒绝参数值等额外字段。

启用后，变量名采用 `[A-Za-z_][A-Za-z0-9_]*`，最多 64 个 ASCII 字节、32 个不同名称，按第一次出现的顺序显示。模板源和渲染结果分别最多 65,536 个 UTF-8 字节；单个参数值最多 4,096 字节。键必须与模板变量精确一致，重复变量复用同一个值；空值合法但必须显式提供，UI 将尚未填写与“使用空值”分开。Unicode、换行和 Tab 原样保留，其他控制字符拒绝。

变量只允许占据未引用的完整词，或 `NAME=` / `--long-option=` 后的完整值。例如：

```sh
printf '%s\n' {{path}}
OUTPUT={{path}} command --label={{label}}
```

每个参数按 POSIX 单引号字面值渲染，内部单引号使用相邻引用与转义连接；替换范围之外的模板字节保持原样。引号或注释内的变量、词片段拼接、复杂展开、here-doc、复合语法和动态文件描述符不受支持，返回带源位置的明确错误。反斜杠换行按 POSIX 词边界判断，渲染仍保留原始模板字节。

引用防止参数在插入位置引入新的 shell 语法，但不是执行沙箱。`eval`、`sh -c`、应用自己的脚本参数和以 `-` 开头的选项仍有其命令语义；完整命令必须由用户审核。这里没有将明文参数变成秘密输入或凭据管理工具。

## 参数审核与历史

编辑器提供变量开关、语法说明、推导变量列表和即时反馈。参数弹窗持有完整片段快照和原目标说明，固定底部操作区，正文可滚动；语言切换只翻译控件，不改值。预览可选择复制但不可编辑，确认时重新读取当前字段并重新渲染，避免输入事件尚未处理时使用旧预览。发出确认事件前冻结字段；工作区拒绝旧授权后保留全部填写值。

工作区在填入时同时核对当前弹窗、完整片段快照、目标终端 EntityId、命令 revision 和原命令正文。片段被编辑或删除、命令被修改、目标切换或重连产生新实体时，旧审核不能向新目标填入。渲染不发网络请求，也不执行命令。

参数化命令填入后默认关闭本次命令的会话历史记录，界面提供显式开关。普通命令保持现有按会话隔离的内存历史；批量任务不自动写入交互终端历史。片段、命令栏和批量结果的明文可在当前进程中供审核，不能因此承诺远端 shell、执行程序或操作系统不会记录命令。

## 批量审核与会话身份

新任务不默认选择目标；最多选择 32 个在线会话，每行显示名称、端点和路线。并发数为 1–8，单目标超时为 1–300 秒。应用默认并发 2、超时 30 秒、失败后停止尚未开始的任务。审核阶段冻结命令与设置，返回修改会使旧审核失效。

确认前再次比较审核 token、完整命令、设置和选中目标；工作区复核终端 EntityId、已认证连接存活状态和端点。任务只持有当时选中的 `SshSession`，后续切换标签不会重定向执行。目标实体结束、关闭或被重连替换时，原目标失效并请求停止对应批次；不会把旧任务转交新连接，也不会自动登录、重连、重试或重放。

一次批次内的 UUID 必须唯一。同一个 SSH 连接可以有多个用户显式选中的逻辑目标，它们各自打开通道并分别返回结果；不会按连接句柄擅自合并用户选择。

## 调度、结果与取消

每个已接纳目标拥有独立 exec 通道，不申请 PTY，提交命令后结束 stdin。单目标截止时间覆盖打开通道、exec 请求和收集输出，排队时间不计入。`Started` 仅表示占用并发槽位，不能证明服务器已接受命令。

应用为每个目标设置 stdout 与 stderr 合计 1 MiB 上限，最多 32 个目标；后端总捕获预算最多 32 MiB，命令、协议缓冲和元数据另计。事件队列可容纳所有最多 64 次状态变化，不依赖 UI 持续消费才能完成。界面收到终局回执后显示各输出流前 64 KiB，转义控制与易混淆字符，并标明预览截断；最终事件须排空后才能释放 handle。

回执区分：已收到退出码且通道结束、明确拒绝 exec、确认未提交 exec、结果未知。只有完整退出码 0 算成功。exec 可能已提交后的取消、超时、断线、缺少退出状态、输出超限、远端信号和矛盾协议都不能归为成功；已收集的有界部分输出保留。

失败后停止策略只停止尚未接纳的目标，已开始的目标继续收集各自结果。显式取消会停止等待项并取消进行项；隐藏面板继续执行，返回可查看；新建任务不覆盖仍运行的批次。结果仅留在本次工作区，没有持久化审计库或自动重试。

正常清理仅关闭该独立通道。尚未确认 OPEN 的清理可能等待本行剩余截止时间，最高 300 秒；异常 CLOSE 先受既有约 2 秒预算限制，必要时有界关闭共享 SSH，另有约 2 秒的底层停止预算。该异常回退可能影响共享连接上的其他通道。取消或关闭本地通道不证明远端进程被终止，也不提供远端回滚。

## 未包含的能力

本轮不是跨主机事务或完整运维编排器。任务依赖图、分阶段批次、逐目标参数映射、定时运行、持久化审计/恢复、离线主机自动认证、确认远端进程终止、历史加密持久化和片段同步仍待设计。非 POSIX 远端 shell 不享有上述模板引用保证，实际兼容性需单独验证。
