# ADR 0021：应用内项目与更新面板

日期：2026-10-03。状态：接受。

KeelShell 在主工具栏提供“关于/更新”入口。面板显示当前版本、项目主页、仓库发布说明和当前平台目标；网络请求只在用户点击检查或下载后后台执行，不读取 SSH 凭据、终端内容或远端文件。

检查请求只接受固定项目的 HTTPS GitHub Releases API，并用严格的版本和平台资产匹配选择安装包。下载先读取同一发布的 `.sha256` 文件，再流式限制大小并在本地计算 SHA-256；校验失败不会留下可用安装包。校验后的包放入私有临时目录。用户可以查看它，或显式点击“自动安装并重启”。安装前会再次读取归档内的 `package-manifest.json`，校验版本、目标平台、每个清单文件的路径与 SHA-256；独立助手只替换清单文件，失败时按反向顺序恢复备份。

自动安装只对标准打包布局生效：macOS 识别 `KeelShell.app`，Linux 识别 `usr/bin/keelshell-app`，Windows 识别当前可执行文件所在目录。助手通过同一版本的隐藏命令行入口启动，等待文件占用消失后执行有界重试；无法确认安装根目录、清单篡改、路径穿越、符号链接或权限失败时会失败关闭并保留原安装。签名、公证、系统权限和各平台真实安装验收仍是发布门禁，不会被本地 helper 的成功替换误报为已完成。
