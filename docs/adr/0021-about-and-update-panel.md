# ADR 0021：应用内项目与更新面板

日期：2026-10-03。状态：接受。

KeelShell 在主工具栏提供“关于/更新”入口。面板显示当前版本、项目主页、仓库发布说明和当前平台目标；网络请求只在用户点击检查或下载后后台执行，不读取 SSH 凭据、终端内容或远端文件。

检查请求只接受固定项目的 HTTPS GitHub Releases API，并用严格的版本和平台资产匹配选择安装包。下载先读取同一发布的 `.sha256` 文件，再流式限制大小并在本地计算 SHA-256；校验失败不会留下可用安装包。校验后的包放入私有临时目录，用户可以查看它并自行完成安装。

自动替换现有安装目录暂不启用。跨平台原生替换需要处理 macOS 签名/公证、Linux 安装权限和 Windows 文件占用与回滚；在这些目标完成真实发布验收前，应用不会覆盖正在运行的程序。面板会明确显示这个边界，避免把下载成功误报为安装成功。
