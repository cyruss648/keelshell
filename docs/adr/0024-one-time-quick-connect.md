# ADR 0024：一次性 SSH 快速连接

## 状态

已接受（2026-10-04）。

## 背景

空工作区需要能够直接打开一个远程 SSH 会话。只把入口显示成静态标签会让首次连接必须先创建持久化配置，也无法满足临时排障或访问一次性主机的场景。

## 决策

- 空工作区显示主机、端口、用户名和可选私钥路径，并允许在 SSH Agent/私钥与密码认证之间切换。
- “连接”构造一次性的内存 `Connection`，通过与已保存配置相同的路线、认证、主机密钥核验和终端创建流程。
- 一次性配置不写入连接库，也不自动写入最近连接。凭据继续只在登录流程中短暂存在；用户明确点击“保存为连接”后才打开持久化编辑器。
- 主机指纹只有在用户显式确认后才写入受信任主机状态。一次性连接仍使用相同的作用域校验，主机密钥变化继续拒绝连接。
- 快速连接只支持单跳直连。跳板、代理、重连策略和标签等高级配置仍通过持久化连接编辑器配置，以避免在临时表单中隐藏安全语义。

## 影响

`ConnectionRoute::direct` 为不依赖 `AppState` 的直连路线生成规范化身份；工作区用不可变的临时路线快照复用认证和主机密钥流程。测试必须证明快速连接不产生连接库写入，并证明保存按钮只是打开编辑器而不是隐式保存。

## 未覆盖范围

一次性连接不会自动恢复会话、保存凭据或创建最近记录。Windows/Linux 原生窗口仍需要平台验收；本决策不改变更新器、AI 或传输层范围。
