# ADR 0025：批量摘要审计与远程文件差异预览

状态：已接受（2026-10-04）

## 背景

批量命令已经要求逐目标审核，但完成后只留在当前工作区；重启后无法回答“这次审核执行了多少目标、结果如何”。远程文件编辑器也只能看到当前文本，用户无法在保存前快速确认相对于读取基线的改动。

## 决策

- 批量执行结束时写入有界的 `BatchAuditRecord`。记录只包含完成时间、命令 SHA-256、可获得的已保存配置 ID、目标数量、结果计数以及取消/停止等待项标记。命令正文、输出、主机地址和凭据永不写入状态文件。
- 记录通过 `AppState` 的候选副本和完整校验后再入队保存；最多保留 500 条，模态窗口关闭时也会刷盘，避免没有后续设置变更时只停留在内存。
- 文件差异使用核心层的有界 UTF-8 行算法，输入每侧最多 4 MiB/4096 行，输出最多 16 MiB；应用界面再将可见预览限制为 128 KiB。比较只使用远程读取基线和当前编辑草稿，不执行路径、命令或网络请求，也不自动应用补丁。
- 保存仍沿用现有的“审核并保存”确认和远程内容冲突检查。差异预览是辅助审阅，不改变授权边界。

## 结果

这个设计给批量运行提供了可恢复的最小审计线索，也让文件修改在提交前可读。低熵命令的 SHA-256 可能被已知候选猜测，因此摘要不是保密日志；若未来需要不可猜测的关联标识，应另行设计密钥化摘要。目录比较、补丁应用、并行传输和完整操作日志仍不在本次范围。
