# ADR 0027：审核式批量命令逐目标元数据展开

状态：已接受（2026-10-04）

## 背景

批量任务此前只能把同一段命令复制到所有已认证 SSH 会话。目标名称、主机、端口和远程用户已经存在于连接路线，但无法在每个目标的审核结果中安全使用。把完整 shell 表达式交给客户端求值会绕过审核边界，也会让环境变量、凭据或远端状态意外进入命令。

## 决策

- 批量命令可选择使用 `{{name}}`、`{{host}}`、`{{port}}`、`{{user}}` 和 `{{endpoint}}` 五个元数据标记。
- 标记由核心层的有界字面模板解析器处理；未知标记、引号内标记、超限输入和不支持的 shell 上下文在进入审核前拒绝。
- 每个目标在“下一步：审核”阶段生成自己的最终命令，并在审核面板逐目标展示。确认时，工作区依据不可变的 `Review.commands` 为每个已认证 `BatchTarget` 绑定命令；命令、会话身份和目标选择任何变化都会使审核失效。
- 模板值只来自本地连接元数据，不包含凭据、环境变量、终端 cwd、远端输出或网络查询。一次性连接缺少配置字段时使用保守的可见端点上下文。
- 展开只用于本次审核和执行，不写入命令历史、片段或持久审计正文。批量任务不自动执行、不自动重连、不自动重试。

## 结果

逐目标参数映射覆盖了常见的主机差异命令，同时保留命令审核和会话绑定的授权边界。自定义用户参数、依赖图、调度和逐目标持久化输出仍需独立设计；这些功能不能通过增加模板变量绕过当前限制。
