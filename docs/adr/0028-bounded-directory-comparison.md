# ADR 0028：有界目录快照比较

日期：2026-10-04

## 背景

文件面板已经能浏览远程目录，也能在审核后上传或下载目录。只看根目录列表不足以支持同步前的审阅；直接在界面线程递归扫描本地目录又会阻塞交互，并可能把大型或恶意树带入无界内存和 CPU 消耗。

## 决策

- `keelshell-session` 增加 `SftpSession::snapshot_tree_limited`。它在认证 SSH 会话上递归读取 SFTP 元数据，固定最多 32 层，调用方提供条目上限；超过深度或条目上限直接失败，不返回看似完整的部分结果。符号链接不会继续遍历。
- `keelshell-app` 增加只供后台 worker 调用的本地 snapshot adapter。它使用 `symlink_metadata`，将本地文件名转换为 UTF-8 相对路径，并以相同的深度和条目上限拒绝不完整快照；GPUI 渲染线程不执行目录遍历。
- `keelshell-core` 增加纯数据的 `compare_directories`。调用方负责在后台 worker 收集本地快照和远程快照，再将相对路径和有限元数据传入核心层；核心层不访问文件系统、不执行 shell、不发起网络请求。
- 比较按 `/` 规范化的相对路径排序，输出 `Same`、`LeftOnly`、`RightOnly`、`Changed` 和 `Uncertain`。类型、已知大小或已知修改时间冲突属于 `Changed`；字段缺失时只能给出 `Uncertain`，不能默认为相等。
- 比较结果是只读审阅数据。当前切片不自动复制、删除、覆盖或应用差异；任何同步动作必须另行生成审核计划，并在执行前重新扫描和复核路径、类型、内容摘要及目标会话。

## 边界

快照使用 SFTP 元数据，不等同于内容哈希，也无法证明并发远端改名或写入不存在。目录扫描仍需要应用层后台 worker；Windows/Linux 原生目录选择器和可视化比较面板尚未在本切片中接入。没有通过完整快照的树不得被显示成“已同步”。
