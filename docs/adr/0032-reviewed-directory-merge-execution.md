# ADR 0032：审核式双向目录合并

日期：2026-10-04

## 决策

文件面板在元数据比较后提供“校验本地 → 远端”和“校验远端 → 本地”。专属文件 worker 从两侧读取常规文件内容，用核心 SHA-256 摘要构建不可变计划。两侧已有文件只按内容和大小判断一致，目录只比较存在与类型，不传播修改时间。当前合并保留目标侧独有项；核心层的删除策略不通过此执行器开放。

点击“审核同步”会显示根路径、方向、全部操作相对路径、限制和部分结果提示；只有确认栏的确认按钮才启动写入。计划绑定原 SSH 会话和 canonical 根，导航/本地路径草稿不会重定向计划，挂起会清除待确认操作。执行前重新读取完整两侧目录并核对根、报告、计划与审阅指纹；每个操作还再次检查源与目标的类型、大小、摘要。

## 读写与资源

- 单侧最多 10000 项、32 层；单文件 64 MiB；两侧内容总计 256 MiB；完整审核路径正文最多 128 KiB。超过任意边界直接拒绝，不把截断快照当作完整目录。
- 只允许真实目录与类型明确的常规文件。静态符号链接、特殊对象、类型冲突、跨平台危险名称、仅字母大小写不同的路径拒绝。Windows drive/device/stream 和 COM/LPT 上标数字保留名也拒绝。
- SFTP 内容读取使用父链 `lstat` 和同一已打开 handle 的 `fstat` 前后核对，读到 EOF 后复核大小与命名目标；错误及取消由已有通道所有权清理。SFTP 上传使用已存在的同目录临时文件与 `posix-rename@openssh.com`，缺少扩展拒绝；写后读回摘要。
- 本地下载使用同目录独占临时文件，缺失目标使用 `persist_noclobber`，已有常规文件经再次校验后原子替换。复制现有本地权限；新文件沿用临时文件的私有默认权限。写后读回摘要。目录按路径顺序建立，目标独有项保留。
- worker 与 GPUI 隔离；取消在读取/操作边界检查。内容扫描异步预算为 30 秒，执行异步预算为 15 分钟。同步 filesystem 调用不能被 Tokio timeout 抢占，挂起网络盘不具有硬墙时限。

## 保证边界

整个目录不是一个事务。取消、网络失败、权限失败或进程退出可能保留已经完成的文件/目录；不会自动回放或递归删除结果。按清单执行的逐文件原子替换保证可见性，不保证掉电后的持久性。

本地 stat/open/rename 和 SFTP v3 lstat/open/rename 之间无法排除所有外部并发替换。检查证明规划和复核时观察到的对象，不能声称锁住了整棵树或提供远程 compare-and-swap/no-follow。Unicode 规范化与具体文件系统名称规则仍需目标平台原生验收。当前不提供镜像删除、并行同步、后台定时同步、元数据/ACL/所有权同步、冲突合并或差异应用。

验证见[目录合并记录](../testing/records/2026-10-04-directory-sync-execution.md)，纯领域计划见 [ADR 0031](0031-directory-content-hash-sync-plan.md)。
