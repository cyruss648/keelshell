# 0040 — 命名本地智能体配置与审核式问答

- 日期：2026-10-04
- 范围：core 配置、app 设置/凭据/助手；依赖 ADR0038 的后台 CLI 进程
- 状态：实现、本机整仓门禁、新独立审查和 macOS 受控原生问答/取消通过；新增提交 CI 与其余平台原生另行验证

## 配置与旧数据

每个 `NamedAiProfile` 明确持有 `AiBackend`：模型 API，或固定 Codex CLI / Claude Code 协议及绝对可执行文件路径。旧元数据缺字段默认 API，加载不探测文件、不启动进程、不改写原文件。未知 backend、额外 argv/秘密字段、相对路径、控制字符与 Windows batch 启动器拒绝。路径元数据可在 Unix/Windows 间保存，执行准入仍要求本机原生可执行文件。

模型 API 保留完整请求地址的校验；CLI 存推理基础地址，允许 HTTPS 或显式回环 HTTP origin。CLI 要求自身固定协议和认证；不支持的 Token/自定义头/代理/推理选项在调用前拒绝，不能降级为 HTTP 或静默丢弃。用户显式切换调用方式会清除旧密钥/引用、模型与不适用的 API 控制，并清楚展示这一行为；更换文件路径或地址也撤销旧凭据绑定。

设置里独立提供“检查 CLI”。检测只启动版本、help、有效能力探针，不发送模型请求；临时名字/模型仅服务检测，不能写回存储或成为推理审核。检测不是后续调用的准入缓存：每次发送仍由后端重新核对。配置构造与请求准备只做内存/词法校验，所有进程、文件与凭据 I/O 留在后台。

## 凭据与生命周期

首个 CLI Ask 适配器使用显式 API 密钥，不复用现有订阅登录。密钥默认本次进程内存；显式保存走现有认证加密 vault。新加密 payload v2 绑定 profile UUID、端点、协议、认证与精确 backend/可执行路径。旧 v1 ciphertext 仅由原 API adapter 解锁，不能被新 CLI 配置复用。模型/名称变更不改变目标绑定；CLI 类型/路径、地址与认证变更必须重新填写或保存。

同步编辑时先清除内存密钥和引用，再异步清除 UI field；随后到达的姓名/模型 Change 不能重新插回旧目标密钥。保存使用不可变 catalog/credential snapshot 与 revision；保存期间的新编辑仍留在草稿。取消检测、修改配置与关闭面板使用取消信号；后台 worker 继续等待 typed 进程清理，不因丢弃 GPUI observer 而放弃 owned future。

## 问题审核与 UI

助手明确分发到 API 或本地 Ask，失败不回退。两者共用显式 `ContextDraft`、全部临时凭据脱敏、SSH context identity 和命令建议审核。CLI 预览展示执行文件、服务、模型、输出/时间界限、隔离/工具策略与准确 stdin；准备不启动 CLI。只有“确认发送此请求”消耗唯一审核并启动后台进程，返回完整回答后仍只能把命令提案送入现有人工审阅区。

问题、上下文、profile、凭据或可执行路径变化撤销预览、旧请求及迟到回复。语言切换保留问题与准确 payload。设置正文和助手正文都保持自然内容高度，外层提供滚动视口；较长 JSON 不得挤压按钮或让底部发送动作不可达。配置选择器按明确 backend 校验，CLI 配置不经过 HTTP 可用性判定。

## 验证边界

原失败与修复后 GPUI/core/vault 回归、独立审查、本机两种安装版 CLI 到自有 SSE 服务的完整窗口操作，分别记录于 [测试记录](../testing/records/2026-10-04-local-agent-ui.md)。受控服务不证明云端模型、计费、订阅登录、任意版本或生产 SSH；Windows/Linux 图形窗口与供应商 CLI 必须各自 native 验收。Ask 不是完整 Agent 工具编排，也不是本地终端管理；对外 MCP 服务仍是独立入口。
