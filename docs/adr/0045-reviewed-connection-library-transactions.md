# ADR 0045：显式选区的连接库事务与永久回收清理

- 日期：2026-10-05
- 状态：实现与本机相关门禁通过；独立复审、整合后的原生验收待完成
- 关联：[连接组织](0007-connection-library-organization.md)、[测试记录](../testing/records/2026-10-05-connection-library-bulk.md)

## 决策

连接库每行提供具备完整连接名称与端点的选择按钮。活动连接与回收站使用独立选区；在两者之间切换清空选区。活动连接的搜索、收藏、最近和目录筛选保留明确选中的 ID，审核始终列出全部选中对象，包括当前筛选之外的连接。保存成功后从选区中移除已完成的对象，单项恢复/删除也清理已不属于当前集合的 ID。

批量操作提供目录移动、添加/移除/替换标签、设为收藏/取消收藏与软删除。标签替换可显式清空标签，其余模式保留无关标签。回收站提供单项、选中与清空全部三种永久清理入口，所有永久清理均经过“编辑/查看对象 → 审阅 → 确认永久删除”。批量恢复与上一批软删除的撤销入口同样创建新的审核，继续使用原 ID、目录及凭据引用；撤销记录仅在内存中保存，重启后仍可在回收站恢复。

`ConnectionLibraryAction` 及 `apply_connection_library_batch` 属于 `keelshell-core`。域操作先验证完整状态与精确、非空、无重复的 ID 集合，在克隆候选中变更并校验最终状态，最后才替换调用方内存。UI 仅一次调用现有 `StateStore::save` 的后台保存通道，保留 revision、合作文件锁、候选快照及原子文件替换。标签超限、目标目录缺失、路由恢复冲突、依赖或任何校验失败都不产生部分对象变更。

对跳板图按照整个选区检查。软删除时，选区外的活动依赖阻止整批操作；已删除连接仍保留原 ID，所以回收站内依赖可以继续引用已回收的跳板。永久清理时，选区外的活动或回收站依赖均阻止整批操作。整条已选链可按任意选择顺序软删除、恢复和永久清理。恢复同时检查新恢复的完整规范路线，不拒绝无关的既有重复路线。

## 审核与会话边界

审核逐条展示名称、端点、ID、原目录/标签/收藏、新目录/标签/收藏、跳板及凭据引用。活动会话按已捕获路线的每一跳关联，既包含目标自身，也包含通过所选跳板连接的目标；审核列出相关会话路线。确认复核连接库、目录、最近成功记录、两套信任记录、精确选区与活动会话身份，变化会保留草稿并要求重新审核。语言/主题保存不会覆盖新的设置或将过期 revision 复制到旧候选；确认重新基于当前状态构造候选，外部写入仍由存储层拒绝。

所有操作仅改变本机配置。当前 SSH 会话保持打开，不发送 SSH 命令、关闭通道或删除服务器文件。软删除保存成功后，既有保存通道取消受影响路线的后续自动重连；保存失败、取消或域依赖拒绝不提前停止重连。没有自动恢复、自动重新连接或自动重放动作。

组织、软删除和恢复保留凭据引用。永久清理只移除被清理配置所携带的引用与目录成员关系；加密凭据条目、其他配置的共享引用、传统与路由信任记录全部保留。跨配置文件的 vault/trust 清理不属于此事务，用户仍可在凭据管理中另行查看和确认维护。流程不读取或保存密码、主密码及其他秘密。

## 展示与验收

使用现有语义 palette 与固定页脚、可滚动正文的 `framed_modal`，目录/标签草稿、取消、返回修改与双语渲染保持可操作。GPUI 布局、受控 SSH 协议夹具和原生二进制构建分别记录，不能作为真实客户主机、Windows/Linux 原生窗口或最终发布包的验收证明。
