# ADR 0048：命名本地 Ask 配置的时限与输出预算

- 状态：已实现，等待整合后的独立复核与原生验收
- 日期：2026-10-05
- 范围：Codex CLI 与 Claude Code 的单次 Ask；HTTP 模型 API 不变

## 问题

本地智能体执行器已有总时限、回答字节、累计输出、单行及事件数量上界，但命名配置只能使用内部默认值。用户需要按服务响应速度和回答大小调整单次 Ask，且保存、审核、实际执行与取消必须使用同一组值。字段编辑错误不能悄悄恢复默认或把最后一次有效值当成当前草稿保存。

## 决策

在 `AiBackend::LocalAgent` 增加非敏感 `limits`，使用 `AiLocalAgentLimits` 严格类型。公开字段是整数秒和 KiB（1024 字节），不是模型 Token。

| 字段 | 默认 | 有效范围 | 作用 |
| --- | --- | --- | --- |
| `timeout_seconds` | 120 | 1–300 | Ask 的本地总等待时限，包括新版本与能力检查 |
| `answer_kib` | 1024 | 1–1024 | 完整回答的 UTF-8 字节上界 |
| `output_kib` | 2048 | 1–8192 | 推理进程 stdout 与 stderr 的累计字节上界，包括协议开销 |

回答预算不得大于累计输出预算。累计输出还要容纳协议开销；相等不保证该大小的回答可成功。未知字段、非整数、字符串数字、负数、零、溢出及越界在反序列化时拒绝。旧本地 metadata 没有 `limits`，或该对象缺少某个字段时，精确保留旧默认；显式 `null` 拒绝。API 后端不接受该字段，不渲染本地预算输入，也不把预算放入 HTTP 请求。应用 schema 与依赖版本不变，读取配置不重写文件。

UI 在本地配置表单使用“等待时限（秒）”“回答上限（KiB）”“累计输出上限（KiB）”。三个字段必填，非数字和范围错误保留在每个配置的草稿中。切换配置、语言、保存失败及保存途中继续编辑均保留草稿；任一隐藏本地草稿无效也会阻止整套配置应用。无效当前草稿还会阻止 CLI 检查、密钥保存与解锁。安全的清除/解除密钥动作仍允许。

有效值映射到 `LocalAgentLimits::for_ask`。固定事件上界仍为 512；JSONL 单行上界仍为 256 KiB，累计输出更小时同步缩小单行上界。探针输出保留原来每个进程 64 KiB 的独立限制，手动“检查 CLI”保留独立 10 秒限制，不计为 Ask 的累计输出。应用内不提供帧数、行大小、任意参数、用户 hooks、工具、环境继承或第三方 MCP 配置编辑。

完整发送审核继续展示实际时限、回答和输出字节以及固定隔离政策，捕获的 `PreparedLocalAsk` 包含不可变执行配置。预算变化参与完整配置相等比较，撤销旧审核、取消旧请求并推进请求来源 revision；迟到完成不能发布回复。运行时仍使用原有进程组 / Job Object 的取消、超时和有界清理，不允许把截断回答呈现为成功结果。

加密密钥仍使用 v2 密文。凭据身份比较只排除不能改变密钥接收方的预算；API / CLI 类型、具体 CLI 适配器、精确可执行路径、profile ID、地址、协议和认证绑定保持。旧 v2 后端缺预算默认可读取，修改预算不要求重新保存密钥；修改适配器或可执行文件仍拒绝原密文。请求审批禁止使用这个较窄的凭据身份比较。

## 验证与剩余范围

核心测试覆盖严格类型、旧元数据默认、无重写读取、保存重载和 API 字段拒绝。GPUI 测试覆盖输入事件、无效草稿保留、精确 runtime 映射、审核撤销、旧结果拒绝、密钥绑定、API 表单隔离及最小窗口滚动。自托管原生进程夹具使用产品预算构造路径，覆盖 UTF-8 回答恰好达到 / 超过上限、累计 stderr 与协议超限、固定单行上限、配置超时、取消及自有后代清理。

测试与构建不是供应商 CLI、云服务或原生窗口验收；本轮不运行它们。工作目录、环境引用、订阅登录、Agent 工具编排及其他平台原生验收继续保留在正式计划，见[本地 Ask 指南](../product/LOCAL_AGENTS.md)与[测试记录](../testing/records/2026-10-05-local-agent-limits.md)。
