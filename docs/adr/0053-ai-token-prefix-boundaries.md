# ADR 0053 — AI 脱敏前缀的保守边界

日期：2026-10-06。状态：实现候选，独立复审与主树整合尚待。

## 问题

AI 输入与完整回复均经过脱敏。原规则在任意位置寻找固定 token 前缀，并在后方至少8个允许字符时移除整行。普通命令 `printf 'ask-progress-review-canary'` 内含 `sk-`，因此在真实原生窗口变成 `[REDACTED]`，无法审阅原建议。相同误报也会吞掉包含 `task-` 或 `mask-` 的普通诊断。

## 决定

固定前缀的启发式识别只排除左侧紧邻 ASCII 字母或数字的候选。前缀后的最少长度、字符集和七种前缀均不变；标点、引号、下划线、连字符、Unicode标签与emoji仍允许识别并移除整行。使用UTF-8匹配位置和前一个字符，不引入字节边界切片错误。

PEM、Bearer、凭据赋值及命令参数规则不变。已配置秘密的精确替换不增加位置限制，仍在启发式处理之后执行，并保持最长匹配优先和临时字符串清零。已知值即使嵌在普通单词内也必须隐藏。

未知 token 如果嵌在 ASCII 字母数字标识符内，不再凭该前缀启发式认定为秘密；这是检测范围，不是“已发现全部秘密”的保证。编码、混淆和未知格式仍可能超出启发式范围。使用时仍由用户显式选择上下文、查看完整请求并确认发送。

## 交互和权限

可读的回复只产生待审建议；必须人工点击才向原 SSH 会话发出建议事件，实际执行仍使用既有命令栏。修正不添加模型权限、工具执行、本地终端管理或其他 MCP 客户端。KeelShell对外MCP仍独立提供受授权远程能力。

## 验证

保留原失败的真实原生记录，以及修正前Rust定向11通过/3失败的回归。修正后验证普通命令、ASCII内嵌前缀、全部固定前缀/分隔符、7/8字符阈值、已知秘密内嵌、凭据赋值和既有私钥/Bearer行为。应用级GPUI回归需核对完整建议、无自动事件及人工点击后精确会话绑定。工程门禁、非作者复核和新版原生结果见[验收记录](../testing/records/2026-10-06-ai-redaction-boundaries.md)，不得用原窗口或合成匹配模型代替新实现验证。
