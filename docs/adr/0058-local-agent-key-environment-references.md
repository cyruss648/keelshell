# ADR0058：本地 Ask 的显式密钥环境引用

- 状态：初版非作者评审发现探针元数据准入 P2；v2 作者修复，等待新非作者复核与主线整合。
- 日期：2026-10-06。

## 决策

命名 Codex CLI / Claude Code 配置复用既有 `AiSecretRef::Environment` 与 ASCII 变量名称校验，不添加第二套凭据引用或 schema。旧配置仍默认手动临时密钥/显式加密库；加载配置不会读取环境，也不会重写旧 metadata。

本地入口有独立来源选择与变量名编辑器。只有用户点击“读取到临时密钥”，才读取 **KeelShell 应用进程** 的环境变量。值必须为非空 Unicode、至多 8192 UTF-8 字节且无控制字符。来源字段仅保存名称；值保持进程内 `Zeroizing` 数据，不显示、不入 metadata、预览、日志或 argv，不直接转交同名环境项给 CLI。GUI 从 Finder/桌面启动时不保证继承 shell 的环境。没有在启动、能力检查、预览或发送时自动读取的行为。

导入值绑定命名配置 ID、精确引用名、接收地址、协议和 CLI 类型/执行路径。固定 CLI 环境与临时空工作区保持；实际值仍只进入适配器原来的固定认证变量。预算与模型调整不改变密钥接收方，但完整配置修改仍撤销既有请求审核。改来源、变量、地址或执行路径，以及重新读取失败，都撤销当前发送值；旧引用名不自动获取新值。输入的无效引用完整保留，保存/启动校验拒绝它。

读取后的每个值（最多每配置 16 个不同导入值）保持为该配置的披露保护数据，包括无法绑定/metadata 校验失败的值。它们不能授权发送。删除配置释放这些数据；切换适配器、清空当前密钥或改引用不会让已观察秘密失去保护。Apply/持久化仍检查所有已配置及保留草稿秘密；本地审核另外拒绝执行路径、临时父目录、地址、模型或来源名中的已知秘密。导入后准备请求冻结当前绑定值，后续应用新值或改接收方撤销旧审核；准备/发送不重新解析环境，模型无法修改来源。

API 入口仍采用既有显式请求动作时的环境引用解析；此次只新增本地配置的编辑和显式导入行为。加密库与环境来源互斥；环境来源不能通过库按钮隐式转换成保存值。

## 探针调度前准入

初版保存和 Ask 已检查已知秘密，但手动 CLI 检查仍可把含已观察值的地址或执行路径交给能力探针。独立评审通过自有原生子进程实际 argv 证实该 P2；原失败、反例及输入证据保持。

v2 在同步编辑器后、建立配置与后台探针任务之前执行完整 `validate_catalog_secrets`。该函数从既有元数据校验中提取原秘密遍历，检查整个目录，包含结构尚无效的草稿、未选中的 API/本地配置、未选中模型、数值的存储/线协议表示、引用名与保留草稿秘密；已撤销的发送值仍作为披露保护。秘密元数据或集合超限以不含输入和值的通用反馈拒绝，创建的任务和子进程均为零。Apply/持久化继续先执行原目录结构校验，再调用同一秘密遍历。探针继续执行原选中 transport 校验，允许尚未选择模型的能力检查。

修复首版直接复用含结构校验的函数，完整门禁中旧空模型能力检查测试失败；原失败与源码保留，没有删改旧断言。提取共享秘密准入后恢复该流程，并补充结构无效的隐藏草稿及两 CLI 空模型合法探针测试。合法探针仍只检查版本与能力，不读取引用、不使用密钥、不请求模型。完整反例保持为正式 GPUI 测试；显式提供自有原生 fixture 的合法探针测试单独执行，普通测试不会运行供应商程序。

修复作者此前担任初版评审者，此阶段是作者实现和验证，不构成对自身修复的独立结论。主线准入需要新的非作者复核；见[修复记录](../testing/records/2026-10-06-local-agent-probe-admission.md)。

## 工作目录与其他环境项

继续使用每次创建的独立空临时目录。任意用户 cwd、任意环境转交、订阅/OAuth 与工具编排仍开放。现版本 Codex 的 `--ignore-user-config`、`--ignore-rules` 及 Claude 的 `--bare`、空 `--setting-sources`、禁 hooks/空 MCP 参数提供必要隔离控制，但帮助说明不证明所有既有目录、祖先配置、平台管理配置或供应商自动发现都被排除。将任意 cwd 交给两个适配器可能扩大未审核上下文与配置发现范围，需要另外设计受限工作区和原生证据。

参考[Codex CLI 官方命令说明](https://learn.chatgpt.com/docs/developer-commands?surface=cli)、[Claude Code CLI 说明](https://code.claude.com/docs/en/cli-reference)。本轮只读实际版本/help；它不是模型调用、文件访问隔离或原生桌面验收。

## 验证边界

使用隔离存储、GPUI 行为测试及自有 native mock-child 验证显式读取/失败/撤销、引用持久化、秘密保护、审核冻结与未转交任意环境项。版本/help 子过程有明确时限、wait/reap 和临时目录清理。测试不使用真实模型、供应商网络、SSH/客户机器或用户项目，不启动 GUI；其他平台原生与真实 CLI 新入口仍未验收。具体结果见[本轮记录](../testing/records/2026-10-06-local-agent-environment.md)。
