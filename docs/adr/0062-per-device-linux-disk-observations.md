# ADR0062：逐设备 Linux 磁盘 I/O 观测

- 状态：实现、新非作者评审、主工作区整合与完整组合门禁已通过；磁盘监控原生桌面与真实远程 Linux 连续采样验收待完成。
- 日期：2026-10-06。

## 采样与兼容

在已有认证 SSH 会话上执行同一段固定、只读、输出至多 2 MiB 的 Linux 资源脚本，额外读取可选的 `/proc/sys/kernel/random/boot_id` 与 `/proc/diskstats`。仍在登记的后台 worker 内等待网络 I/O；面板的暂停、取消、挂起与五秒轮询规则不变。非 Linux 保持既有明确能力错误，进程身份复核与单独确认的 SIGTERM 不变。没有远端安装、任意脚本、自动连接或新的 MCP schema/工具授权。

旧采样没有新增段落仍能解析 CPU、内存、网络和文件系统容量。新增段落缺失、读失败、非法启动标识、不支持布局或超过限额只让可选磁盘数据不可用。非法 UTF-8 或超过完整命令输出限额仍拒绝整个响应；UI 保持既有旧样本年龄和失败状态，不生成成功采样。

## 内核语义与预算

仅接受官方 11、15 或 17 个计数字段的完整布局，拒绝四字段旧分区形式和未知未来布局，不猜字段。扇区固定按 512 字节进行 checked 转换，时间字段是毫秒；in-flight 是可下降的当前量，其余字段必须累计不回退。读写次数是内核完成且可能已经合并的请求；平均耗时以对应完成请求数分母，为零时无均值。活动时间增量不是精确设备利用率。依据 [Linux I/O statistics](https://docs.kernel.org/admin-guide/iostats.html) 和 [block stat](https://docs.kernel.org/block/stat.html)。

可选数据至多 256 KiB、256 行设备，名字至多 128 字节 ASCII graphic；身份为精确 major/minor/name，major/minor 为 u32、计数为 u64 严格十进制，不允许符号、重复身份或重复名字。启动 UUID 必须是完整非空标准形式，不保留到磁盘。boot_id 在一次启动期间保持固定，见 [kernel sysctl](https://docs.kernel.org/admin-guide/sysctl/kernel.html)。

各 proc 文件与 uptime 依次读取，非原子快照；远端时间计算区间速率，不声称请求级精确时间线。差值需要前后 boot_id 与原 btime 一致、远端 uptime 有限且严格递增、相同设备身份与字段布局。回退/重置、乘法或速率溢出、新设备、设备消失、时间无效各有明确不可用原因；有效无 I/O 区间可以显示零。单行 major/minor/name 不是物理序列号，无法识别未观察到的同名重挂载/重新初始化后计数又超过旧值；不声称解决该内核可观测性限制。

## 展示与边界

设备/分区/逻辑设备逐行选择，显示精确 major:minor，选择只修改当前面板，不发命令。父盘、分区和堆叠设备不求和，不推断物理盘类型。保留选择身份；消失时展示身份和不可用状态，不能显示旧数值。只有有效差值才显示区间读写吞吐、完成请求次数和均值；当前 in-flight 单独标注。大或极小有限数字用有界科学计数或 IEC 单位，长名字缩略但完整选中身份可横向滚动。

中文/英文、System/Light/Dark 复用语义色与既有主题。不改变终端、工作区工具栏或进程确认；最小窗口使用外层资源滚动和有界内层设备选择，固定刷新/暂停与状态仍可达。原有 MCP 缓存读取继续只返回既有资源字段，磁盘不扩大服务端权限或暴露新增工具。

作者 GPUI 和 owned TCP/SSH 测试不等于原生桌面。自有离线只读 Linux 容器能证明固定采集脚本确实读取可见内核与解析器兼容，不能证明客户 SSH、物理主机或 Windows/Linux 桌面。当前证据和保留失败见[测试记录](../testing/records/2026-10-06-disk-io-monitoring.md)；功能说明见[指南](../product/DISK_IO_MONITORING.md)。
