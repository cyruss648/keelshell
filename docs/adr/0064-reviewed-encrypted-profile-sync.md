# ADR 0064：审核式端到端加密连接同步

- 状态：非作者源码复核与隔离完整门禁通过，等待根组合及原生验收
- 日期：2026-10-06

## 决策

SYNC-02 采用显式操作的双客户端同步，而非加密导出。用户选择支持协作跨设备锁和原子替换的共享/挂载目录，客户端读取同一认证加密快照，按完整记录展示差异，再逐项选择和批准。KeelShell 不创建云账户、自动连接 SSH 或接受远端动作指令。

core 管理 allow-list 记录、版本向量、墓碑、已见共享摘要、乐观审核绑定、pending publication 和加密 transport；GPUI 管理 masked 输入、分页差异、逐项选择与固定确认区，阻塞读取/KDF/写入在后台进行。同步凭据与派生密钥不进入状态。完整选择后的纯预览验证最终路线图，并列出每个受影响连接的完整前后路线。存在路线变化或本机位置保留映射时，需要额外的人工影响确认；改变选择撤销此前确认。

已有 vault 的固定 Argon2id 和 zeroizing XChaCha20-Poly1305 primitives 通过 crate-private envelope helper 复用，单独认证域防止与凭据库互换。

共享 generation/digest 以及每条记录的向量防止已关联设备接受旧快照、丢失墓碑、版本倒退或同版本改写。新客户端缺少外部锚点，无法证明首次接入之前的历史。用户显式解除本机关联必须二次确认这项损失。

本机与共享快照无法一次原子替换。先把已批准的本机变更与 pending 密文原子保存，再做共享 CAS，最后确认本地 ledger。失败时保留实际本地保存和待发布状态，不自动重试或报告已完成。继续操作重新认证同一候选；同密文已存在时幂等确认。共享变化可明确放弃未发布 receipt 后重新审核。

仅接受共享记录的现有向量，不增加虚假编辑以免两个客户端反复产生回声差异。新/变更完整路线的认证重置为本机 Agent 默认，包括因父跳板变化而受影响、未直接编辑的下游 profile；只撤销 metadata 引用，保留 OS/vault 条目。既有同一路线本地认证保留。活动 tabs/transports 与保存的 profile 变更分离。

本机文件夹派生 group 与共享 legacy group 是不同映射。差异明确显示保留位置及批准后本机显示；本机 folder placement 优先，wire 标签从已审核基线投影，首次本机 folder 路径不上传。device-local ledger 记录受本机树管理过的 profile IDs（旧 ledger 默认空），避免移到 root 或删除空 folder 后产生回声编辑。接收恢复保留回收记录的本机 membership；接收删除用本机批准时间。

## 代价和边界

- 没有云账户、网络挂载或后台文件复制实现。最终一致缓存目录不具备全局 CAS，不能作为已支持传输宣称。
- 文件夹树、认证方式和私钥路径保持本地。旧分组标签是可同步显示元数据，新接收 profile 放在本机根目录。
- 限额为 2,000 条记录、每记录 64 个设备版本、2 MiB 明文和 4 MiB envelope/应用状态；超限明确失败。
- 密码丢失不能解密共享密文；本机连接可通过明确解除关联、新目录、新密码重新建立空间。
- 测试必须覆盖两个独立 local store、共享密文、并发冲突、墓碑、认证后 replay/tamper、审核源变化和中断恢复；GPUI 测试不等同原生桌面或网络文件系统验收。
