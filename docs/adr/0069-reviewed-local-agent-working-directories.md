# ADR 0069 — 本地智能体的审核式工作目录

- 日期：2026-10-07
- 状态：作者候选；待新非作者复核和主树整合

## 背景

本地 Claude Code / Codex CLI 配置需要允许用户明确选择运行目录。旧配置继续使用每次新建的空隔离目录。这个入口属于后台 AI 问答，不提供本地终端管理，也不授权读取用户登录材料或自动继承项目工具。

## 决策

持久化元数据增加 `working_directory`：`isolated` 为缺省，`selected` 保存完整绝对路径。API 配置独立。设置提供两种模式、目录选择器、手工路径、后台检查和完整可滚动路径；切换配置、修改草稿、取消或关闭会使旧检查结果失效。目录模式和路径是已加载本地密钥的绑定条件之一。

发送前在后台重新验证目录，审核同时展示原始与规范路径以及实际 SSH 选区。路径不会自动变成模型上下文，但 CLI 生成的目录元数据可能随请求发给推理服务。所有目录组件拒绝符号链接，Unix 持有目录 inode，在单线程私有 bootstrap 中重新检查后用安全 `fchdir` 进入所审核目录；Windows 持有拒绝删除的目录句柄并拒绝 reparse/device/网络命名空间。目录变化会拒绝发送或丢弃候选答案。

Unix 所选 native 执行文件从持有的常规文件句柄复制到私有 `0700` 临时树。原文件与副本的完整字节摘要、身份和大小均重新绑定；版本、帮助和有效能力探测只运行即将执行的副本。Darwin Codex 的 app bundle 只复制三项有界公共签名元数据：`Info.plist`、`_CodeSignature/CodeResources`、`embedded.provisionprofile`，原 bundle 和副本均须通过固定 `/usr/bin/codesign --verify --strict`。不复制通用资源、脚本解释器、登录文件、助手程序或配置。任意恶意同用户进程不属于该进程封装的沙箱保证。

bootstrap 只接收固定标志和不超过 64 KiB 的严格控制帧，不接受任意 argv、环境映射、命令模板或工具权限。它在 GPUI / Tokio 初始化前进入，保留原有管道和进程组，拒绝未知字段、身份或摘要变化、无效版本和额外环境变量。

Claude Code 继续使用 bare 模式、空工具和显式空 MCP/设置来源；Codex 所选目录使用不可信项目层、禁用项目说明/技能发现、19 项有效禁用能力检查和无工具 Ask。项目 `.codex/config.toml` 需要有界、无符号链接的语法准入与重新检查，但不转交其中的配置或说明。检查配置不执行模型、hooks 或 MCP。

精确 Codex 版本在已完成运行和官方源码核对后逐项准入，不按整个 minor 猜测兼容性。所选目录的唯一 vendor 启动提示只允许 `thread.started` 后、`turn.started` 前出现一次：完整固定 disabled-host 提示、严格字段、无重复键、`item_0`。它只属于控制信息，不生成回答、不触发成功；其它错误、未知提示、重复或晚到帧保持拒绝。默认隔离流的规则保持。

## 验证与边界

有意义的测试覆盖老资料缺省、领域存储、秘密绑定、迟到选择器与后台检查、目录/元数据换位、保留已授权 inode、固定 bootstrap 帧篡改、未知版本、取消与清理。真实 installed CLI 的生产适配器使用自有 loopback SSE 服务，核对明确问题/SSH 片段、六种未授权项目内容、工具列表和项目 hooks/MCP canary；这不等于付费模型、订阅登录或三平台桌面验收。
