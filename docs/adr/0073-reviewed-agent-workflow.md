# ADR 0073 — 有界、逐轮审核的应用内 Agent

- 日期：2026-10-07
- 状态：epoch3经新非作者限定复核并导入主副本；组合工程门禁与macOS包检查通过，精确提交CI及新原生另见[整合记录](../testing/records/2026-10-07-reviewed-ai-mcp-main-integration.md)
- 范围：AI-AGENT-01，应用内 API／本地 CLI 共同工作流

## 决策

将 Ask 与 Agent 区分。Ask 保留现有单轮文本建议；Agent 使用真正的有限推理／提案／人工审批／实际结果／新上下文审核循环。模型每次返回严格 JSON，只能请求一个命令、一个完整常规文件读取、一个现有文件替换，或结束。协议不接受未知字段、重复字段、替代目标、多个动作、自动批准、畸形 JSON 或超限内容。`keelshell-ai` 的状态机只持有领域状态，不拥有网络或过程权限；后台远程执行及目标权威校验属于 app/session 层。

API 与本地 CLI 复用同一命名配置、脱敏预览、认证和取消生命周期。Agent 不需要供应商内置自动工具：CLI 仍调用已准入、已核对版本和工具关闭的单轮协议，由应用组合实际回合。此选择保留供应商工具能力边界，不用提示词宣称禁读或隔离。KeelShell 对外 MCP 服务端仍供外部智能体调用；本 ADR 不增加通用 MCP 客户端。

用户为每个回合批准完整目的地／请求；SSH 输出和文件读取不能自动进入下一次推理。用户为每个动作独立批准固定目标和完整内容。文件修改分为读取原文准备与最终写入批准，复用现有 SFTP 原文检查、共享 mutation 排他、原子发布及未知写隔离。模型不能变更目标、提升权限、读取凭据、解锁 vault、批准自己或释放冲突隔离。

捕获终端身份与实际 SSH 句柄，并持续复核当前路线和信任。UI 消费单次审批后才发起 I/O，派发前后都检查原连接；关闭、重连、替换连接、改变路线或信任都会停止并丢弃迟到结果。每个提案 120 秒有效、远程操作 30 秒总期限；默认 6 模型回合／4 操作，上限 12／8；累计完整历史 64 KiB，不删旧结果续跑。未知命令／写入结果终止，不自动重试或继承到新会话。

捕获目标的权威退休必须同步撤销后台取消令牌：生产 `close_tab` 删除页签／连接映射后、`finish_reconnect` 移除旧连接后，以及终端观察回调收到正常结束通知时，在当前前台回合维护 Agent。200 ms 巡检只作补充，不能承担唯一撤权责任。后台保留的 `SshSession` 克隆不构成继续写入授权。已派发操作仍保守记录未知；不因事后原文读回或迟到成功恢复旧任务。独立复核曾通过暂停预写 canonical 请求、关闭捕获页签、释放后台并完整读回证实旧候选可越过权威退休，故旧冻结候选被阻塞；修正与新冻结验收在记录中分开保留。

实际 SSH bridge 总是附带同一条 typed lifecycle watch；任务开始时捕获其只读 receiver，不能改绑新终端。后台原文准备和实际操作同时监听这条源，typed End 或 producer 关闭会取消后台；SFTP 每个写授权检查还直接读取这条源，必须仍为 Ready 且 producer 未关闭。因此在前台 Terminal.poll／观察回调尚未运行时，原始源已结束就拒绝新的写发布，不依赖200 ms巡检。终端状态和步骤 Unknown／TargetLost 的桌面显示仍由排队的前台回调更新；不能把后台即时拒权说成所有 UI 状态同一时刻完成。字节流旧受控夹具没有 typed source，仍由前台权威退休保护；真实生产 SSH 路径没有该缺省。

停止和用户失效动作也必须在同一前台回合撤销精确后台授权。Panel持有Workspace为同run创建的取消令牌；停止、两种上下文选择、实际上下文替换、问题编辑入口、模式、配置或凭据变化直接cancel，再发带run身份的排队清理通知。旧AgentStart准入前核对Panel仍在请求同run；旧Capture绑定previous_run，旧停止、执行、目标接受和动作结果不能替换或退休新run。domain已显示Unknown不代表后台已经撤权，独立epoch2反例证明仅排队AgentStop会让暂停写入在前台延迟时继续发布，故旧epoch2候选也被阻塞。

gpui-kit 0.7的Textarea Change订阅异步，set_value不发Change，通用validator不覆盖所有多行／空文本编辑。因此活跃run创建时当场把问题设为只读，仍支持选取和复制；固定操作区提供中英“编辑问题并停止”，先同步撤销旧token再解锁，用公开ScrollAnchor定位并聚焦问题。键盘、IME、删除和粘贴不能在旧授权仍存时修改草稿。终态后界面自动恢复编辑，内部问题setter先失效旧请求；旧排队Change若描述的当前文本已与新run捕获问题相同就忽略。不能把Kit异步订阅宣传成同步编辑回调。

## 后果与验收

完整步骤记录与模型文字分开，非零退出码、拒绝、已知准备失败、未知结果及模型结束都有各自语义。中英文入口共享语义 token；完整文本两轴滚动，停止、批准和拒绝固定在视口外侧。编辑问题／配置／上下文停止旧任务并要求重新审核。

供应商严格 JSON 能力不足时明确失败；不自动放宽解析或重试模型。完整模型结论并不成为远程事实。读取和替换限已有 canonical POSIX 常规 UTF-8 文件，32 KiB；不隐式增加新文件、远端 Windows 路径或无限工具。订阅登录、供应商原生工具审批协议与更广授权工具范围仍属于原计划余项，不用本循环关闭它们。

有界领域及实际 HTTP＋受控 GPUI＋TCP SSH/SFTP 测试需要验证真实回合、审批前无执行、结果发送前审核、拒绝、精确文件读回、单次审批、预算终止、停止、目标变化与迟到结果。编译、夹具、真实供应商 CLI 和各平台原生窗口分别记录；独立新非作者复核通过后才由根消费。详见[指南](../product/REVIEWED_AGENT.md)及[记录](../testing/records/2026-10-07-reviewed-agent-workflow.md)。
