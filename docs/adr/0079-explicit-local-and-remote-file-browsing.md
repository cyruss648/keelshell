# ADR 0079：显式本地与远程文件浏览

- 日期：2026-10-08
- 状态：主副本整合；v5 新非作者限定复核、根完整门禁及新 macOS 标准包通过，宽窗口 picker／浏览／审核式双向 SFTP 已实际验证；新的非作者组合源码／工程／宽窗口原生证据复核无 P1/P2；精确 CI／最小原生窗口／其它平台桌面开放
- 范围：SFTP 的本地源／目标选择和远程列表呈现；不增加本地终端

## 决策

本地栏初始为空。用户通过 GPUI 系统单目录 picker、绝对路径输入后按 Enter／刷新、
普通目录条目的打开按钮或上级按钮明确导航；后台仅枚举该目录的一层元数据。
普通文件可填入既有传输路径；所选普通目录和当前目录也可显式填入该路径。
“选作下载目录”把当前本地目录与已选远程单个名称连接，仅填入目标输入，不启动下载。
上传审核同时显示本地来源和远程目标；所有写入沿用现有审核、传输队列、实际写入
准入、MutationLease、内容复核和未知结果隔离。

本地 scanner 有类型化错误，保留原生 OsString／PathBuf；不读取内容、HOME、认证文件、
环境或任意无关目录。输入必须绝对且不能包含 `..`；最终根链接和 Windows reparse 拒绝。
条目通过 no-follow metadata 区分 File／Directory／Symlink／Other，链接及特殊条目
不提供浏览打开或传输使用动作。普通前缀链接仍可能存在，浏览结果不构成传输对象或权限锚。
系统选择和条目导航可携带非 UTF-8 路径；显示用 lossy 文本，原生路径保留在独立草稿中，
不会反向解析显示文本。当前传输字符串输入无法表达非 UTF-8 路径，因而拒绝填入。

单次浏览最多 4096 项／1 MiB 原生编码文件名总量，5 秒与取消在 syscall 间协作检查，
不能硬取消单个阻塞 fs 调用。根 before/after metadata 检查仅拒绝观察到的变化，
不声称精确跨平台 inode／权限绑定或消除 TOCTOU。失败不采用部分列表。
每个面板只保留一个扫描 owner，下一次明确请求等前次扫描的终态消息后启动。
实际注册线程仍由应用 shutdown 注册表持有和 join；收到列表消息不等同于已 join 线程。
手动草稿、新导航、旧 picker 回复通过 revision 区分；旧消息不能覆盖新目录。
picker 在真实回复前仍保持占用，回复先释放占用，再拒绝过期结果。

两侧支持名称／大小／修改时间的升降序，以及隐藏文件显示开关。目录排在文件前。
本地识别 dot-name 和 Windows hidden attribute；远程当前 SFTP 快照只按 dot-name
识别隐藏项，不推断服务端未提供的 hidden attribute。
未知元数据在任一方向均排在已知数据后。排序不修改底层快照或选区；隐藏所选条目清除
不可见选区并撤回未执行的审核。新的浏览／草稿／选区也撤回旧只读准备版本和目录同步
计划；只读成功回调可以被拒绝采用，但所有已发送写入、失败与未知结果仍保留真实 owner。
远程行 ID 表示可见行位置，动作和选区捕获实际原条目路径。
行选择会撤回未执行审核；因此 Open/Edit 子按钮先停止冒泡，不能让父行撤回刚创建的
弃未保存草稿审核。本地 Open/Use 同样隔离父行，避免导航清空选区后恢复旧目录条目。
真实绘制后指针对回归定义已加；静态修改不代替旧反例与修后行为通过。

## 界面和工程边界

沿用 38px 导航、至少 64px 浏览区（28px 表头和真实行）、独立工具滚动及原 48px
紧凑审核上限。展开审核、固定确认／取消、两轴滚动、原 Textarea 草稿／patch、路径锁
逻辑保持。导航 icon 按钮提供中文／英文可访问名称和 tooltip；使用现有明暗 palette。
900×580／1440×900、有／无 AI 侧栏的受控 GPUI 数据行矩阵已运行通过，仍不是原生窗口／系统 picker 验收。

新逻辑限定在 app/files 领域，无依赖、core/workspace/AI/MCP 协议变更。
scanner、纯排序及 GPUI／受控 SFTP 在本机适用三十八项已运行，文件领域总一百三十六项四线程通过。
macOS 非 UTF-8 名称夹具实际被创建系统调用拒绝；typed拒绝／原字节保持不代替 Linux 接受编码的真实 listing。
远程列表 builder 抽为独立 AnyElement helper，降低外层 debug 渲染帧，修复实际默认测试栈失败；不调高测试栈。
多选、拖放、批量目标审核和 Windows／Linux 原生系统 picker 验收保持开放。

主副本 810 输入的新完整检查实际通过 1,769 项普通 Rust、10 项 rustdoc、6 项脚本测试及严格工程检查，22 项 ignored 未执行；同输入新标准 macOS 包和 57 项打包回归通过。新原生系统 picker、隐藏项、子目录和上级导航、大小排序以及人工批准上传／下载已有窗口与完整三文件读回证据；最小原生窗口、辅助技术、其它平台和阻塞调用硬取消不由此关闭。详见[整合记录](../testing/records/2026-10-08-local-file-browser-main-integration.md)。
