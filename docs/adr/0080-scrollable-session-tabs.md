# ADR 0080：小窗口会话标签与固定关闭入口

状态：已实现，2026-10-08；最终主树完整工程门禁通过，宽窗口限定原生已观察，英文原生小窗口验收开放。

## 问题

新的独立macOS原生审查发现，英文小窗口的工具栏文字挤压会话标签容器。标题与关闭按钮一起被 `overflow_hidden` 裁切；AX中存在关闭动作不能代替鼠标用户看得见的入口。

## 决策

小于1280逻辑像素的工作区使用带可访问名称和本地化tooltip的连接、分屏、AI、关于图标按钮，保留主题与语言的明确文字选择。较宽窗口恢复文字标签。

会话标签使用有界184像素宽度，标题省略，关闭入口不收缩；超过可见区域的标签可横向滚动。两个或更多会话显示明确的上一会话／下一会话按钮，选择仍经过相同的远程终端焦点逻辑。选择、标签数量、语言或宽度变化时，滚动最小距离使活动标签可见；一般重绘不会撤销用户手动滚动。同一活动标签再次被点击也会完整显示；布局改变后，在取得新可视区尺寸的下一帧再执行一次有界滚动，避免按旧GPUI bounds判断。

关闭仍经过原工作区关闭函数，包括原SSH生命周期、Agent／MCP授权撤销和分屏关系清理。选择和关闭解析绘制时的原实体，避免列表变化后的旧索引关闭替代会话或越界；目标已移除则无动作，close阻止事件再冒泡到标签选择。本次不更改远程连接、命令审核或后台写入权限。

GPUI Kit 0.7的默认 `Assets` 只内嵌组件默认图标，应用用到的分屏／AI／软件包图标不在其中。应用注册完整离线 `AllAssets`，避免图标入口出现空白。直接 `rust-embed = "8.12"` 开启 `debug-embed`，通过Cargo特性统一让Kit在开发／正式构建都内嵌图标；不再依赖编译机registry目录或远程获取。实际资产源回归要求每个图标返回静态Borrowed字节，不把当前源码目录下成功读取当作内嵌证明。相关版本/特性见[rust-embed 8.12官方文档](https://docs.rs/rust-embed/8.12.0/rust_embed/)。

## 验证边界

四项真实GPUI元素尺寸与指针路由回归及应用实际asset source的全目录加载检查实际通过：双语言、900／1100／1279／1280／1440宽度（包括切换断点）、长标题、AI侧栏、六会话导航、旧绘制控制的实体绑定和关闭指定目标，未发送命令草稿。原始旧索引失败与限定结果见[测试记录](../testing/records/2026-10-08-compact-session-tabs.md)。这些不能代表macOS、Windows或Linux桌面截图／辅助技术验收。新原生场景需验证英文小窗口关闭动作真正可见且可点击，并核对其关闭目标。
