# ADR 0081：有界元数据历史与显式恢复

日期：2026-10-08。状态：隔离候选 v2；v1 非作者静态 P2 已修正，尚未完成最终复核、工程门禁或原生验收。

`StateStore` 已有类型验证、4 MiB 文件上限、同 inode 合作锁、原子替换、process-local revision 和损坏后拒绝覆盖。CON-04 必须扩展这条边界；不能把 load 错误转换成默认配置后保存，也不能由恢复路径重放会话或操作。认证 vault 及 OS 凭据保持独立。

采用 `state.json.backups` 中八个 UUID 槽位，包装包含格式版本、单调 sequence 和通过验证的 `AppState`。没有新依赖；包装最大为既有 4 MiB 加 256 字节。序号在同一状态锁下分配，满额时原子替换最小序号槽位，不依赖时间精度、系统时钟倒退或目录枚举顺序。序号溢出、重复、未知包装、未知文件、损坏资料及不安全文件失败关闭，拒绝正常保存前的轮转。临时文件由现有 tempfile RAII 管理；写入先同步文件，Unix 再同步历史目录。

公开 API 提供有界列表、明确创建当前有效备份、预览和明确恢复。`ConfigRecoveryPreview` 不允许外部构造，绑定具体 `StateStore` 身份、原件完整字节／缺失状态、所选槽位完整字节和已有 observed revision。两份磁盘资料在恢复的同一锁下重新读取；相同内容重新保存仍使旧 process-local revision 失效。预览只输出当前状态分类及数量，不公开命令内容、地址或原始文件 Debug。

原件写入独立 `state.json.originals`，最大八个、每个最大 4 MiB。只有用户明确恢复才创建原件，原件绝不参与自动轮转；满额拒绝恢复并要求手工归档。原件先完成独立落盘后才原子替换当前文件。成功发放新 revision；替换后目录同步错误尝试恢复完整原字节／缺失状态，不能确认回滚时清除 observed baseline 并报告 `ConfigRecoveryRequired`。所有失败材料与原件可供后续检查。

界面使用现有专业模态、滚动正文、固定操作区和中英语言／主题。blocking I/O 使用 GPUI background executor；表格读取与写入都不进入 render／event 线程。确认动作绑定当前 panel generation，且由 `Workspace` 再次验证空 SSH、AI／MCP／批量／定时空闲、无保存和待落盘审计。已派发的原子写不宣称可取消：关闭延后到实际 worker 结果，先传播成功恢复的状态再发关闭事件。语言切换的既有刷新动作提取为无磁盘写入 helper，以便恢复已有语言偏好时不会生成额外保存。

v1 静态审查确认：worker Err 只更新 panel.status 后仍发 Close，Workspace 卸载后结果会消失。v2 将实际完成处理提取为生产共用方法；失败取消 deferred close，保存实际 `Error` 和可见反馈，特别区分已确认回滚和无法确认回滚的人工修复状态。只有成功保留原有 Restored→Close 顺序；失败后需新的用户关闭。真实 stale-review／磁盘变化反例与两个 typed UI 完成控制已定义，尚未执行，不把可见状态故障注入当真实文件系统失败。

备份含 metadata 中原有凭据引用和用户片段。结构没有密码或主密码字段，恢复 API 不接收主密码、不调用 VaultStore、不读取 OS keychain。恢复后临时 AI 凭据、上下文和外部 MCP 配置失效，命令草稿保留但失去目标，后续操作需要重新审核。既有 schema 1 的缺省字段迁移保持，未来 schema 不推断；用户显式回退时保留未知当前文件的全部字节。

未采用无限快照、以 mtime 决定轮转、首次损坏自动恢复、把 vault 与 metadata 打成明文包、在 UI 线程复制资料或以后台状态恢复授权的方案。没有新增加密备份格式；未来如果导出 vault，必须独立设计认证加密容器与密码流程。

MCP 的现有 stop 路径撤销桌面权能、取消并清除句柄，把已发出的 Running 记为 OutcomeUnknown；这些本机状态不证明实际 Join 或远端物理静止。恢复的准入和新操作不重放保证不能关闭旧未知远端效果、推理进程回收或完整应用退出的生命周期验证。

原件保存与恢复是两个可观察的持久化步骤，进程突然终止可能留下原件与旧／新状态；不承诺跨文件断电事务。可信目录／合作锁不防恶意同用户路径置换。Windows ACL、断电耐久性、实际原生焦点／VoiceOver、阻塞 syscall／全应用退出与三平台 GUI 都保持开放，不能以测试定义或格式检查关闭。
