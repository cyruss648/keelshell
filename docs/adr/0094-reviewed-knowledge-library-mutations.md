# ADR 0094 — 已保存知识的审核式修改

日期：2026-11-04。状态：实现中，等待组合门禁及独立复核。

## 决策

沿用单条知识的持久化 schema，不为 UI 管理另建数据库。`SavedKnowledgeEntry::with_reviewed_content` 仅允许替换标题与摘要；所有来源与结果元数据不可变。`AppState` 替换和删除方法要求完整 `expected` 相等，在临时候选通过验证后才修改内存。磁盘仍由 `StateStore` 的快照比较和原子发布处理。

独立 GPUI 知识库 panel 只处理内存与审核。Workspace 在统一配置保存准入之后冻结 panel，并在后台读写 StateStore。审核同时绑定随机身份、原条目、配置快照和原始草稿。事件回调和最终提交都比较这些绑定，不能依赖控件的 disabled 状态或输入 Change 事件作为唯一安全门。

标题保持单行。多行摘要草稿先校验原始大小和控制字符，再按已有终端捕获语义合并空白；审核展示规范化后的完整文本。来源、时间和结果不能通过编辑变成新的事实。

任何未确认成功的保存都要求显式重新加载；重新加载成功清除旧审核并重新绑定配置消费者。单次重载身份防止迟到回调解锁另一请求。普通配置保存、配置恢复和同步变更都会刷新知识快照，导致旧审核失效。

## 取舍与验证

使用完整条目相等加配置快照避免 schema 迁移，也保留现有跨进程冲突规则。无关配置写入可能要求用户重新审核，这是有意保留的保守行为。

删除不宣称清理历史备份。本切片不增加模型发送、远程执行、审计自动摄入或跨机器同步。领域行为、真实存储往返、旧审核拒绝、取消零写入、冲突后重载与长内容页脚分别验证；原生平台验收单列。
