# ADR 0096 — 原生工作区导航与会话层级

- 日期：2026-11-05
- 状态：已实施；本机工程门禁和限定 macOS 原生观察完成，其它验收分别记录
- 范围：连接导航、会话栏、主机信息及命令工具区布局

## 问题

原工作区把会话标签和所有全局操作放在同一行，标签空间随操作文字变化。
左侧只显示主机监控，切换保存的连接需要再次打开管理器。
宽窗口的远端补全使用两行，压缩终端和文件区的可用高度。
用户已接受三套主题，要求继续优化实际应用的布局和使用体验。

## 决策

1. 沿用 Hallmark app screen 方法及既有三套语义主题。颜色、字体和组件形状
   仍由主题提供，工作区布局独立演进，不添加主题 ID 分支或示例在线数据。
2. 全局操作与会话标签分层。会话栏位于中央终端上方，保留滚动、前后导航、
   新建和关闭入口；关闭仍绑定原始实体。标签可用宽度因侧栏变化时重新显露活动项。
3. 左侧提供连接和主机信息两个入口。连接导航使用实际保存的目录、名称和端点；
   点击必须重新查找当前 UUID，复用现有连接认证和主机密钥审核。
   已存在的活动会话可以直接选中，不能凭保存的配置虚构在线状态。
4. 收起侧栏不销毁实体、修改配置或发起网络请求。小窗口显示 AI 时自动让出左侧；
   显式打开左侧会收起 AI，保留其会话和草稿。主机信息实体随原 SSH 会话保留。
5. 命令输入继续显示准确目标并保留 64px 多行编辑，补全控件改为紧凑单行。
   补全目录仍独立于终端工作目录；切换布局不能发出补全查询或执行命令。
   历史开关使用简短的开/关文案，完整作用域保留在 AX 名称和提示中。
   低于 700px 高度时从可滚动工具区调配 32px，保留真实文件行和工具操作空间。
6. 文件、命令、隧道工具入口明确显示当前选择，沿用既有实体和审核流程。
   当前阶段不改变文件操作、传输、MCP 或 AI 的权限和审核语义。
7. 弹窗返回目标记录原先所在导航页。弹窗期间窗口缩小导致该页隐藏时，
   关闭弹窗回到惰性的工作区背景，不能落入终端。侧栏和工具选择同时提供 AX toggle 状态。

## 工程与验收

导航视图单独放在 `workspace/navigation.rs`，Workspace 只拥有显示偏好和现有实体。
布局测试检查 900×580 及默认窗口的双轴可见性、活动标签关闭按钮、实际输入实体、
草稿/审核目标保持及零额外远端写入；监控测试通过实际导航进入主机页后保留原断言。
旧顶部测试改为分别约束全局栏和会话栏，不能移除控件可见性与防重叠断言。
独立会话栏更宽，手动滚动夹具改选第五项，以实际负偏移检查关闭按钮仍可移出和恢复；
历史开关缩短后要求普通操作保持同一行，仍保留完整边界、非重叠与执行行为检查。

受控 GPUI 测试不代表原生桌面验收。首包已捕获三主题浅深、中英文及窄窗口；
修后包另验隐藏焦点和 AX，按包身份和实际尺寸区分证据，
详见[工作区记录](../testing/records/2026-11-05-native-workbench.md)。Windows/Linux 桌面、IME、VoiceOver、
整套文件工具区迁移及完整产品目标继续独立验收。
