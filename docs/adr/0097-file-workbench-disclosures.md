# ADR 0097 — 浏览优先的文件工作区

日期：2026-11-05

状态：已实施；原生与平台验收边界见[本轮记录](../testing/records/2026-11-05-native-file-workbench.md)

## 背景

文件面板同时常驻名称、权限、传输路径、续传、批量说明和目录比较按钮，
压缩实际列表。本地路径与四个图标同处窄行，在最小窗口中难以阅读。
这些能力已具备操作审核和会话隔离，布局改进须保留它们。

## 决定

- 本地和远程导航均使用两行：标题与导航按钮、完整宽度的路径输入。
- 审核和已断开快照采用单行路径，给审核和结果让出高度。路径草稿仍可编辑，
  修改时继续撤回旧审核；远程刷新仍使用原有 canonical directory 规则。
- 批量上传/下载保留为直接可见的常用入口；名称/权限和传输/比较设置
  各有明确的展开入口，同一时间最多展开一个设置区。
- 默认收起设置，让真实文件列表占用剩余空间。展开设置时保留实际列表行，
  设置区独立滚动。已有编辑、比较、冲突及传输结果继续显示，不因收起设置而消失。
- 折叠只控制呈现，不替换输入实体、不清除选择、不改变 canonical directory、
  审核身份或传输 owner。待审核操作和取消入口始终由现有审核组件负责。
- 隐藏的设置输入不能继续接收键盘输入；切换设置时焦点回到可见入口，
  审核或队列导致设置隐藏时使用惰性的文件面板焦点。
- 三个主题共用语义 Palette 和组件 token，业务布局不根据主题 ID 分支。
  语言、主题和面板切换保持草稿。
- 工作区渲染构造按会话标签、终端区、工具标签、工具栏、命令输入/操作和状态栏
  分成独立函数，完成元素后返回 `AnyElement`。工具栏分组返回同级元素，
  不额外引入容器或改变焦点/操作的层级。调用边界保留，避免调试构建将多个
  大型 builder 临时值同时放入单个栈帧；不通过增大 CI 栈设置掩盖问题。

## 验证

使用真实受控 SFTP 数据验证默认浏览高度、两组操作的可达性、折叠后的
草稿及焦点、审核目标和传输状态。覆盖中英文、三主题浅深与最小/默认尺寸，
工程几何检查与实际原生捕获分开记录。独立审查后再提交。
