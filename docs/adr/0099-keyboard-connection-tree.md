# ADR 0099 — 连接树折叠与键盘浏览

- 日期：2026-11-05
- 状态：候选实现；修后工程及限定源码审查通过，原生 PARTIAL_OBSERVED，新的非作者复核只认可所列观察子集，完整输入隔离和finish仍OPEN
- 范围：现有远程工作区左侧连接导航

## 背景

目录层级已经显示，但所有目录永久展开。大量连接挤占侧栏，用户只能逐行点击或滚动；
方向键不能沿目录浏览。连接动作必须继续绑定当前保存 UUID 和实际会话，不能让浏览
触发 SSH 连接、命令或 AI 请求。

## 决定

1. 保留 260px 侧栏、名称/端点/真实连接状态三行，以及新建、搜索、管理连接入口。
   文件夹显示可折叠箭头，空文件夹保留名称但没有虚假的展开状态。三主题共用语义 token，
   使用各自的控件圆角；当前会话由文字说明，键盘浏览目标由选择背景和焦点边框标明。
2. `navigation/tree.rs` 拥有 process-local 折叠、选择及滚动状态。条目使用
   `Unfiled / Folder(UUID) / Connection(UUID)`，不保存可漂移的数组位置。
   当前版本不向配置写入目录折叠偏好。
3. 树为一个 Tab 停靠点。上下键移动可见条目，Home/End 到首尾；右键展开或进入第一子项，
   左键折叠或返回父级。搜索框向下键进入树。Tab 和 Shift-Tab 可退出，方向键浏览不连接。
4. Enter/Space 的松键激活条目；文件夹切换展开状态，连接沿用已有认证、主机密钥和会话
   绑定检查。激活候选与尚未释放的按键分别记录；鼠标切换焦点、查询、可见条目或模态
   上下文变化会撤销旧激活，但按键仍归导航所有。窗口范围的拦截先阻断绑定动作，
   工作区和模态的原始事件捕获阻止旧重复按键写入 SSH，松键后才释放归属。
   Enter/Space 交叠按下取消此次激活；隐藏导航后焦点仍回到惰性工作区。
   OS 失焦丢失松键时，后续首次非重复按下清理旧归属；跨焦点的这一事件仍不执行动作。
5. 查询临时展开匹配路径，并使用独立的查询内折叠状态；改变查询重新展开，清空后恢复
   原浏览折叠状态。删除项或隐藏子项沿旧父链回到仍可见的祖先；
   只有整个父链均不可见时才回首项，并显露恢复的选择。
   管理器的收藏/回收站过滤仍不作用于导航。
6. Kit 原生基础 Button 提供指针和 disabled 语义，行覆盖为 TreeItem 角色；
   容器拥有键盘焦点，当前项报告 active descendant、selected、层级和同级位置。
   这些语义和受控事件验证不能代替 VoiceOver 或其它辅助技术实测。

## 备选与边界

检查了锁定的 `gpui-component` / `gpui-base` 0.9.0 Tree：现成树没有本产品所需的
Home/End、父级/第一子项行为以及连接激活身份守卫，空目录也按叶处理。
本轮组合 Kit 原生控件和独立导航状态，保留原工作区业务入口，未引入新依赖或修改上游。

浏览交互参考 WAI-ARIA Tree View Pattern 的键盘约定；适配以本项目锁定 GPUI 的实际
角色、焦点 API 和生产事件测试为准。搜索框同时承担按名称/端点查找，暂未实现树内
按首字母跳转，不将其列为已完成能力。

工程、原生、跨平台及独立审查结果见
[本轮记录](../testing/records/2026-11-05-navigation-keyboard.md)。
修订包的新 run 已观察早期中文导航、搜索恢复及已有会话切换；
后期按键无变化的原因仍 UNKNOWN，两个未 Enter 的终端正控未证明输入通道有效。
零输入计数不能关闭完整键盘隔离，缩窗与完整主题矩阵仍开放；本 ADR 的按键约定
不能替代完整 OS 验收。新审查状态由父任务回写，不沿用旧源码批准为原生 ship。
