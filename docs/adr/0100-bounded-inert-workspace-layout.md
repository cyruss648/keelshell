# ADR 0100：有界分屏布局与非活动恢复元数据

- 日期：2026-11-05
- 状态：领域与持久化候选；原生接入独立推进
- 需求：TERM-02 / UI-04

## 背景

工作区目前只有会话标签和成对分屏。嵌套分屏、拖动比例、多窗口与重启恢复
需要稳定的布局身份，不能持久化 GPUI EntityId 或把旧 SSH 授权当作恢复权限。
当前连接树候选等待原生复核，因此此切片在独立 worktree 中实现，
不改变其源码、包或已冻结输入。

## 决定

在 `keelshell-core` 引入 `PaneLayout`，用扁平节点表表示二叉布局树。
`Leaf` 和 `Split` 都有类型化 `PaneNodeId`；分支通过 ID 指向两个子节点。
`Horizontal` 表示左右，`Vertical` 表示上下，比例为第一个子树的万分比。
使用整数避免 NaN、Infinity 与浮点序列化误差。比例范围 1000–9000，
实际像素最小尺寸由后续原生布局器另行约束。

每窗最多 32 个叶面板、63 个节点，根深度为 0、最大深度为 8。
迭代验证拒绝 nil/重复身份、悬空引用、环、多父、孤立节点、错误活动面板和越界比例。
分割、关闭、切换活动面板与调整比例先验证完整候选，再替换旧值；
失败保留原值。关闭最后一个面板被拒绝；关闭活动叶时选择其兄弟子树的第一个叶，
否则保持原活动叶；兄弟子树整体提升，不丢弃其内部布局。

`WorkspaceLayout` 单独保存版本、1–8 个窗口、每叶有序标签以及活动窗口/标签。
每叶最多 32 个标签，总计最多 128 个；标签 ID 在整个快照唯一，
节点 ID 在窗口内唯一。每个拓扑叶必须有且只有一份标签集合，允许空面板。
同一个连接可有多个不同标签。未知或已删除的连接 UUID 保留为缺失占位；
一次性连接只保留无连接引用的标签，不保存端点。

应用状态新增可选 `workspace_layout`。缺失时为 `None` 且不改写文件，
显式 `null`、未知版本、未知字段或无效内部引用均拒绝。
通过已有 StateStore 实施校验、字节上限、原子保存、备份和 revision 冲突保护；
AppState 相等比较包含布局，避免配置审核漏掉布局变化。
连接导出不带布局，导入不覆盖本机布局。

## 权限与实现边界

快照仅有几何关系、选择和连接 UUID，不含凭据、目标端点、命令草稿、终端输出、
传输队列、运行会话、已批准审核或隧道运行权。领域校验和可用性解析不产生 I/O 或
连接动作；StateStore 加载和保存仍是必须离开 UI 线程执行的阻塞文件 I/O。
后续原生接入只能恢复非活动视图，连接操作继续通过当前配置、认证和主机密钥流程。
若原 UUID 的目标已修改，布局本身不认可旧目标或旧信任。

本切片不创建原生窗口、不接入拖动分隔条、不替换现有成对分屏，
也不提供“自动恢复并连接”的开关。原生接入前还需设计配置恢复摘要、窗口可见范围、
空面板和缺失连接的呈现，并验证命令/AI 的活动面板作用域。
三主题继续复用同一语义 token，无需按主题分叉布局模型。

导入导出和无效输入不覆盖。门禁、失败与独立审查见
