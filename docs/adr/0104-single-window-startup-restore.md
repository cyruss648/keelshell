# ADR 0104：单窗启动恢复与未连接标签

- 日期：2026-11-05
- 状态：组合源码与门禁、限定离线原生重启分别获非作者批准
- 需求：TERM-02 / UI-04
- 基线：`dcf7438a13fff737997ee5e8061044c94d4ba53a`

## 背景

ADR 0100 已定义有界、无运行权限的布局快照，ADR 0101 已把原生分屏和稳定布局
身份接入生产工作区。启动时仍创建空布局，保存的几何、逐叶标签和选择未被安装。
恢复不能隐式认证，也不能把保存连接的 UUID、旧实体或旧审核当作运行授权。

## 决定

`Workspace::new` 在构造完成时读取已加载的 `AppState.workspace_layout`，
重新验证完整快照，只把 `active_window` 对应的一条记录安装进当前原生窗口。
生产面板树、逐叶标签和上方会话栏直接消费该恢复结果。没有布局字段时保留原有
启动行为；无效快照不发布部分布局、不改写保存数据。配置重载和保存完成不会
调用启动安装器，因此连接、主题、信任或备份状态变化不能替换已有运行实体。

`SessionPanes::restore` 在领域校验后将保存标签映射为新的临时实体 key。
保留窗口 UUID、所有分割节点和叶 UUID、轴与比例、每叶标签 UUID/顺序/选择、
活动叶以及可选连接引用。多个空叶也是有效布局；普通 render/reconcile 不收拢
未被使用的保存空叶。原本有标签的叶在最后一个标签被移除时继续沿用收拢规则。
空活动叶使用没有活动实体的索引状态，所有实体读取保持有界 `get`；
不得退选、关闭或向兄弟叶的会话发送输入。

每个恢复标签使用 `TerminalView::inactive` 获得临时实体身份，便于复用现有
`SessionPanes<EntityId>` 和目标隔离规则。该实体关闭输入，没有传输、
生命周期来源、worker、轮询任务、待发送输入或旧历史；生产视图渲染明确的
未连接占位内容。`restored_tabs` 单独持有原 `LayoutTab`，
不会填充 remote session、主机、工具面板、重连、命令历史或审核权限的映射。

## 原生呈现与动作

每次绘制及动作执行重新从当前 profile 集合解析原连接引用：

| 状态 | 原生说明和动作 |
| --- | --- |
| 可用，未连接 | 当前 profile 名称；显式“连接”、管理连接、关闭标签 |
| 未保存连接占位 | 不恢复地址或认证草稿；管理连接、关闭标签 |
| 连接缺失或在回收站 | 保留原引用；管理连接检查删除/回收记录、关闭标签 |

管理器中恢复 profile 后，原标签可再次显示为可用；相同端点的新 UUID 不替代旧引用。
关闭标签与显式保存布局分开：保存保留尚存的未保存/缺失引用，只更新当前窗口记录，
未选保存窗口的内容与顺序继续保留。后台 StateStore 写入和 revision 冲突保护沿用既有实现。

使用既有 Palette、Kit 按钮和原生焦点，没有主题 ID 分支、字面颜色、新字体或动画。
状态提供文字及中英文 AX，操作按钮可通过键盘到达；空间不足沿用活动叶紧凑呈现。
空叶可选择并打开连接管理器。占位标签选择和空叶选择把焦点放到惰性工作区；
弹窗返回检查原占位控件是否仍属于可见标签，避免恢复到已替换或隐藏的旧控件。

## 显式连接的授权边界

占位“连接”不走导航中复用已有实时会话的捷径。它在动作时解析当前 profile，
通过现有 `begin_connect_route` / `prepare_route_hop` 进入逐跳认证、当前凭据来源、
主机密钥审核与变化阻断流程。路线额外携带原占位实体、布局标签 UUID 和连接 UUID；
现有异步路线校验同时确认该占位仍存在、引用仍匹配且未成为运行会话。
删除/回收、路线变更、关闭或取消使旧结果失效；迟到成功不能安装到其他标签。

认证成功后只通过 `SessionPanes::replace` 将原占位 key 替换为新传输实体，
保留窗口/叶/标签身份、顺序和选择。原位替换不占新增标签容量，满叶/满工作区
仍可显式连接。新实体不继承旧草稿、终端历史、命令历史、AI/MCP 授权或审核目标。
已有命令审核仍绑定原实体，必须重新审核才能发给新会话。
若另一个实时标签处于活动状态，安装恢复连接不改选该标签或更换其工具选择。

启动恢复本身不启动 SSH、Shell、AI 请求、隧道、批任务或工作流。显式连接成功后
按正常新运行会话建立观察与工具能力；保存快照没有恢复这些运行操作的字段。

## 范围与验证

本轮只恢复一个已保存活动窗口的内容。其余窗口仅保留元数据，不创建额外 OS 窗口。
已有版本一快照的“几何”是面板拓扑和比例，没有 OS 窗口坐标、显示器或外框尺寸；
因此本轮不声称恢复这些不存在的字段，原生窗口仍使用现有启动选项。

受控 GPUI 测试必须从持久化状态构造生产 `Workspace` 并实际绘制面板，
不能用 preview 数据替代恢复。领域适配器测试验证空叶、身份、容量和失败保持；
loopback SSH 测试验证显式认证、逐跳信任和异步撤销。所有 Cargo 执行由父任务分配槽位，
本轮在独占槽位上完成有界定向检查，使用 jobs=2、test-threads=4；
领域/GPUI/惰性终端/reopen/loopback 合计 61 个不同测试通过。
宏导入编译失败和紧凑夹具失败及其修复记录保留；工程输入已冻结，target 已释放。
