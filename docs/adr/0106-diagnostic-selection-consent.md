# ADR 0106：诊断审核绑定连续的活动面板选择

日期：2026-11-06。状态：已实现候选，组合门禁与独立复核另记。

## 决定

Workspace 为活动叶和选中标签保留一个临时 UUID。仅当这两个身份之一变化时，
在同一前台操作内更新 UUID，并通知已有监控面板撤销诊断审核、清除结果和取消任务。
切走再切回不会恢复旧 UUID；再次选择同一标签或关闭非活动标签保留当前 UUID。
选择空叶也参与这项规则，即使全局标签索引同样指向列表末尾。

诊断预览捕获 UUID，确认与结果采用再次通过只读接口核对活动叶、实际标签、
捕获的 SSH 连接和既有保存路线/信任。每次重新选择都可以重新预览，
普通选择变化不会销毁 SSH 连接。标签焦点、新建、关闭、重连替换、折叠、
恢复和空叶操作从其生产入口同步维护选择；不依赖渲染或轮询撤权。
终端正文的指针事件在 Workspace wrapper 捕获阶段先选择目标，
再进入终端实体和可能消费事件的鼠标报告处理。GPUI 焦点监听到绘制末尾才通知，
因此只作为已选择目标的后备同步，不能承载同帧切走再切回的审核保证。

搜索条保留鼠标遮挡，避免点击搜索控件编码成 SSH 鼠标输入；
它在自己的捕获阶段发布输入所有者。终端聚焦、打开搜索和搜索动作也先发布所有者。
回调只按 EntityId 更新 Workspace，不能读取或更新当前已借用的 TerminalView
或 InputState，也不移动焦点，保证搜索输入仍保留用户的实际焦点。
Workspace 自身发起的命令聚焦使用已有 FocusHandle，避免反向重入已借用的父实体。
Tab/Shift-Tab 的已完成动作另通过限定窗口的按键观察者核对真实输入焦点，
在子实体借用返回后、下一帧绘制前同步选择。普通终端消费的 Tab 不经过该观察者。
搜索输入的焦点只在 Input 上登记一次，避免同一 handle 在祖先与子元素重复插入 Tab 顺序。
搜索条另有独立且不参与 Tab 顺序的父焦点范围，覆盖输入框及上一个、下一个、关闭按钮；
不能只识别输入框，否则反向 Tab 可直接进入按钮而跳过撤权。
搜索导航动作自身也发布所有者，覆盖直接键盘激活按钮的路径。

既有 `protocol_session_current` 的会话有效性语义保持独立。Agent、MCP、
文件和隧道的授权不因这项诊断选择规则而被隐式改写。

## 不确定退出

ICMP 调用的任意错误都意味着本次没有取得可验证的监督器结果，
包含非零退出、仅 SSH exit-signal、缺失 Python、取消、通道故障和输出错误。
即使请求标记已经失效，也先停用该诊断权限，防止旧 worker 未确认退出时直接重试。
退出零且通过完整帧校验的能力拒绝仍作为结构化结果呈现。
这项 UI 停用不能证明远端 worker 已回收。

## 验证与边界

使用实际 Workspace 选择/关闭入口及固定主机身份的回环 SSH，
验证同一前台操作中的 A→B→A、旧确认拒绝、新预览后成功、
非活动关闭正控、挂起回复取消和迟到结果拒绝。
另以受控 SSH 非零/信号退出帧覆盖当前与过期请求标记。
真实裸鼠标事件另覆盖正文和遮挡搜索条的切走/返回、搜索关闭取消挂起回复；
真实 Root Tab/Shift-Tab 动作覆盖输入框及三个按钮，Escape 返回终端，
空格激活覆盖搜索导航与关闭；另有绕过 Tab 观察者的导航按钮激活用例。
焦点断言在 key-down 返回后、下一事件之前检查，空格激活在 key-up 返回后检查；
GPUI 可能在后续键盘事件开始前绘制，不声称多次按键之间完全没有绘制。
同一所有者内搜索开关和输入点击保留审核与搜索焦点，并可经新审核实际 dispatch，
防止把全部禁用误当作选择隔离。负控单独停用输入所有者通知，
保留控件与测试，旧确认测试必须在选择断言失败。
另分别恢复“仅识别输入框”和移除搜索导航发布，各自同测均必须失败；
实际结果见运行记录。
这些是工程回归；真实 ICMP、原生输入和平台验收分别记录。
