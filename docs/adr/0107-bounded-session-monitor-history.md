# ADR 0107：会话内有界资源历史

日期：2026-11-06。状态：已实现，组合工程门禁通过，原生范围另记。

## 决定

CPU/内存趋势复用现有Linux资源采集器与五秒轮询，不新增远端命令或后台任务。
UI内的独立历史模型接收已采用的新样本，最多保留最近五分钟、60个时间位置。
数量和时间淘汰同时生效，手动刷新不会绕过上限。

时间轴使用样本的实际时间；值可用性与段身份显式表示。
缺失、非法数值、首CPU样本、暂停、错误、重启、计数回退和时间异常
不能隐式转换为零或跨段插值。新段需要自己的有效CPU计数基准。
模型不依赖绘制频率；资源面板只读取模型并使用语义token绘制和提供文本说明。

历史归属现有MonitorPanel及捕获的SSH会话，不作全局共享或持久化。
重连/替换后旧完成不得追加到新的历史；暂停和会话结束的生命周期
继续使用现有busy、取消和关闭规则。趋势显示不改变诊断或其它功能的审核权限。

## 原因与限制

日常压力判断需要一段短历史，单个瞬时值不能显示持续性。
固定内存、复用采集及显式断段能避免额外远端负载和误导性的连续图形。
此设计只服务当前会话，不构成监控数据库、告警或跨设备历史系统。

验收入口为[资源趋势指南](../product/HOST_RESOURCE_TRENDS.md)。
实现、专项、组合门禁及原生记录完成前，不将本设计记为已验收功能。
