# ADR 0108：知识条目的审核式整批删除

日期：2026-11-06。状态：已实现，组合工程门禁通过，原生范围另记。

## 决定

知识管理维护独立的有界管理选择，最多32个唯一条目，
不复用Ask附件或单条编辑的选择状态。审核捕获完整原条目集、配置快照和独立review ID；
选择或任一原条目改变即撤销审核，旧控件回调不能操作新review。

core先验证全部条目及集合约束，再从同一配置克隆一次候选并精确删除整批，
保持其它记录及顺序。Workspace复用既有保存队列和AfterSave通知，
不为批量删除另建存储通道，不逐条保存制造部分成功。

保存开始就同步使受影响的Ask上下文不可用，并取消在途请求。
发送入口仍须重新验证当前资料与保存状态，不能依赖异步通知已送达。
旧完成不能重新接纳已经移除或发生变化的条目。

取消不写入；Conflict、Unknown和其它失败继续遵循既有显式恢复规则，
不自动重新提交删除，也不以UI成功代替实际存储读回。
操作仅影响本地知识元数据，不授权模型发送、SSH动作或历史备份擦除。

## 原因与限制

独立管理选择能避免整理资料时改变Ask发送范围。
整批验证和一次持久化让用户看到的审核集合与实际删除集合保持一致；
已有队列继续负责顺序、冲突和耐久性边界。
分类、跨设备同步及知识schema扩展留给后续切片。

验收入口为[知识管理指南](../product/KNOWLEDGE_BULK_MANAGEMENT.md)。
实现、专项、组合门禁及原生记录完成前，不将本设计记为已验收功能。
