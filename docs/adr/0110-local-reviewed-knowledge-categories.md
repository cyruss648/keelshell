# ADR 0110：本地知识分类与独立上下文投影

日期：2026-11-06。状态：实施中，验收尚未完成。

## 背景

知识库已有来源事实、完整对象审核、管理多选和显式Ask附件。
用户整理用分类需要独立于来源类型，并保持已有持久化及授权撤销边界。
直接给序列化记录增加分类字段会使既有Ask完整JSON组合顺带发送该标签。

## 决定

每条保存知识增加一个可选本地分类；旧数据缺字段时默认未分类。
分类从条目派生，不建立独立目录或层级。
输入通过统一有界校验；错误和Debug信息不回显分类内容。
具体规范在[产品合同](../product/KNOWLEDGE_CATEGORIES.md)随实现冻结。

分类纳入完整对象相等性，旧分类版本不能继续批准修改、删除或模型上下文。
单条分类变更有独立草稿和修订身份，审核展示完整原对象与候选对象；
确认复用Workspace后台保存队列，取消不写入，Conflict/Unknown仍重新加载并重新审核。
仅分类变化不混入正文草稿，正文编辑保留分类。

持久化记录和模型上下文采用不同的显式投影。
保存配置包含分类；Ask投影省略分类，保留原有历史内容和来源事实。
上下文字节预算使用同一投影，完整对象检查仍使用包含分类的当前库记录。
因此本地分类变化会撤销旧授权，同时不会扩大模型接收的信息。

筛选只影响可见列表，与管理选择、Ask附件和编辑状态独立。
类别数量与名称长度不应挤掉实际条目和审核入口；
使用有界可访问选择区，并保留完整名称的辅助说明。

## 后果与验证

旧配置继续可用，重启后分类随明确保存保留；
本片不引入跨设备知识同步、自动分类或历史SSH授权恢复。
验证旧数据兼容、输入边界、交集筛选、完整对象冲突、
取消零写、单次保存及实际Ask投影不含分类。
源码、组合门禁和开发包原生验收分别从
[本片记录](../testing/records/2026-11-06-monitor-knowledge-categories.md)接续。
