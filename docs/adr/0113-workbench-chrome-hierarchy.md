# ADR 0113：工作区高频外壳的层级化视觉

- 日期：2026-11-06
- 状态：实现候选；定向 GPUI 回归、完整工程门禁和独立只读复核通过，原生桌面边界另记
- 关联：Hallmark 原生映射、三主题注册表、工作区设计

## 背景

连接导航、会话栏、工具栏和状态栏是用户持续注视的工作区外壳。此前这些区域
主要使用相邻的 `surface`、`canvas` 和细边框，功能正确但层级较平，活动会话
与当前工具的视觉重量不够明确。

## 决定

工作区外壳使用稳定的三层语义关系：

1. 顶部全局工具栏、会话栏、底部工具栏和状态栏使用当前主题的 `chrome`。
2. 活动会话使用 `surface`，以 `accent` 边界和半粗底边表达当前目标；未活动
   会话保留 `canvas` 和普通 `border`，不改变会话身份或点击行为。
3. 连接导航的面板选择器也使用 `chrome`，与树内容的 `sidebar` 区分；树行仍
   使用现有选择、悬停、焦点和辅助技术语义。

会话标题在活动时提高一个字重，工具栏的全局设置组与会话操作组之间使用一条
细分隔线。所有这些调整只消费语义 Palette 和现有 ComponentTokens，不按
`frost`、`graphite` 或 `lavender` 分支业务布局，也不改变窗口宽度、会话
实体、焦点所有者、审核权限或持久化协议。

## 取舍

`chrome` 只用于工作区外壳，避免把所有区域都提升为卡片。活动会话使用 `surface`
而非新的颜色，保证浅色和深色主题都保持足够对比；accent 只表达当前目标，
不作为装饰性状态点。保留现有 900×580 最小窗口布局和横向会话滚动，避免视觉
改动挤压命令输入、AI 面板或文件工具。

## 验证和边界

定向 GPUI 测试覆盖三主题/明暗/中英文下的工作区边界和草稿身份，工作区布局
5 项、主题 7 项、连接导航 21 项通过。该证据证明受控 GPUI 布局与行为保持，
不证明 macOS 完整原生截图、VoiceOver、Windows/Linux 桌面或发行包验收。
