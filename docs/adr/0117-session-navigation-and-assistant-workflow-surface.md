# ADR 0117：会话导航与 AI 审核工作流表面

- 日期：2026-11-07
- 状态：已实现，定向 GPUI 回归和完整工程门禁通过；独立复核和原生桌面验收待完成
- 范围：`keelshell-app` 工作区会话条、连接库和 AI 助手面板

## 背景

工作区已经具备连接库、终端会话、显式 AI 请求和本地知识审核能力，但这些
能力在视觉上仍由多个局部入口表达。会话较多时，用户需要反复点击标签条才能
切换目标；连接库空态和筛选状态缺少稳定的范围反馈；AI 面板虽然保留审核闸门，
但用户需要从上下文捕获一路读到回复和知识保存，才能理解当前阶段。

本轮需要提高工作台的连续性，同时保持已有的连接、草稿、凭据、SSH 生命周期和
AI 权限模型不变。

## 决策

### 会话条使用稳定的导航动作

会话条提供上一个和下一个会话动作，并绑定平台惯用组合键：

- macOS：`Command-Option-Left/Right`；
- Windows/Linux：`Control-Alt-Left/Right`。

快捷键在应用级按当前窗口拦截，终端输入获得焦点时仍然可以切换会话；动作只
改变 Workspace 的活动索引和已有焦点，不连接新主机、不重建 SSH、不发送命令，
也不覆盖当前会话的未发送草稿。到达首尾时保持当前会话。会话条显示总数，并
用双语可访问标签描述按钮、标签和快捷键。

### 连接库反馈范围和空态

连接库把当前范围、命中数量、批量选择数量和搜索摘要放在标题区。全部、收藏、
最近连接、回收站、文件夹和搜索无结果分别使用对应的空态；空库提供新建连接
入口。视图只消费已有的筛选和选择状态，不改变连接数据、持久化或批量审核。

### AI 助手以阶段轨道表达审核边界

AI 助手顶部使用六个阶段：

1. 捕获：用户明确选择所选文本或当前屏幕；
2. 提问：编辑问题并选择配置；
3. 预览：检查完整脱敏请求；
4. 发送：只发送用户确认的精确请求；
5. 审核回复：查看回复、目标和命令建议；
6. 保存知识：确认结果后预览并保存本地知识。

阶段状态由现有面板状态派生，不增加第二套授权状态。上下文不会自动读取，
请求不会跳过预览，回复中的命令不会自动进入命令栏，Agent 操作仍逐项审核，
知识保存仍要求明确结果状态和本地内容闸门。模型发送、命令执行、文件修改和
知识写入都不能由阶段轨道本身触发。

AI 面板使用独立正文滚动区。收到普通 Ask 回复后，回复审核标题成为滚动锚点，
面板在下一帧自动显露审核区，避免长上下文把回复藏在首屏之外；用户仍可继续
滚动查看完整捕获、请求和审核内容。

知识预览的保存动作位于助手底部固定 footer，长 Markdown 和来源列表只占用正文
滚动区。Agent 停止并编辑问题时，面板先撤销旧请求和 Agent 状态，再在最新 render
的 `on_prepaint` 中按问题矩形与正文 viewport 的实际关系修正滚动偏移，避免旧
历史布局留下不可见输入框。

### 主题通过 token 扩展

会话条、连接库和 AI 助手只使用语义 Palette、组件形状、Chrome token 和
Typography token。Frost「霜白」、Graphite「曜石」、Lavender「雾紫」全部作为
注册表主题提供，业务视图不按主题 ID 分支。新增主题只需要补齐注册定义及其
语义 token，不能在业务视图中复制一套主题条件。

## 取舍与限制

平台组合键在 GPUI headless 测试中按当前编译目标验证；Windows/Linux 原生键盘
布局、输入法和辅助技术仍要在真实桌面复核。AI 阶段轨道是状态和审核边界的
可视化，不代表外部供应商、云模型或完整 Agent 原生体验已经验收。响应自动显露
只调整 UI 滚动位置，不改变请求结果、目标绑定或审核状态。

双语重新翻译、完整请求预览、回复审核可达性、长 MCP 审核、Agent 问题编辑、
知识保存 footer 和主题 token 消费。完整 `python3 scripts/check.py` 已退出 0；
