# ADR 0124：保存已审核的 AI 命令为可复用片段

- 日期：2026-11-13
- 状态：已实现；本片 focused GPUI、纯逻辑和静态门禁通过；原生/provider 验收待后续
- 关联：[AI 命令片段](../product/AI_COMMAND_SNIPPETS.md)、[AI 助手审核工作流](../product/AI_ASSISTANT_WORKFLOW.md)、[命令片段领域与存储](0010-command-snippets-and-local-suggestions.md)

## 背景

AI 回复中的 shell 代码块已经可以经过目标和会话绑定的人工审核后送入命令审阅区。
用户还需要把经过审核的建议整理为本地可复用片段，同时保留审核来源，避免把模型
输出误认为已经允许执行的命令。

## 决定

普通建议和诊断计划步骤都提供“保存为命令片段”入口。用户点击入口时，助手为当前
命令、目标和会话生成一次有效期 120 秒的精确 `CommandProposal` 审核票据，并把
命令、目标、会话、review ID 和单调审核时间传给既有 `SnippetEditor`。

编辑器使用已有 `Snippet` 字段和命令片段模型。名称、说明、标签、命令和显式参数
模式在保存前都可以修改。编辑器横幅持续显示原始目标与会话；命令被修改后明确提示
原审核只覆盖原始命令，使用前仍需要重新审核。保存只产生本地片段写入事件，不填入
命令栏、不发送终端输入、不执行命令。

Workspace 在接受保存事件时重新检查审核来源：命令不能为空且不能含危险控制字符，
目标和会话必须完整且无控制字符，review ID 不能为 nil，审核时间不能超过 120 秒，
当前活动终端必须仍是原始会话且其目标必须仍匹配。会话结束或目标变化时，编辑器保留
完整草稿并显示原因，StateStore 不发生写入。

通过后继续调用既有 `AppState::insert_snippet` 和 `Workspace::persist`。因此现有
`Snippet::validate`、重复 ID 检查、StateStore revision/锁和原子替换仍是唯一的
持久化边界。重复 ID、空命令和危险控制字符都以可恢复错误返回，用户可以继续编辑
或取消。

来源横幅和命令预览使用现有主题的 `TypographyTokens::code_font_family`。本片不增加
主题分支、不改变主题注册表，也不引入依赖。

## 后果

保存后的片段是本地明文命令模板，仍属于不可信、需再次审核的输入。编辑过的命令不会
伪装成原始 AI 审核内容；保存过程也不会替用户重新审核或自动执行。审核来源只在当前
进程的编辑器草稿中保留，不扩展持久化 JSON 格式。

headless GPUI 回归可以证明生产组件的事件、可见性、草稿保留和本地 StateStore 边界，
不能代替 macOS、Windows 或 Linux 原生窗口与输入法/辅助技术验收，也不能证明真实
AI provider、真实 SSH 或客户机器上的业务流程。
