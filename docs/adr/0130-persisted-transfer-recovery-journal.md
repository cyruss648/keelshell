# ADR 0130：重启后传输恢复日志与显式续传

日期：2026-11-14。当前实现提交：
`52f861e3130749715ea20824efa1f1b1619f1e3b`。本 ADR 只描述文件传输恢复
日志；它不把日志记录当作自动恢复指令。

## 背景

文件传输可能在应用退出、会话断开、取消或传输结果无法确认时留下部分
目标内容。仅把恢复候选保存在当前文件面板中，会让用户重启后看不到已知
风险；把完整队列、SSH 会话或 worker 写入磁盘，又会把过期的执行权带入新
进程。恢复必须让用户看见事实，同时要求新会话和新审核重新建立执行条件。

## 决策

### 1. 使用独立的有界恢复日志

应用在用户数据目录中使用独立的 `transfer-recovery.json`，不把传输恢复记录
混入普通工作区状态文件。文档 schema version 为 `1`，最多保留 32 条记录，
序列化文档最多 256 KiB，每条本地或远端路径最多 4096 个 UTF-8 字节。记录
保存传输方向、文件/目录类型、路径、已传输字节、已审核的已有字节、可选总
字节数、创建/更新时间和 `Unfinished`、`OutcomeUnknown`、`Failed`、
`Cancelled` 之一的结果分类。

保存连接来源的记录带有 `connection_id`。快速连接和旧格式记录可以没有这个
绑定，但界面必须显示当前 SSH 端点并要求用户确认当前主机；没有绑定不能被
解释成自动信任。

### 2. 日志不携带任何运行时执行权

恢复记录明确不包含 SSH session、SFTP handle、socket、worker、review token、
凭据、私钥、命令、秘密、代理认证或流量。路径只用于用户检查和生成下一次
只读审核输入。加载日志不会连接远端、启动传输、复用旧运行时或重放命令。

绑定的 `connection_id` 在任何远端只读检查前进行比较；绑定不一致立即拒绝。
无绑定记录必须经过当前 SSH 主机确认。当前路径、方向、目录类型、连接绑定
和会话身份仍由应用在 `Inspect → Review → Confirm` 的流程中重新确认。

### 3. 采用原子、有锁、权限受限的本地写入

`TransferRecoveryStore` 的读取、更新和删除都在后台 worker 执行。存储使用
同目录锁文件串行化多窗口更新，拒绝符号链接和非普通文件；Unix 文件使用
owner-only 权限。写入先创建同目录临时文件，写完后 `sync_all`，再原子替换
目标文件，并同步父目录。文档损坏、未知 schema、重复 ID、超出数量/大小、
路径越界或权限不安全时 fail closed。

每条记录在审核和执行生命周期中还持有一个独立的 OS 文件锁 claim。claim
覆盖当前记录的日志路径和记录 ID，窗口和进程之间只能有一个恢复审核或
worker 继续持有它；普通 `upsert` 在已有 claim 时拒绝，带 claim 的更新和
删除会重新校验所有权。这样同一恢复记录不会被两个窗口同时续传，也不会由
迟到的 worker 覆盖新审核或删除新的状态。队列初始化失败、取消、worker
启动失败、挂起、导航撤销和旧审核替换都会释放 claim。

### 4. 在真实传输生命周期中写入检查点和终态

实际开始传输前先持久化 `Unfinished`。传输进度在有界检查点更新已传输字节；
失败、取消、结果未知、队列初始化失败和 SFTP 入队失败都保留明确终态。重复
终态事件不会覆盖已经保留的未知结果。恢复日志自身写入或清理失败时，最终
UI 结果继续显示该风险，不能伪装成已完成。

成功的显式恢复完成后删除对应记录；用户的 `Discard` 也只删除本地记录，不
连接、不检查、不写远端、不重放传输。恢复失败、取消或结果未知时保留记录，
供用户再次检查。

恢复 Inspect 先获取 claim。没有 `connection_id` 的旧格式或快速连接记录，
必须先让用户确认当前 SSH 主机，确认前不执行远端只读计划。只读计划重新
计算的已有字节数、总字节数和安全范围内的已传输字节数会回写持久记录；
审核文案使用记录自身保存的连接绑定，而不是当前面板的瞬时绑定状态。

## 后果

用户重启后可以看到未完成、失败、取消和未知结果的传输事实，并能从当前会话
重新检查部分目标。应用不会因为恢复日志而获得隐含的连接或写入权限；连接、
主机信任、远端内容、已有目标和当前会话都必须重新通过现有审核合同。

日志使用独立文件和稳定 schema，未来可以扩展记录字段而不改变普通工作区
状态迁移。新增主题只扩展主题 registry、Palette 和组件 token；恢复卡片不
按主题 ID 增加业务分支。
