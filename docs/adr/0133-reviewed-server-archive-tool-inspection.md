# ADR 0133：审核式服务端归档工具观察

- 日期：2026-11-15
- 状态：已实现，集中工程门禁与非作者源码复核通过；原生交互验收开放
- 对应需求：FILE-05 的服务端能力探测基础

## 决策

在现有归档传输披露区增加「服务端工具」观察。用户先审核当前 SSH 主机和完整
固定命令，再明确确认。命令只通过 POSIX `sh` / `command -v` 观察 tar、gzip、
zip、unzip、python3、rz、sz 的 PATH 解析；不运行所列工具，不安装程序，不读取
归档，也不启动压缩、Zmodem 或网络测速。

状态分为已找到绝对路径、未找到和未能确认的解析结果。找到路径不代表程序版本、
可执行权限、实际格式支持或互通已验证；shell/protocol 不支持和超时是本次检测
失败，不能伪装成所有工具都缺失。本片不把观察结果用作写操作或命令授权。

传输层提供固定命令与有界类型化报告，处理严格 NUL 协议、UTF-8、路径长度、
记录顺序、输出上限、取消和总体期限。使用当前认证 SSH 的独立 exec channel；
不打开 SFTP，不在本地执行 shell。所有网络工作在后台 transport worker。

审核同时绑定面板会话 token、主机显示与实际 `SshSession::same_connection`。
确认、worker 入场与结果回调均核对身份。迟到结果、会话替换和挂起不能带入新
目标。每次检测需要新的审核；没有启动、主题切换或自动刷新探测。

观察只保存在对应面板内存中。重新检测开始即撤销旧成功显示，失败明确要求重新
审核，不用旧结果冒充本次结果。不修改连接配置、传输恢复记录或凭据。
文件草稿、比较和既有传输结果继续保留。

## 原生设计与验证

三套主题共用注册表、语义 Palette 和 Kit 控件。结果默认摘要，详情最多七项，
使用独立有界滚动区；完整命令复用既有固定确认/取消审核，不截断后执行。
中英文、未检查、执行中、失败及成功观察各有明确文本。

实现按传输层、原生界面和归档格式兼容三个不相交写集并行；集成后统一执行
核心/SSH/GPUI 专项、完整门禁、实际 OpenSSH 和新的非作者复核。发现项集中
修复。原生平台、完整工具执行、版本识别、服务端实际打包及 Zmodem 仍独立验收。

本批最终集中门禁退出 `0`；工具 transport/UI 非作者复核 APPROVE、零 P0–P3，
使用已核对的父预构建 binary 独立执行 6 项 GPUI 和 16 项 SSH 回归，没有独立
重编译。真实 localhost OpenSSH 14 项通过。原始报告和最终冻结见
[集中验证记录](../testing/records/2026-11-15-archive-tools-pax-integration.md)。
