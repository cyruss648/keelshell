# ADR 0135：审核式服务器归档

- 日期：2026-11-15
- 状态：采用；集中工程门禁与真实 OpenSSH 通过，独立复核和原生边界单独记录
- 对应需求：FILE-05 的服务器打包

## 决策

在既有「传输设置 → 归档传输」增加「审核远端打包」，使用远端复选项、
明确格式和新归档名称。接纳 1–32 个同级普通文件或目录，目标为同一父目录下
的新 ZIP/tar.gz。这样临时工作、目标与被归档子树分离，避免把输出再次归档。

需要远端 macOS/Linux 与 Python 3.8+ 标准库，不依赖 tar/zip 的版本和命令行差异。
不把此前 PATH 观察当作执行或功能授权。完整辅助程序随产品源码提供，
通过固定解释器命令与结构化数据传入，路径不能成为 shell 语法。

采用两次独立审核。第一次展示当前真实 SSH 主机和完整只读扫描命令；
确认后在服务器遍历并计算完整清单和 SHA-256，不上传源内容、不写归档。
第二次展示全部成员、类型、大小、摘要、新目标、精确临时路径、完整写入命令
和标准输入。取消、导航、草稿或选择变化、会话替换都会撤销后续权限。
标准输入必须能以精确 UTF-8 展示，不能损失转换后仍执行原字节。

## 有界格式与发布

沿用客户端归档的格式与资源上限：编码 64 MiB、展开 128 MiB、2048 成员、
32 层、4096 字节单路径、48 KiB 成员名。请求、标准输入、标准输出及错误另有
固定上限；非法、过量、不完整或含歧义的响应直接拒绝，不省略成员后执行。
路径、大小写别名、链接、硬链接及特殊成员均保持保守拒绝。

确认后，辅助程序使用已有父目录的受检句柄、逐级 no-follow 打开和完整源快照，
重新核验成员并在服务器压缩。新建私有临时目录和普通 payload，不复用既有
临时路径；成员不恢复归档权限或所有者。发布使用同一文件系统的 no-replace
硬链接，目标存在则失败。只在完整读回、格式解码、成员内容摘要及临时目录
清理均确定后认定成功。失败不自动删除、重试、覆盖或继续下载。

`0700/0600` 不能替代继承 ACL 检查。新建目录和 payload 在任何源内容写入前，
仅通过各自受检 fd 清除并重新验证 ACL；macOS 使用 Darwin extended ACL 接口，
Linux 使用 fd xattr 接口清除 POSIX access/default ACL 并拒绝其他 ACL 家族。
权限接口缺失、查询或设置失败及无法识别的权限模型均拒绝，其他 POSIX 后端
保持未支持。源、父目录及已有目标的权限不修改。目录复核和归档读回还要重复
验证 ACL；失败保留隔离对象。真实 macOS 继承与中途权限变化回归单独保存，
不能据此代签 Linux 文件系统或旧 Python 运行验收。

session 为源子树保留读资源，为新目标和精确临时树保留写资源。
SSH 真正派发之前重新检查取消及当前连接；派发后丢失回复、丢弃 future、
超时、失败或读回不符保留未知写入和隔离。SSH 通道关闭不能证明远程进程退出。
文件面板的关闭保护只释放本次已知终态的 owner，保留更早未决项。

这些检查是有界观察和应用内协调，不宣称对服务器同一用户的恶意并发修改
建立全文件系统锁。源快照和目标读回的范围、时间窗口随测试公开。
临时归档没有持久恢复授权，重启后不能自动继续。

2026-11-16 集中回归补充：未选中的祖先目录在逐级打开前后及最终路径复核时，
比较设备、inode、mode、uid、gid 和 flags。其他进程创建或删除其旁支，
会改变目录大小、链接数及时间，这些字段不代表祖先身份。
所选父目录和成员继续比较完整 stat，并核对内容摘要；链接替换、inode 替换、
权限或归属字段变化仍拒绝。该身份检查不新增祖先 ACL 快照保证；
新建临时目录和 payload 的 ACL 清除与重复验证合同保持。
确定性真实文件系统红/绿回归及原始并发失败见
[旧编码批集中记录](../testing/records/2026-11-15-legacy-editor-encodings.md)。

## 原生设计

共用现有三套主题注册表、语义 Palette 和 Kit 按钮，不新增主题 ID 业务分支。
保留文件列表空间；只新增归档区的明确动作，复用完整正文滚动和固定确认/取消。
第一次审核说明只读扫描，第二次审核说明写入；忙碌、失败、未知和成功使用
中英文文本，不以颜色代替状态。完成后提示刷新列表再选择下载或解包。

## 验证与边界

纯 core 测试覆盖请求、严格协议、格式与清单匹配，真实隔离 Python 进程覆盖
实际打包、变更、别名和已有目标。session 测试覆盖加密 SSH、标准输入、期限、
取消、连接替换、资源竞争及未知结果。GPUI 测试覆盖两次实际确认、撤销和三主题
双语；真实 localhost OpenSSH 另行执行。集成后统一完整门禁和新的非作者复核，
不重复每个作者的全仓运行。

冻结输入包含 Rust、Cargo 与所有被 `include_str!` 引用的辅助程序；构建和测试
库存必须实际包含本批新增用例。源码、受控协议和本机 OpenSSH 均不能代签三平台
原生桌面、Windows 解包、Zmodem、中继、性能收益或发行安装验收。
