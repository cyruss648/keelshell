# 0141 — 审核式 SSH 路径比较

日期：2026-11-16。状态：已实现，集中工程门禁、真实 localhost OpenSSH 与
两个限定非作者范围复核通过；原生与 IP 丢包验收开放。

## 目标

用户使用已有 SSH 连接配置管理自己的中继。跳板配置实际建立经过中继的 SSH
连接，每一跳独立验证主机密钥，目标继续端到端认证。增加两条已认证路径的有限、
可复现比较，帮助用户依据本次观察选择配置；不自动连接、重试或切换路径。

## 身份与授权

传输层在成功认证时封存请求的目标 host、port、username、已核验主机密钥，以及
实际建立的完整 SSH 跳板链和每跳显式代理种类/host/port。元数据没有凭据，
不从可编辑 profile 回填。比较必须使用两个不同的真实连接，目标三元组和已核验
主机密钥相等、路径不同；同一主机密钥不被解释为独占机器身份，DNS/集群仍可能
落到不同实例。比较只证明请求同一逻辑端点的两条路径。

原生入口位于现有监控区。用户从同窗仍然有效的连接中选择第二条路径，审核两个
完整路由、固定命令、数据量、次数和期限，随后明确确认。审核绑定两个真实会话、
当前选择 revision 和一次性请求身份。换 tab/pane、重连、关闭会话或修改相关
保存路线/信任会撤销审核、取消正在执行的请求并拒绝迟到结果。语言、主题、详情
开关不启动网络操作。中继链生命周期继续由现有连接所有者管理。

## 有界探测

默认三轮，每轮交替 A/B，下一轮反转先后顺序。每条路径测量三种固定操作：
SSH exec 往返、小块合成数据上传、同量下载。上传/下载每次 256 KiB，
两条路径合计 3 MiB 合成载荷；额外包括固定命令、确认和 SSH 协议开销。
只使用内存，不读取用户文件，不创建远端文件，不请求 PTY、sudo 或安装工具。
目标需显式可用的 POSIX/Python 3 环境；缺工具如实失败。

每个样本最多八秒，整次最多六十秒；固定远端程序另设八秒 alarm。
取消在 channel open 后、EXEC 前再次检查。channel 使用既有独立 owner，
取消/超时收取自身清理结果；无法证实已派发程序结束时保留未知，并撤销本面板
继续比较的权限，要求核对后重连。不能关闭不相关的跳板或兄弟连接来伪造清理成功。

成功样本必须有准确 stdout、无 stderr、明确 exit 0 和正常结束；多余数据、
截断、错误内容、拒绝、缺 exit、超时和取消均不能计为成功。保留按实际顺序的
原始样本、耗时、字节及失败原因；部分结果不生成完整优胜结论。

计时含 channel open、远端解释器/命令启动、传输和完成确认，不能称为 ICMP RTT
或裸链路带宽。只在全部样本成功时显示每路径各操作的中位数及实测差异；
没有样本、缺样本、相同耗时或不足以比较时明确显示数据不足，不补零或宣称加速。
结果留在本地内存，不发送 AI/遥测，不持久化或触发操作。

## 验证与交付

开发期间按必要边界编译/专项检查；集成后统一完整门禁、真实 OpenSSH 与网络实验。
受控 SSH fixture 覆盖真实路由身份、严格样本验证、取消/迟到和父连接存活。
用隔离 OpenSSH 中继服务与受控网络延迟/丢包做 A/B，记录网络条件、原始样本、
失败/未知和清理。没有真实损伤实验不得将 NET-03/M4 写为完整验收。

不按主题 ID 分支。GPUI 控制器、真实协议联调、正常程序构建和各平台桌面验收
分别记录。新非作者复核后只本地提交，并清理本批 agent/worktree/容器。
