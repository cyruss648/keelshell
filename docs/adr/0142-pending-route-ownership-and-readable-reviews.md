# ADR 0142：待完成路线的连接寿命与可读取的审核信息

- 日期：2026-11-16
- 状态：已实施，集中门禁与限定非作者复核通过
- 相关：[ADR 0141](0141-reviewed-ssh-path-comparison.md)、
  [本批记录](../testing/records/2026-11-16-native-network.md)

## 背景

真实 macOS 原生流程发现：跳板完成认证、目标仍等待用户输入时，
窗口的周期性 orphan 清理只从终端会话计算保留集合。
未完成路线尚未创建终端，其已认证上游被误关闭，
后续目标握手返回 `session is closed`。快速自动化认证可能绕过清理时间点，
所以既有完整路由用例未稳定揭示该问题。

另一个原生观察是主机指纹、变更提示、路径审核正文及比较结果虽已绘制，
但缺少明确的辅助功能角色与名称。按钮可操作不代表核对依据可被辅助技术读取。

## 决定

1. 活动终端与当前待完成路线的最近已认证上游共同作为连接保留根。
   对根继续沿现有 child → parent 依赖计算传递闭包，保留更早跳板。
   不通过“存在任意认证就禁止所有清理”扩大保留范围。
2. 路线取消、失败或成功移交到终端后，当前路线根自然消失。
   正常终端根与最后一个使用者释放的现有清理规则继续工作。
   不创建新认证、重试、共享其他窗口的句柄或延长授权。
3. 主机身份审核的标题、收到/先前指纹和核对提示使用明确 Label。
   当前连接步骤与展开路线使用带完整名称、账户、端口及显式代理的 Group 摘要。
   摘要不包括密码、私钥内容或凭据库主密码。
4. 路径比较的审核正文、状态、原始样本、失败原因与历史来源使用 Label，
   中位数使用命名 Group。可读文本与实际绘制文本共用同一字符串，
   不维护内容不同的第二套安全说明。

## 验证要求

用真实认证 peer，在目标凭据面板停留时显式运行生产清理函数，
验证上游继续保留、目标可完成握手、取消及关闭最后终端后全部连接退出。
两个分支都使用有界等待与隔离状态。
渲染测试核对中英文首用/变更指纹、同一段绘制文本与 AX 名称，
并保留三主题、窄窗口与审核操作固定区域的已有回归。
真实 macOS 使用最终包重新验证每跳身份、留停后认证及比较流程。

工程测试和 macOS AX 读取都不替代实际 VoiceOver、输入法、
Windows/Linux 原生桌面和签名发行验收。
