# 0145 — 原生文件列表的键盘工作流

日期：2026-11-16。状态：实现中，集成验证与非作者复核待完成。

文件浏览使用稳定路径保存选择、锚点和键盘游标。行号只表示当前排序后的显示位置，
不是文件身份。鼠标、方向键、Shift 范围选择和全选共用有界选择模型。
超过 32 项时整次拒绝，保留原选择、锚点与游标；不静默截断。

本地与远程列表分别持有原生焦点和滚动句柄。方向键、Page Up/Down、Home/End、
Space、Escape 和平台全选键只在列表本身聚焦时处理；子按钮、复选框、路径输入、
编辑器和终端保留自己的键盘路由。移动游标后按实际显示行滚动，使落点可见。
切换目录后清除选择并回到列表起点。

每次绘制捕获当前会话、实际连接、目录、完整条目元数据、排序与隐藏项偏好。
旧绘制回调拒绝不同的当前身份或列表，不能将旧行号解释为新目录中的文件。
暂停、卸载、审核、队列详情和编辑器视图分别保持原边界。
选择本身不发起传输；忙碌时仍可选择，但不由快捷键发起新文件操作。

Enter 打开远程目录或请求读取当前单选文件；脏草稿沿用放弃审核。
本地 Enter 只浏览普通目录或填写普通文件传输路径，保留原生 PathBuf；
非 UTF-8 值不通过 lossy 文本转换进入传输。链接和特殊对象不作为普通来源打开。
Backspace/Alt+Up 浏览已加载目录的上级，F5 刷新已加载目录，不使用未提交路径草稿。

远程 F2 展开现有文件操作区、填入单选名称并聚焦。仅此明确重命名意图允许名称框
Enter 提出精确原路径和新路径的审核；改选、路径编辑、失效身份或隐藏工具不能
继续旧意图。Delete 或 macOS Cmd+Backspace 同样只展开既有完整删除审核。
重复按键和审核正文 Enter 均不确认，远端修改仍由独立确认按钮发起。
多选不被默认为对第一项重命名或删除。本地栏继续只提供 SFTP 来源与目标选择。

列表提供 ListBox/选项角色、选择状态、活动后代和双语操作说明。文件底部状态与
当前位置使用实际完整文本作为辅助技术标签，不用截断显示文本代替。
霜白、曜石、雾紫复用 registry、Palette 和组件 token；新增主题无需业务分支。

纯模型、真实 GPUI 分发和受控 SSH/SFTP 分别核验；实际 macOS 输入、AX、窗口截图
及其他平台桌面继续单独验收。首次红例、fixture 修正、未知和未完成状态均保留，
不将编译或预构建测试执行签为完整原生体验。
