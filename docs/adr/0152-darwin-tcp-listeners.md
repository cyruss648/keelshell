# ADR 0152：远端 macOS 的只读 TCP 监听端口

日期：2026-11-17。状态：已实现；专项、独立复核、集中工程门禁与真实 SSH
通过，原生桌面与发行验收仍开放。

## 决策

扩展现有 `LinuxMonitor::listening_sockets`，通过固定平台选择保留 Linux 的
`ss` TCP/UDP 采集，新增 Darwin 的 TCP LISTEN 采集。公开类型名称保持兼容。
Darwin 使用远端已有 `/usr/sbin/lsof` 的机器字段输出，不依赖资源采集所需的
Python，不安装程序、不提权，不读取进程环境变量。

这一片只观察 TCP 监听端口。UDP、TCP 主动连接探测、进程身份核对和 SIGTERM
不因列表可读而获准；这些动作继续保留各自的 Linux 合同。已连接 TCP 端点不是
监听端口，不能通过字符串包含端口号把它混入列表。

## 数据与权限

采集和解析都保持有界，使用完整帧及真实退出状态；解析校验 NUL 分隔字段、
进程／文件边界、TCP 协议、LISTEN 状态、地址与数值端口。缺少必需字段、
重复／冲突字段、非法字符、超量、截断和失败响应不得成为可用空列表。
错误只保留固定原因，原始命令、进程名和远端诊断不进入错误文本。

列表只描述当前远端账户可见的数据。成功读取不证明全系统端口清单完整，
也不证明应用协议健康。空结果不表示“主机没有监听端口”。
工具缺失、权限或输出失败沿用连接内能力负缓存；显式重新检测才重新观察。
SSH 故障保持传输错误，不能误记为工具缺失。

## 界面

在原有端口按钮和列表内提供该能力。保留当前账户可见范围与 macOS 仅 TCP
的双语说明；能力名使用功能名称，避免固定写成 Linux 工具名。
三主题通过同一 registry、Palette 和 Kit 控件显示，主题或语言切换只重绘缓存。
Darwin 不显示 TCP 探测或进程终止按钮，操作分派也拒绝绕过界面的调用。

使用项目的 Hallmark 原生组件合同，不新增 Web 页面或 CSS；Web 渲染检查
不适用于此 Rust/GPUI 组件。实际原生观察与 headless 可达性分别记录。

## 验证

跨平台解析用例覆盖合法 IPv4／IPv6／wildcard、多个进程和描述符、空结果、
错误退出、警告、重复／缺失字段、非 LISTEN、截断和预算。
GPUI/SSH 夹具覆盖显式按钮、负缓存／重新检测、暂停／迟到结果及双语三主题。
真实本机 OpenSSH 测试只核对自有 IPv4／IPv6／mapped 监听对象，确认已连接的自有客户端
端点不出现在监听列表；不持久化整机端口或进程原始输出。
源码门禁、独立非作者复核、真实 SSH 和三平台桌面／发行分别验收。

真实工具会把 IPv4-mapped IPv6 描述符显示为无括号 IPv4 字面量。解析保留工具
观察的地址，不从描述符族猜造 IPv6；该行为有自有 listener 的 SSH 正例。
独立评审发现的缺帧空列表问题已经由公开 SSH 入口负例复现并修复：
Linux 与 Darwin 均要求明确 start／真实工具 status／end，裸输出不能成为可用空集合。
完整安静的 Darwin exit-1 与 Linux 成功空帧继续合法。

最终 724 输入上集中门禁为 `3272 passed / 0 failed / 51 ignored`，
app `1367/0/2`、14 rustdoc，26 新例逐名通过；真实 Darwin SSH `9/0/0`、
Linux Podman 恢复 `2/0/0`。两位非作者限定批准、原失败和清理边界见
[本批测试记录](../testing/records/2026-11-17-darwin-tcp-listeners.md)。

实现依据为 [lsof 官方手册](https://github.com/lsof-org/lsof/blob/master/Lsof.8)
中的 field output、TCP state selection 和退出状态约定，并核对本机已有工具行为。
