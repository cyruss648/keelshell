# ADR 0153：编辑器原始备份的完整读回

日期：2026-11-17。状态：已实现，宿主完整门禁和两位非作者复核通过；
原生桌面、精确三平台 CI 和发行分别验收，结果以本批测试记录为准。

## 决策

审核式编辑保存先复核原始 snapshot，在同目录原子发布原始字节备份，再完整
检查该备份。备份写入 ACK 之后，继续持有同一备份 mutation reservation，
沿用 checked regular-file reader 检查父链、普通文件类型、打开句柄前后和最终
leaf 元数据、精确大小、完整 EOF 与只读 CLOSE ACK。只有全部原始字节相等且
备份是私有 `0600` 普通文件，才进入原目标的审核式原子替换。

备份与目标继续顺序取得 reservation，避免嵌套抢占。备份读回不延长原有整个
备份操作的 deadline；完成后再执行目标原有的完整基线复核和发布流程。
读回前后检查当前授权；撤权、关闭、busy、UNKNOWN 和 quarantine 保留原有
类型与优先级。不重试未知写入，不自动清理未确认或验证失败的备份。

## 结果与界面

新增不可自动重试的 `SessionError::EditorBackupUnverified`：仅表示备份发布已
ACK、但其完整读回未通过，本次目标替换尚未发起。错误不包含远端内容、路径或
服务器诊断。目标未开始不代表独立远端写者没有修改文件。

app 将这一结果映射为独立双语状态，保留当前草稿、旧基线和远端备份，要求检查
后重新审核。目标已发布但完整读回失败继续沿用原状态，不能误报为“目标未发起”。
成功状态明确备份经过完整核验；完整目标读回仍是采用新保存基线的必要条件，
较新草稿不会被已审核版本的迟到结果覆盖。

紧凑状态行按主题 chrome 高度约束，保留完整 AX 名称；使用原生可悬停 tooltip
展开当前完整消息，允许指针移入、换行与有界滚动。已打开的详情随语言／主题
变化重绘，不发起网络请求。长消息不能把文件面板底部操作区撑出窗口。
复用现有 Hallmark 原生合同与三主题 registry，不新增字面颜色、字体或主题分支。

## 边界与验证

这是一轮有界的完整字节与元数据观察，不是版本历史、持续身份锁、远端 CAS、
自动恢复、事务回滚或崩溃耐久性承诺。观察结束后独立写者仍可更改备份或目标；
owner、ACL、特殊 mode 的保留不在合同内。

受控 TCP/SSH/SFTP 回归验证生产 public API 的完整读回顺序，以及损坏、截断、
缺失、链接、类型／大小／mode 缺失或变化、读错误、CLOSE 失败、超时、撤权、
UNKNOWN、共享隔离与目标二次复核。GPUI 动作验证取消、草稿保留、双语状态、
三主题明暗和目标发布后的错误分类。独立 OpenSSH 用例检查真实标准服务端上
Unicode、UTF-16、显式旧编码、空内容与连续保存的完整备份和目标字节。
这些证据与三平台 CI、正常包结构、原生桌面和发行分别验收。
