# ADR 0154：远端 macOS 的 UDP 端口与指定对端

日期：2026-11-17。状态：已实现；专项、真实 SSH、两位独立复核及集中工程门禁
及正常包结构通过；提交交付进行中，原生桌面与发行仍开放。

## 决策与依据

扩展现有端口读取，不新增公开 API、依赖、远端安装或授权动作。Darwin 使用固定
`/usr/sbin/lsof -nP -a -iTCP -sTCP:LISTEN -iUDP -F0pcftPnT -Ts`；
私有帧升为 `darwin-sockets:2`。Linux 的 `ss` 命令和帧保持原合同。
TCP 仍严格要求 LISTEN，已连接 TCP 客户端不属于该列表。

[lsof 上游手册](https://github.com/lsof-org/lsof/blob/master/Lsof.8)
说明同一选择集合内按 OR 合并，`-a` 对不同集合按 AND 筛选，Darwin 不提供
UDP 状态。本机实验仅选择实验进程的 PID，核对 TCP 监听／已连接客户端、
IPv4／IPv6 的 UDP 绑定、wildcard、指定对端和未绑定对象；组合命令实际保留
TCP LISTEN 与 UDP，排除 TCP 客户端。只保留这些自有对象的原件。

## 数据合同

- TCP 文件恰有 `f/t/P/n/T` 五个字段，`P=TCP`、`T=ST=LISTEN`。
- UDP 文件恰有 `f/t/P/n` 四个字段，`P=UDP`；不接受伪造或附带的状态字段。
- UDP 的数值本地地址／正端口产生 `BOUND`；`local->peer` 产生 `PEER`，
  两端都严格校验，指定对端不接受 wildcard。保留实际数字地址与 IPv6 scope。
- 合法族上的精确 `n*:*` 表示未绑定端口，正常过滤。仍须通过进程、描述符、
  字段完整性及全局预算；过滤不能掩盖畸形、重复或超量输出。
- `BOUND`／`PEER` 只描述观察到的端点形状，不是内核连接状态，不证明握手、
  可达性、远端身份、服务存活或应用协议健康。

完整帧、真实 SSH 退出、lsof 状态、stderr 和 2 MiB 输出预算仍严格校验。
最多 10,000 个描述符，包含被过滤的未绑定对象。不返回被截断的可用子集。
安静的 exit 1／空输出，以及成功输出中只有完整未绑定 UDP 的集合，可以是
可用空列表；不完整成功输出、警告或失败响应不能成为空列表。
权限和工具能力负缓存继续属于连接，显式重新检测后才重新观察；SSH 故障不
误记成缺少工具，旧报告与迟到结果继续失效。

## 原生界面与权限

沿用现有端口按钮和列表，标题与能力名改为“端口列表”。协议、端点与进程分层
显示，长端点及进程在完整 AX 名称中保留。UDP 状态用双语“已绑定”／
“已指定对端”，附账户可见范围及状态含义说明。未知或空结果不声称全主机完整。
三主题共用 registry、Palette 和 Kit 组件，不按主题 ID 分支。
列表按每页 12 项浏览，页码显示当前页、总页数和条目总数；翻页只读取缓存。
新列表或失败结果到达时夹紧页码，避免缩短后的列表停在不可见页。

Darwin 的 TCP 主动探测、进程核对和终止继续禁用；UDP 列表不授予这些动作。
主题、明暗和语言切换只重绘缓存，不执行新的 SSH 操作。
