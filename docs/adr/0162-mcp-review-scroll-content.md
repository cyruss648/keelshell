# ADR 0162 — MCP 审核正文与可见滚动入口

日期：2026-11-17。状态：实现、最终工程门禁与限定原生拖动通过；原生滚轮 P2 继续开放。
基线：`e394f6d16a448b7f8c3617451749d0d4ebc1b05a`。

## 触发与问题

准确基线的正常 macOS 包连接一次性 Podman OpenSSH，经原生界面显式授权后，
自有 stdio 客户端读取真实 UTF-8 文件并提交完整替换提案。提案没有写入，
但打开完整审核的按钮位于固定页脚下方，反复点击和滚轮没有让入口可达。
不能以 AX 中存在按钮或既有 headless 几何结果替代这次实际失败。

## 决定

将有界滚动视口与按自然高度排列的正文分开，并为授权／提案面板和完整文件
审核分别持有 ScrollHandle、显示 Kit 滚动条。用户可以直接拖动滑块进入后续
正文，不依赖滚轮才能找到审核入口。为滚动条预留正文内边距；头部和确认、
撤权、返回页脚保留独立固定区域。主面板返回后保留位置，打开另一份完整文件
审核从顶部开始。没有内容溢出时遵循 Kit 不绘制该轴的行为。

自然高度分离是布局约束，不作为已查明的原生根因。旧生产和仅分离正文的
首版在相同 headless 滚轮测试中均四项通过；首版正常包的原生滚轮复验仍未
移动正文。真实字体、AppKit 输入转换、帧调度等差异尚未隔离，精确原因继续
UNKNOWN。新增滚动条的原生拖动与原滚轮路径分别观察，不能相互代签。

保持既有主题 registry、语义 Palette、Kit 按钮、提案身份、路由、
完整 diff、两次审核及授权规则。滚动与主题切换不请求远端数据，
看到按钮不代表审核或执行已经发生。未知写入、隔离与关闭限制继续保持。

## 验证

补充生产 GPUI 渲染的坐标滚轮及滑块拖动回归，核对正文位移、页脚不动、
审核按钮滚动后可点击及完整文件审核可进入；覆盖双语、三推荐主题、两尺寸、
1／6／32 条待审提案和第 33 条 Busy。120 行替换正文必须实际溢出视口，
拖到末尾后 diff 底部必须进入视口；不能以条件跳过或仅发生位移代签完整可达。
headless 测试使用强制绘帧与测试字体，明确不证明原生事件或调度已经恢复。
原生失败原图、撤权后的客户端断开、原应用正常退出及所有资源清理保留。
修订正常包实际拖动主面板和完整 diff 滚动条后，已审核一次性 SFTP 文件、
独立读回全部 6628 字节相等，并通过原生入口拒绝另一项命令提案。
原生滚轮仍未观察到正文位移，根因 UNKNOWN；限定通过显式拖动路径，
紧凑原生窗口和其他平台保持未验。
