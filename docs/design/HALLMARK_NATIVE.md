## 设计基线

受众为远程主机管理的开发与运维人员。主要任务是查看状态、准备操作、审核准确目标和内容，然后执行。风格为克制、紧凑、可追踪的工具界面。

- 颜色使用 `crates/keelshell-app/src/design.rs` 的语义 Palette，经 GPUI Theme 安装；字体继承同一个 Kit Theme。终端 ANSI 内容单独管理。
- 三套主题各自提供 System/Light/Dark 和中英文，详见 [原生主题设计](NATIVE_THEMES.md)。状态使用明确文字，不能只靠颜色或装饰圆点。
- 数据使用列表、表格和有标签的值。来源与技术身份放在明确的详情披露中，避免用多个中点串联元数据。
- 使用真实数据和真实空状态。没有来源的指标、客户引言、图标墙或示例在线主机均不进入产品。
- 审核正文独立滚动；确认/取消固定可达。删除有明确确认。危险动作绑定实际审核身份，不只依赖按钮外观或禁用状态。
- 原生焦点、键盘、悬停、按下、禁用、忙碌、成功、失败分别核验。默认不添加装饰性动画。
- 空列表说明应如何产生内容；失败显示下一步；读取或写入期间显示真实忙碌状态。未实现的后端流程不得显示成功。

## Native mapping

Hallmark 的 HTML/CSS 规则在本项目映射到原生实现：

| Hallmark 检查意图 | GPUI 对应实现与验证 |
| --- | --- |
| `:root` / theme tokens | `design.rs` Palette 与 GPUI Theme；组件不散布字面颜色或自建字体 |
| `:focus-visible` / disabled | Kit focus handle、键盘焦点与控件 disabled；原生截图/AX 及指针/键盘回归 |
| 页面横向溢出与伸缩 | `min_w_0`、有界面板、独立滚动区域；900×580 和默认窗口检查 |
| reduced motion | 本轮无新增动画；将来动画需实现原生减少动态效果策略 |
| URL state | 原生实体保留查询、选择、草稿和导航状态，不引入无用途 URL |
| CSS stamp / design log | `.hallmark/preflight.json`、`.hallmark/log.json` 与本文件记录来源和设计决定 |
| 浏览器截图与 render lint | 工具若不支持 Rust，记录 `not_applicable`；GPUI 测试和实际原生捕获另行执行，不能记作浏览器 render 通过 |

用户已将功能和 UI 设计交由本轮实现自主决定，因此材料、受众、用途和风格按现有产品推断；不重复索取设计许可。所有图片证据必须来自实际应用运行，不用网页或生成图冒充原生产品。
