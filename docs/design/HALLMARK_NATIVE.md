# Hallmark 与原生 GPUI 界面

2026-11-04 起，用户要求使用 Hallmark 管理界面设计。本项目仍是原生 GPUI Kit 应用；设计采用 Hallmark 的 app screen 分支，沿用导航、事件和审核规则，并为本轮三主题建立统一目录与语义 token。

## 设计基线

受众为远程主机管理的开发与运维人员。主要任务是查看状态、准备操作、审核准确目标和内容，然后执行。风格为克制、紧凑、可追踪的工具界面。

- 颜色使用 `crates/keelshell-app/src/design.rs` 的语义 Palette，经 GPUI Theme 安装；字体继承同一个 Kit Theme。终端 ANSI 内容单独管理。
- 三套主题各自提供 System/Light/Dark 和中英文，详见 [原生主题设计](NATIVE_THEMES.md)。状态使用明确文字，不能只靠颜色或装饰圆点。
- 数据使用列表、表格和有标签的值。来源与技术身份放在明确的详情披露中，避免用多个中点串联元数据。
- 使用真实数据和真实空状态。没有来源的指标、客户引言、图标墙或示例在线主机均不进入产品。
- 审核正文独立滚动；确认/取消固定可达。删除有明确确认。危险动作绑定实际审核身份，不只依赖按钮外观或禁用状态。
- 原生焦点、键盘、悬停、按下、禁用、忙碌、成功、失败分别核验。默认不添加装饰性动画。
- 空列表说明应如何产生内容；失败显示下一步；读取或写入期间显示真实忙碌状态。未实现的后端流程不得显示成功。

## Native mapping

Hallmark 的 HTML/CSS 规则在本项目映射到原生实现：

| Hallmark 检查意图 | GPUI 对应实现与验证 |
| --- | --- |
| `:root` / theme tokens | `design.rs` Palette 与 GPUI Theme；组件不散布字面颜色或自建字体 |
| `:focus-visible` / disabled | Kit focus handle、键盘焦点与控件 disabled；原生截图/AX 及指针/键盘回归 |
| 页面横向溢出与伸缩 | `min_w_0`、有界面板、独立滚动区域；900×580 和默认窗口检查 |
| reduced motion | 本轮无新增动画；将来动画需实现原生减少动态效果策略 |
| URL state | 原生实体保留查询、选择、草稿和导航状态，不引入无用途 URL |
| CSS stamp / design log | `.hallmark/preflight.json`、`.hallmark/log.json` 与本文件记录来源和设计决定 |
| 浏览器截图与 render lint | 工具若不支持 Rust，记录 `not_applicable`；GPUI 测试和实际原生捕获另行执行，不能记作浏览器 render 通过 |

用户已将功能和 UI 设计交由本轮实现自主决定，因此材料、受众、用途和风格按现有产品推断；不重复索取设计许可。所有图片证据必须来自实际应用运行，不用网页或生成图冒充原生产品。

## 本轮屏幕

文件工作区：本地/远程路径各占独立行；常用选择、传输、队列入口常驻，
文件名称/权限和传输路径/目录比较设置互斥展开。默认空间用于真实文件列表，
审核和已断开的快照采用紧凑路径；已有编辑、比较、冲突和传输结果不会因折叠消失。
隐藏输入的焦点回到可见入口或惰性文件面板。生产与测试共用面板高度计算，
三主题仍使用同一布局和语义组件 token。
见[文件工作区设计](../adr/0097-file-workbench-disclosures.md)及[按包记录](../testing/records/2026-11-05-native-file-workbench.md)。

工作区：顶部全局操作与中央会话栏分层；左侧提供真实保存连接和主机信息，
中央保留终端、准确命令目标与多行草稿。窄窗口中的导航/AI 互相让出空间，
隐藏后保留实体和草稿。搜索无匹配时显示明确空状态，不增加虚构在线主机。
弹窗期间隐藏的导航不能接收返回焦点或让后续按键进入终端。
工具页和侧栏同时呈现视觉选择及 AX toggle 状态。
见[工作区设计](../adr/0096-native-workbench-navigation.md)及[按包区分的验证记录](../testing/records/2026-11-05-native-workbench.md)。

知识库：本地搜索列表 → 条目编辑 → 完整原/新摘要审核。固定底部操作；默认只显示来源名称、捕获时间和确认结果，其他来源身份可展开。空、准备、保存、失败待重载和成功状态均与实际存储操作对应。

知识上下文：在已有条目旁逐条加入或移出 Ask，返回助手后显示标题、历史来源、
日期和原结果。选择、问题、完整请求与确认发送保持明确层次；浏览和选择不产生
网络请求。确认栏沿用现有固定区域，完整 JSON 独立滚动。移除、编辑或重新加载
会撤销旧预览；仍可恢复已知凭据的请求拒绝准备，不用成功外观掩盖拒绝状态。
三套主题复用现有语义 token，见[使用说明](../product/AI_KNOWLEDGE_CONTEXT.md)
与[验证记录](../testing/records/2026-11-05-ai-knowledge-context.md)。

隧道：规则列表 → 绑定连接与端点的编辑/删除/停止审核。活动运行与保存规则分别显示，不把修改配置等同于运行中隧道已变更。

本文件定义设计方向，不声称已完成全应用或三平台原生验收。每次交付仍需按测试记录列出实际覆盖与缺口。
