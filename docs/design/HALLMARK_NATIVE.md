## 设计基线

受众为远程主机管理的开发与运维人员。主要任务是查看状态、准备操作、审核准确目标和内容，然后执行。风格为克制、紧凑、可追踪的工具界面。

- 颜色使用 `crates/keelshell-app/src/design.rs` 的语义 Palette，经 GPUI Theme 安装；字体继承同一个 Kit Theme。终端 ANSI 内容单独管理。
- 三套主题各自提供 System/Light/Dark 和中英文，详见 [原生主题设计](NATIVE_THEMES.md)。状态使用明确文字，不能只靠颜色或装饰圆点。
- 数据使用列表、表格和有标签的值。来源与技术身份放在明确的详情披露中，避免用多个中点串联元数据。
- 使用真实数据和真实空状态。没有来源的指标、客户引言、图标墙或示例在线主机均不进入产品。
- 审核正文独立滚动；确认/取消固定可达。删除有明确确认。危险动作绑定实际审核身份，不只依赖按钮外观或禁用状态。
- 原生焦点、键盘、悬停、按下、禁用、忙碌、成功、失败分别核验。默认不添加装饰性动画。
- 空列表说明应如何产生内容；失败显示下一步；读取或写入期间显示真实忙碌状态。未实现的后端流程不得显示成功。

连接、会话、终端、审核输入和工具区。

本轮实现和验证见 [ADR 0115](../adr/0115-workbench-visual-rhythm-and-context.md)
及 [测试记录](../testing/records/2026-11-07-workbench-visual-refinement.md)。

## 2026-11-07 终端 pane 连接身份

所有终端 pane 现在都保留一行紧凑 header：左侧是会话标签，右侧是来自
Workspace 快照的真实用户、主机和端口，下面以独立文字表示 `SSH / UTF-8`，
状态使用同时具备文字和语义色的 badge。单 pane 与分屏 pane 使用同一组件路径，
恢复占位使用当前 profile 或明确的缺失状态；未保存连接与已移除配置分别显示，
避免把两种不可连接原因压成同一个警告状态。

该身份栏不把连接状态写入 `TerminalView`，不改变 SSH 输入焦点、命令审核目标、
AI 权限或传输线程。布局和 AX 标签使用 `ChromeTokens::pane_header_height`、
Palette 状态色、边框和组件圆角 token；端点代码字体使用主题
`TypographyTokens`。Frost、Graphite、Lavender 共享视图实现，新增主题只需要
扩展 registry、Palette、组件、chrome 和 typography token。

定向验证见 [ADR 0116](../adr/0116-pane-connection-identity-bar.md) 和
[测试记录](../testing/records/2026-11-07-pane-connection-identity-bar.md)。当前
工程门禁已通过，旧提交的只读报告已指导并关闭身份栏点击区域、恢复状态、字体
字面量和缺失档案语义问题。macOS 原生包已实际观察三套主题、双语、横/纵分屏、
合并保留会话、关闭面板、真实回环 SSH、断开状态和重新认证恢复；900×580 因
无边框窗口 accessibility frame 异常保持未验收。当前候选仍需最新提交的独立
非作者复核，以及 Windows/Linux、IME、VoiceOver 和完整键盘矩阵验收。
