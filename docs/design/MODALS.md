# 模态与键盘范围

实现状态：单个活动子树与保留焦点已接入，原生辅助技术矩阵及独立复核仍待完成。
设计决定见 [ADR0047](../adr/0047-single-active-modal-and-retained-focus.md)，
验证进度见 [测试记录](../testing/records/2026-10-05-modal-isolation.md)。

## 交互约定

- 一个时刻只挂载最上层任务。主题画布衬托居中的真实任务面板，当前目标与路线信息来自该面板，不显示可操作的背景或复制截图。
- 当前层有自己的标题、跟随系统/浅色/深色与语言控件，全部在同一焦点范围内。34px 控件栏下保留面板的滚动内容与固定关闭/确认区域；保存中及凭据库操作中禁用偏好修改。
- Tab 与 Shift-Tab 只在当前任务中循环。Escape 与关闭快捷键只关闭当前层，保存中的禁用规则继续生效。
- 子层关闭后回到父层的触发位置；父层关闭后回到工作区的触发位置。已删除的目标使用当前可操作焦点作为后备。
- 认证、主机指纹及 MFA 异步出现时优先于草稿层，关闭沿用现有的取消与秘密清理规则。普通 SSH 握手进度为非模态状态卡，不阻塞其它会话。
- 主题、语言和后台事件只更新保留的实体。隐藏并重开不重建连接草稿、AI配置实体、命令任务或 SSH 句柄。
- 对话框角色与视觉遮罩不是 AX 隔离证据。背景不进入当前布局、事件与辅助技术子树才是本实现的实际边界。
- 异步认证出现但尚未绘制时，窗口的原始鼠标捕获先于子控件处理，并绑定已绘制层及挑战身份；旧画面的按下/释放不能取消下层草稿或响应新的同类型挑战。此原始事件回归与原生 AX 激活分别验收。

## 原生验收脚本

在绑定最终源码和二进制摘要的隔离开发包上操作，不连接客户机器。
分别使用中文/英文、Light/Dark、900×580 与默认窗口。检查当前层自有外观控件可达，背景同名入口不可达；关闭/确认区域不随内容滚出窗口：

1. 工作区 → 连接管理器：原生 AX 中有当前命名 Dialog，工作区快速连接、新建会话、AI和MCP入口不应出现；连续 Tab/Shift-Tab 绕过首尾仍停留在管理器。
2. 用键盘选择“新建连接”并 Enter：AX 中只剩连接编辑器，管理器关闭及连接行操作不应出现；输入未保存中英文草稿。
3. 打开“选择目标文件夹”：AX 中只剩文件夹选择，连接保存/取消不可导航或激活；Escape 返回相同文件夹触发控件，连接草稿保留。
4. Escape 返回管理器的“新建连接”；再 Escape 返回根连接入口。重复指针关闭路径，确认当前任务关闭而下一层保持。
5. 模态中调用全局连接管理和AI快捷键：当前任务与草稿保持，后台SSH标签不被关闭。关闭快捷键只处理当前层。
6. 自有SSH夹具产生凭据/指纹/MFA挑战：最高层只包含挑战与必要路线信息；取消清理临时响应，回到原草稿与合理焦点。接收挑战期间切换系统外观，不丢内容。
7. 关于更新、凭据库、AI配置、MCP、批量任务、依赖工作流、导入、片段与归档确认逐项重复范围与关闭检查；任务进行中关闭/重开遵循各面板原有后台行为，不重新执行。

原生AX树删除、实际屏幕阅读器导航与滞留旧节点的激活尝试分别记录。
GPUI测试通过不能代替这些结果；没有本机环境的平台继续保持未验收。
