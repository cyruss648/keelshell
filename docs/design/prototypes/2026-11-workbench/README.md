# KeelShell 三主题交互原型

用户已接受全部三套主题；这些页面保留设计探索与布局参考，不再要求用户从中只选一套。

- [霜白 Frost](a-frost/index.html)：冷灰蓝、轻边框和清晰层次。
- [曜石 Graphite](b-graphite/index.html)：暖石墨、琥珀提示和紧凑轮廓。
- [雾紫 Lavender](c-lavender/index.html)：低饱和紫灰、柔和圆角和面板分区。

直接打开 HTML，或从本目录启动仅绑定 loopback 的静态服务即可预览。三个页面共用 `workbench.js` 与 `workbench.css`，各自的 token/base 文件保留原设计方向。无脚本时仍有主题导航和静态截图。

所有连接、文件、监控数值、终端输出和 AI 回答均为明确标注的示例。交互只改变本页显示和草稿，不产生 SSH、上传、命令执行或模型请求。

原生主题已使用统一目录、语义配色和组件形状实现，见[原生主题设计](../../NATIVE_THEMES.md)。主题不规定工作区几何；HTML 的连接导航、文件工具区和 AI 面板布局仍需独立迁入原生并验收。这里的 PNG 不能证明原生应用效果。

本轮最终浏览器覆盖 A/B/C 的 1440×900、900×580，以及 A 的 375×844，未出现文档横向溢出；关键选择、目录清空和专注模式恢复已实际操作。独立源码复核无确认 P0/P1/P2，详见[测试记录](../../../testing/records/2026-11-04-native-themes.md)。
