# AI 命令片段

AI 助手回复中的 shell 建议可以在人工审核后保存为本地可复用命令片段。这个入口适合
把一次排查中已经核对过的命令整理成以后可以再次检查的模板。

## 用户流程

1. 在当前 SSH 会话中明确捕获上下文，并完成 AI 请求预览与发送审核。
2. 在回复中的命令建议或诊断计划步骤上点击“保存为命令片段”。
3. 在既有片段编辑器中检查并编辑名称、说明、标签、命令和显式参数模式。
4. 编辑器显示原始 SSH 目标和会话。命令发生修改时，编辑器显示原审核只覆盖原始命令，
   使用前需要重新审核。
5. 点击“保存片段”后，片段写入既有本地命令库。保存不会填入命令栏、发送终端输入或
   执行命令；以后从命令库使用时仍经过命令栏的目标和命令审核。

## 来源和失败反馈

保存草稿携带原始命令、目标、会话、非空 review ID 和单调审核时间。审核来源有效期为
120 秒。保存边界会再次检查来源和当前活动终端，以下情况会显示原因并保留草稿：

- AI 命令为空或含危险控制字符；
- 目标主机或会话缺失、含控制字符或 review ID 无效；
- 审核已经过期；
- 原始会话已经结束，或当前活动会话/目标已经改变；
- 片段 ID 重复，或片段模型的名称、说明、标签、命令和参数校验失败。

编辑器的失败状态可恢复，StateStore 只在完整候选通过既有 `AppState` 校验后写入。
重复 ID、空命令和危险控制字符不会产生部分写入。

## 视觉和平台边界

来源横幅和命令预览复用现有 snippet editor、命令库、主题语义色和 typography token。
本片不增加主题系统分支，也不把 AI 审核来源加入持久化状态格式。

GPUI 集成回归覆盖按钮可见、原始目标/会话展示、修改命令后的重新审核提示、stale
会话阻止保存、草稿保留、重复 ID 反馈和终端无写入。该证据属于本地 headless UI 与
StateStore 边界；原生多平台窗口、输入法、VoiceOver、真实 provider、真实 SSH 和
客户机器验收仍需单独记录。
