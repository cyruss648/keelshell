# AI API 请求选项

每个命名 API 配置可以独立设置自定义请求头和显式代理。发现模型、固定连接测试与审核后提问使用同一套选项；编辑配置不会自动联网。

## 请求头

在 AI 设置中添加请求头，填写名称，再选择值的来源：

- 临时值：密码输入只保留在本次程序运行；配置保存一个无值 UUID。重启后需要重新输入。
- 环境引用：填写环境变量名称，不填写值。明确点击发现、测试或预览时读取该变量；缺失、非 Unicode、控制字符或越界会拒绝请求。
- 凭据库引用：使用“加密保存”保存当前值，再应用配置；以后需显式“解锁”。也可关联已有 UUID，只有相同用途和目的地的条目能解锁。

保留的认证、协议版本、HTTP framing 和路由头不可自定义。请求头最多 32 条，名称忽略大小写唯一；值最多 8 KiB，全部名称和值最多 64 KiB。缺失值不被静默省略。

自定义头名称也必须通过已知秘密检查，包括 HTTP 名称大小写规范化后的匹配。认证、代理、请求头值和仍保留草稿的已知值不能嵌入名称；发现、测试和上下文批准在网络请求前拒绝这类名称。显式批准的头值和认证值仍按原用途交付，秘密集合不会被转换成投递权限。

应用配置前还会检查将保存的配置文字，避免已知秘密被写入头名称、model、endpoint、代理地址等元数据。实际写入入口对同一快照再次检查，拒绝时保留当前输入、不写配置，错误消息不回显匹配值。保存期间的新输入继续留在草稿里，迟到回执不会恢复旧值。

改名、换来源或删除请求头会清除原临时值。修改已解锁值会解除旧凭据库关联；需要再次加密保存才能将新值写入凭据库。换服务地址、协议或后端会清除旧目的地秘密。

## 代理

默认“直连”忽略系统环境代理。选择“显式代理”后输入 HTTP、HTTPS、SOCKS5 或 SOCKS5h origin，如 `http://proxy.example:8080`。地址不能包含用户密码、路径、查询或 fragment。代理失败、认证失败和重定向都不会自动直连或重试。

可选择匿名代理，或显式开启代理认证。临时/凭据库认证使用独立用户名和密码控件；环境引用要求变量值为仅含 `username`、`password` 的 JSON 对象，两字段均必填。用户名不能含冒号；用户名和密码各最多 255 UTF-8 字节。SOCKS5 在本机解析目标 DNS；SOCKS5h 由代理解析。HTTPS 代理要求可验证的 TLS 证书。

请求预览显示真正的目的地、路由、头名称与来源、是否有代理认证及脱敏后的正文。发送使用这一快照；预览后环境变量改变不会改变这一次已审核请求。任何配置或已知进程秘密变化会撤销审核，必须重新预览。

## 支持边界

自定义头与代理只供 API 后端使用。LocalAgent 不会借用这些选项；非默认 reasoning 设置仍不支持并会阻止请求。发现和测试无终端上下文，测试只发送固定提示；提问的上下文仍由用户显式选择，模型输出不能自动执行动作。

无效草稿保留在设置界面，切换配置、语言、主题和保存回执都不会抹掉输入；必须修正才能应用或请求。秘密值及代理的裸 Basic / `Basic ` 派生形式不写配置元数据、日志或变更记录；已知全配置凭据用于上下文、审核与回复脱敏，包括非当前配置。路由是用户主动配置的，程序不会上传配置或启用遥测。

发现、分页、固定连接测试与审核后的提问共用已知全配置秘密边界：已知秘密不能被服务端返回为可选 model ID 或分页游标，也不能作为手填 model/endpoint 发出。该快照只用于拒绝与脱敏，不会自动向当前服务发送其它配置的认证信息。修改秘密会撤销旧请求和审核；敏感 ID 在目录解析和入网前检查，不依赖界面完成后的过滤。此承诺限于程序当前已知的值，无法发现未知或任意混淆的凭据。

仍保留在密码控件中的值也属于已知秘密，包括无效、空名称、重复名称或引用校验失败的请求头，以及不完整或无效代理的原始字段。这些草稿独立于允许投递的用途绑定；其它配置的上下文、回复、目录和请求输入仍检查它们。清空、删除或改变用途/目的地释放对应值；取消一次请求或切换配置不会清空草稿。合法的有界代理字段还保留裸 Basic 与 `Basic ` 两种派生形式用于拒绝和脱敏。

已知值按内容去重后形成有界审核快照，最多 4096 项、每项 1 MiB、合计 8 MiB。超界会拒绝新的发现、测试或审核，不通过截断或省略草稿继续发送，也不会为满足预算悄悄清除输入。
