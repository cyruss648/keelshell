# 快速操作中心

## 目标

快速操作中心为远程工作台提供一个统一的键盘入口。用户可以用
`Command/Ctrl + K` 搜索当前可用的连接、会话、分屏、工具面板、AI 和设置动作，
再用方向键与 Enter 触发已有的显式 UI 流程。

它只负责发现和选择动作，不直接连接 SSH、发送命令、修改文件、调用模型或写入
配置。每个动作继续进入现有的连接审核、目标审核、AI 审核或设置面板。

## 动作目录

动作目录使用稳定的注册顺序，并为每项提供：

- 中英文标题；
- 一句中英文说明；
- 搜索关键词；
- 可选快捷键提示；
- 是否需要已打开的 SSH 会话；
- 是否需要当前工作区存在可用会话；
- 是否存在可用的前一个或后一个会话标签。

当前实现覆盖：

- 连接管理器和一次性快速连接表单；快速连接成功后不会自动写入连接库，
  用户仍可在表单中明确选择保存为连接配置；
- 上一个/下一个会话；
- 文件、命令片段、批量命令、依赖工作流、主机监控和隧道面板；
- AI 助手和 AI 配置；
- 主题与外观、凭据库和更新。

新建窗口、分屏和布局保存会继续沿用现有工具栏入口，后续加入动作目录时只需
扩展纯动作注册和 Workspace 映射，不改变搜索、主题或模态焦点机制。

动作执行由 Workspace 统一映射到现有方法。动作目录不保存 `Window`、SSH
session、凭据、Entity 或异步任务，避免把 UI 搜索状态变成远端权限。

## 搜索与上下文

空查询显示有限的高频动作。非空查询按以下顺序排序：

1. 标题前缀匹配；
2. 标题包含匹配；
3. 关键词或说明包含匹配。

同一等级保持注册顺序，结果数量有上限。搜索同时接受中文、英文和快捷键文本。
没有 SSH 会话时，要求会话的动作不会显示；连接管理器、快速连接、主题、设置和
AI 配置仍可用。上一个/下一个会话只在对应方向确实存在会话标签时显示，避免执行
后没有效果的动作进入结果列表。

## 交互

- 打开后输入框获得焦点，结果列表与输入框属于同一键盘焦点范围；
- `ArrowUp` / `ArrowDown` 移动选择，`Enter` 触发当前动作，`Escape` 关闭并恢复
  打开前的焦点；
- 鼠标点击结果与 Enter 使用同一执行路径；
- 不满足会话条件的动作不会出现在结果中；
- 选择变化同时更新 `aria-selected`、位置/数量和活动后代语义；
- 中英文切换实时更新标题、说明、占位符、辅助标签和快捷键提示；
- 900×580 及更窄窗口保持输入框、至少一项结果和取消入口可见，结果区独立滚动。

## 视觉约束

快速操作中心使用当前主题的语义 `canvas`、`surface`、`border`、`accent`、
`selected` 和 `muted` token。三套内置主题 Frost「霜白」、Graphite「曜石」、
Lavender「雾紫」共用同一结构；新增主题只补充 registry 和 token 定义。

弹层采用单层面板、清晰的结果层级和轻量选中边界。动作图标只表达类别，不用图标
代替标题。搜索结果保持紧凑信息密度，避免把连接端点、认证信息或远程输出放进
动作目录。

## 验收

源码验收至少覆盖：

- 中英文空查询与关键词查询；
- 前缀优先、注册顺序稳定、结果数量上限；
- 无会话/有会话上下文过滤；
- Command/Ctrl+K 打开、上下键选择、Enter 执行、Escape 关闭；
- 鼠标与键盘触发同一动作；
- 快速连接进入一次性连接模态，主机监控切换到 Monitor 导航面板；
- 首个、末个和唯一会话的方向动作边界过滤；
- 三主题、明暗模式、900×580 布局和辅助标签；
- 打开快速操作中心不会产生网络、SSH、AI provider 或持久化副作用。
