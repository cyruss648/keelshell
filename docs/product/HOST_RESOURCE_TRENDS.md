# 主机资源短期趋势

状态：2026-11-06源码与专项已完成，530输入组合门禁通过；
新包已有16轮真实Linux采样及暂停/恢复断段的单窗原生观察，
原件与限定复核见[原生记录](../testing/records/2026-11-06-resource-knowledge-native.md)，不继承旧包捕获。

主机信息的资源区增加CPU和内存趋势，帮助判断瞬时尖峰及持续压力。
它复用当前已认证Linux SSH会话的资源采样，不增加远端探测命令或轮询频率。
当前数值、样本年龄、暂停和刷新操作仍使用同一份真实数据。

## 显示与操作

- 两条紧凑趋势共用最近五分钟的时间范围，每条保留当前值和单位。
  使用既有主题的画布、文字、边框和强调色，三家族及明暗模式共用组件。
- 最多保留60个有效时间位置，手动刷新同样受数量和时间上限约束。
  横轴使用真实采样时间，不能把不规则刷新画成等间距。
- CPU第一份累计计数没有可用速率，不显示伪造的零值。
  真正的零负载、未知值和数据不足具有不同的文本与图形状态。
- 暂停、采样错误、重启、计数回退或时间异常使趋势断段；
  恢复后只使用新采样，不重复旧值或跨断段连线。
- 趋势及文本说明应在紧凑窗口中可查看，刷新与暂停按钮保留清晰的键盘焦点。
  图形不能作为唯一的信息通道。

历史只在对应面板和会话的内存中存在。重连创建新序列；旧会话的迟到结果
不能追加到新序列。切换主题、语言或重新绘制只改变显示，不增加SSH执行。
本切片不提供历史持久化、告警、网络/磁盘趋势或新的远端操作系统适配。

## 验收

确定性模型测试覆盖时间/数量淘汰、首样本、零值/缺失、无效数值及断段；
GPUI与回环夹具覆盖暂停/恢复、错误、迟到、重连和绘制不新增执行。
三主题、明暗、中英文、900×580与宽窗口分别检查布局及文本。
源码门禁和真实开发包的自有Linux SSH采样观察分别记录，不能互相代签。
