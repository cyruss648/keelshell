# 本地智能体问答

KeelShell 的 AI 配置提供模型 API、Codex CLI 和 Claude Code 三种调用方式。本地 CLI 由后台启动，用于解释你明确提供的远程上下文和生成待审核建议；它仍会向配置的推理服务发送请求。

## 配置与使用

1. 打开 **AI 助手 → 配置**，新建或选择命名配置，选择 **Codex CLI** 或 **Claude Code**。
2. 填入已经安装的原生可执行文件绝对路径、推理服务基础地址、显式 API 密钥与模型 ID。Codex 使用 Responses 基础地址，Claude 使用 Anthropic Messages 基础地址；CLI 配置的地址不需要追加完整请求路径。只接受 HTTPS 或本机回环 HTTP。
3. 密钥来源可选择 **输入 / 加密凭据库** 或 **环境变量引用**。后者只保存变量名，点击 **读取到临时密钥** 才读取当前应用进程环境；成功后点击应用。值只在内存中保持，启动、检查 CLI、预览和发送不会自动读取；环境改变后需显式重新读取。变量未设置、非 Unicode、空值、超过 8192 UTF-8 字节或含控制字符时失败且撤销旧发送值。改变来源、变量名、地址或执行路径后需重新读取。
4. 设置等待时限、回答上限和累计输出上限，再点击 **检查 CLI** 核对版本和能力，最后点击 **应用**。检查前会核对全部配置及保留草稿中的已知秘密；已经撤销发送资格的导入值也继续受到保护。检测到秘密或秘密集合超限时拒绝检查，不创建探针任务或进程。合法检查允许尚未填写模型，只运行版本/能力探针，不读取环境引用、不请求模型；它也不表示密钥或模型服务已通过验证。应用前仍需修正全部配置的结构和参数。
5. 在助手中选择配置，主动选择远程终端上下文并填写问题。点击 **预览请求**，检查执行文件、服务地址、模型、隔离策略和完整 stdin，滚动至 **确认发送此请求** 后发送。
6. 发送后可查看固定的 **请求进度** 和可展开的 **事实记录**；取消按钮保持可达。答复中的命令只能送入命令审阅区。确认精确命令和 SSH 目标后，再单独执行。**取消请求** 立即撤销界面等待和旧审核，并请求后台停止及清理；提示不代表后台已清理完成，已经发出的内容可能已被服务处理。

密钥默认仅在当前应用进程内存中存在；重启后需要重新输入或显式解锁。可使用已有主密码加密凭据库保存密钥，配置文件仅存引用。改变调用方式、可执行路径、地址或认证会清除原绑定；改变问题、上下文或配置（包括预算）会撤销旧审核并取消在途请求。预算调整不会改变密钥接收方，原加密密钥仍可解锁；切换 CLI 类型或路径仍要求重新绑定。

## 单次 Ask 限制

| 设置 | 默认 | 范围 |
| --- | --- | --- |
| 等待时限 | 120 秒 | 1–300 秒 |
| 回答上限 | 1024 KiB | 1–1024 KiB |
| 累计输出上限 | 2048 KiB | 1–8192 KiB，至少覆盖回答上限 |

三个字段都必须是整数。1 KiB = 1024 字节，按 UTF-8 字节计算，不是 Token 数。等待时限包括发送前的 CLI 版本与能力检查；累计输出统计推理进程的协议输出和诊断字节，诊断内容不会显示。协议也占空间，所以将回答和累计输出设为相同数值不能保证达到回答上限的内容通过。超过时限或任一输出上界都会停止本地请求并清理自有进程；超限回答不会截断后标为成功。已经发送的内容可能仍由服务处理。

无效输入保留在该配置的草稿中，切换配置和语言不会丢失；修正所有配置后才能应用。发送审核展示实际使用的预算，编辑预算会撤销旧审核。旧本地配置没有预算字段时保持上述默认，不在读取时重写；模型 API 配置继续使用自身的 Token 和请求限制。

手动 **检查 CLI** 保留独立 10 秒时限与每个探针 64 KiB 输出限制；它不发送模型请求，不使用 Ask 的累计输出预算。协议行与事件数量仍有固定内部上界。实现及本轮测试边界见[ADR0048](../adr/0048-configurable-local-ask-limits.md)和[预算测试记录](../testing/records/2026-10-05-local-agent-limits.md)。

## 请求进度

进度只显示本次 Ask 实际发生的有限事实：创建隔离工作区、检查并准入 CLI、启动进程、完整写入并关闭审核输入、验证协议开始/结束回执和进入收尾。它不显示供应商原始事件、工具调用或部分回答，也不是百分比。并发读取、写入和退出可能使事实交错；结束回执仍须等待后续协议、退出和清理检查，收尾提示也不表示已清理完成。

只有最终检查成功才显示完整答复与待审命令。更换问题、配置、上下文或 SSH 会话，以及取消，会撤销旧请求的界面所有权；面板实体的最后拥有者释放时会请求后台取消。隐藏助手会保留当前请求，如需停止请点击取消。旧事实或回复不会覆盖新请求。记录最多八条，默认折叠，展开后可独立滚动；切换语言和明暗主题保留同一请求的事实。实现与验证范围见[ADR0052](../adr/0052-observed-local-ask-lifecycle.md)和[进度测试记录](../testing/records/2026-10-06-local-ask-stages.md)。新版真实Codex/自有SSE的中文浅色窗口已完成限定等待、取消及新请求审阅；最小窗口、完整矩阵与其他平台仍待验收，见[部分原生记录](../testing/records/2026-10-06-local-ask-progress-native.md)。历史 Ask 验收不覆盖此界面。

## 当前支持边界

已核对 Codex CLI `0.160.0` 和 Claude Code `2.1.285`，其他版本在重新核对之前会拒绝运行。Windows `.cmd` / `.bat` 启动器不支持，应选择原生可执行文件。普通测试无需安装供应商 CLI；macOS 已用实际安装版、原生窗口及自有回环 SSE 完成问答和取消，详见[验收记录](../testing/records/2026-10-04-local-agent-ui.md)。该记录不证明云端账户、计费或 Windows/Linux 原生窗口。

当前为单次 Ask：每次创建独立空工作目录和 CLI 配置，不复用订阅/OAuth 登录、现有项目、用户 hooks、插件或 MCP 配置；没有 CLI 工具执行入口。显式 API 密钥、模型和服务地址必须自行配置。本地密钥环境引用已通过新非作者审查、主线整合及精确提交的三平台源码 CI，新桌面入口验收仍开放；只向适配器固定认证槽提供显式读取的值，变量名不进入 stdin/argv，任意其他环境项不转交。导入值按命名配置、引用、地址、协议和 CLI 类型/路径绑定，准备请求冻结值；已观察值继续参与所有配置的秘密保护，删除配置才释放。应用从桌面启动时不保证拥有 shell 的环境。详情见[ADR0058](../adr/0058-local-agent-key-environment-references.md)。任意环境转交、自定义工作目录、Agent 工具编排和订阅登录仍在[计划](DESIGN_AND_AGENT_PLAN.md)中。

初版环境引用候选的独立评审发现手动能力检查绕过秘密元数据准入，v2 已补齐调度前检查；作者反例及合法双 CLI 自有原生夹具验证通过，完整门禁与新非作者复核状态见[修复记录](../testing/records/2026-10-06-local-agent-probe-admission.md)。这些证据不关闭真实 CLI 新入口、桌面或其他平台原生范围。

KeelShell **向外部智能体提供 MCP 服务**是独立功能。本地 Ask 不连接其他 MCP 服务，也不通过模型输出自行扩大远程操作权限。
