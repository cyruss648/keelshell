# 本地智能体问答

KeelShell 的 AI 配置提供模型 API、Codex CLI 和 Claude Code 三种调用方式。本地 CLI 由后台启动，用于解释你明确提供的远程上下文和生成待审核建议；它仍会向配置的推理服务发送请求。

## 配置与使用

1. 打开 **AI 助手 → 配置**，新建或选择命名配置，选择 **Codex CLI** 或 **Claude Code**。
2. 填入已经安装的原生可执行文件绝对路径、推理服务基础地址、显式 API 密钥与模型 ID。Codex 使用 Responses 基础地址，Claude 使用 Anthropic Messages 基础地址；CLI 配置的地址不需要追加完整请求路径。只接受 HTTPS 或本机回环 HTTP。
3. 点击 **检查 CLI** 核对版本和能力，再点击 **应用**。检查只运行版本/能力探针，不请求模型；它也不表示密钥或模型服务已通过验证。
4. 在助手中选择配置，主动选择远程终端上下文并填写问题。点击 **预览请求**，检查执行文件、服务地址、模型、隔离策略和完整 stdin，滚动至 **确认发送此请求** 后发送。
5. 答复中的命令只能送入命令审阅区。确认精确命令和 SSH 目标后，再单独执行。**取消请求** 会停止本地请求，但已经发出的内容可能已被服务处理。

密钥默认仅在当前应用进程内存中存在；重启后需要重新输入或显式解锁。可使用已有主密码加密凭据库保存密钥，配置文件仅存引用。改变调用方式、可执行路径、地址或认证会清除原绑定；改变问题、上下文或配置会撤销旧审核并取消在途请求。

## 当前支持边界

已核对 Codex CLI `0.160.0` 和 Claude Code `2.1.285`，其他版本在重新核对之前会拒绝运行。Windows `.cmd` / `.bat` 启动器不支持，应选择原生可执行文件。普通测试无需安装供应商 CLI；macOS 已用实际安装版、原生窗口及自有回环 SSE 完成问答和取消，详见[验收记录](../testing/records/2026-10-04-local-agent-ui.md)。该记录不证明云端账户、计费或 Windows/Linux 原生窗口。

当前为单次 Ask：每次创建独立空工作目录和 CLI 配置，不复用订阅/OAuth 登录、现有项目、用户 hooks、插件或 MCP 配置；没有 CLI 工具执行入口。显式 API 密钥、模型和服务地址必须自行配置。自定义环境引用、工作目录、预算编辑、Agent 工具编排和订阅登录仍在[计划](DESIGN_AND_AGENT_PLAN.md)中。

KeelShell **向外部智能体提供 MCP 服务**是独立功能。本地 Ask 不连接其他 MCP 服务，也不通过模型输出自行扩大远程操作权限。
