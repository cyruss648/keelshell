# 本地智能体工作目录

在 AI 设置中选择 Claude Code 或 Codex CLI 后，可以选择问答运行目录。旧配置和新配置默认使用“新建空隔离目录”；需要其它目录时，选择“使用我选择的目录”，填写完整绝对路径或点击“选择目录…”，再点击“检查目录”。检查在后台进行，不启动 CLI 或模型请求。

检查通过后，应用显示所选完整路径与规范路径。点击预览发送时还会重新检查，审核中同时展示路径、运行方、问题和明确选择的 SSH 片段；批准后才开始本次问答。修改草稿、切换配置或取消会使旧检查结果失效。无效路径继续保留在草稿中，便于修正。

选择目录不会转交已有登录、环境变量或工具权限，不会自动发送项目文件、说明、技能，也不会自动启动项目 hooks/MCP。CLI 生成的目录元数据可能到达配置的推理服务；发送前应检查完整路径与上下文。命令建议仍需回到 KeelShell 的命令审核区，AI 答案不能批准或执行操作。

应用逐次检查已核对的 CLI 版本与有效能力。符号链接目录、元数据变化、未知版本、无效项目配置或不兼容的 native 文件会给出明确拒绝；不会为了兼容而扩大工具权限。目录改变时必须重新校验和审阅。执行结束、取消或错误均清理本次私有临时数据。

此功能不提供本地终端管理。外部智能体调用 KeelShell 的 MCP 服务是另一个方向，见[对外 MCP](EXTERNAL_MCP.md)。完整兼容及原生验收状态见[测试记录](../testing/records/2026-10-07-local-agent-working-directory.md)与[ADR 0069](../adr/0069-reviewed-local-agent-working-directories.md)。
