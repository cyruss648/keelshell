# MCP 提案记录与未知结果

命令和文件修改仍由桌面用户逐项审核。客户端只能提交和查询提案，不能批准、
核对未知结果或自行执行。结果未知可能表示远端已经产生影响，不能自动重试。

“清除已处理记录”只清理拒绝、到期、取消、成功和失败记录。待审核、运行中和
结果未知的记录均保留；没有可清理记录时该按钮禁用。

遇到结果未知：

1. 通过独立 SSH 或文件检查核对远端实际状态。
2. 在该提案中点击“核对未知结果”，核对原目标、连接/会话/路线 ID、动作 ID、
   digest，以及完整命令或文件路径、前后 hash 和 diff。
3. 尚未核对时选择“保留关闭限制”或按 Escape；未知记录及关闭限制保持。
4. 独立核对后点击“我已独立核对远端结果”，只解除该提案的窗口关闭限制。
   界面仍显示“远端结果未知”和你已确认独立核对的说明。

确认没有远端 I/O，也不重新授权、重试、回滚或把提案改成成功；其他尚未结束的
服务、任务、文件 quarantine 和窗口关闭限制仍各自适用。原未知记录即使确认过
仍保留在本次窗口内，批量清理不能删除。所有历史仍计入 32 项上限；先清理已知
终态可释放额度。应用退出不恢复这些记录和授权。
