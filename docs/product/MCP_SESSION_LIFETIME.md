# MCP 会话生命周期

KeelShell 向外部智能体提供 MCP 服务。授予的目标绑定当前终端实体、已认证 SSH handle、路线和主机信任，以及该终端原始的生命周期；外部客户端不能改变这些绑定。

关闭已授权页签或完成重新连接会在同一个界面事件中撤销旧授权。新的连接即使使用相同地址，也需要新的明确授权，不能恢复旧提案或重放操作。仅关闭 MCP 设置面板仍不撤权；明确撤销按钮的行为保持。

远程 shell 结束或其生命周期 producer 关闭时，后台读取、文件准备、命令和审核式文件写入会直接观察这个原始状态。它们不等待界面轮询才停止后续本地准入。界面状态在下一次前台更新中同步：待审提案取消，在途变更显示结果未知，迟到成功不发布。未知表示必须独立检查远端结果；已经发出的命令可能仍在远端执行。

保留全部既有授权边界：仅八项固定工具，明确选择上下文，应用内人工审阅，64 KiB 文件与输出上限，原操作期限、原文件基线与实际完整读回复核。共享的 SSH/SFTP 连接不因关闭终端 shell 被当作已关闭，撤权不以这个假设替代。

本修复已经过完整作者门禁、新的非作者限定回归、主树组合源码审查和根完整工程检查，新 macOS 开发包已构建检查。新组合原生桌面、外部客户端和两种 owner 同时活跃的传输撤权仍需分别验收，不能由候选或编译替代。详见 [ADR 0074](../adr/0074-mcp-session-lifetime-authorization.md)、[作者测试记录](../testing/records/2026-10-07-mcp-session-retirement.md)和[主树整合记录](../testing/records/2026-10-07-reviewed-ai-mcp-main-integration.md)。
