# 远端监控能力与按项降级

## 2026-11-17 读取取消

暂停保留已完成观察并撤销旧读取；显式重新检测还清空平台身份与各项观察。
两种操作均唤醒等待远端响应及平台探针锁的旧请求，返回明确取消，
不把取消显示成空结果或缓存成工具缺失。新一代请求独立进入读取流程。
已发出命令的通道由既有 SSH owner 有界关闭；不据此宣称远端进程已终止，
通道清理失败可能导致共享连接关闭。普通命令与审核式写入的结果合同不变。
设计及精确验证见 [ADR 0161](../adr/0161-monitor-read-cancellation.md)和
[本批记录](../testing/records/2026-11-17-monitor-read-cancellation.md)。

## 2026-11-17 Windows 只读适配

独立平台／运行时探针与 Windows 资源、容量、进程及 TCP/UDP 读取已实现，
当前正在集成验证。身份未知保持未知，不由一次 shell 错误推断 Windows。
已确认 Windows 的接口负缓存等待显式重检；传输错误不按命令缺失缓存。
Windows 的 CPU 百分比、free 内存、工作集及未提供指标有各自明确语义，
不扩大 Linux 动作权限。详细使用说明和真实平台验收边界见
[Windows 监控](WINDOWS_MONITORING.md)及[本批记录](../testing/records/2026-11-17-windows-read-only-monitor.md)。
以下 macOS／Linux 分节保留其历史验收范围。

## 2026-11-17 macOS UDP 扩展

端口列表已提供当前账户可见的 TCP LISTEN 和有本地端口的 UDP 对象，
独立使用系统 lsof。UDP 显示“已绑定”或“已指定对端”，保留实际端点；
尚未绑定端口的对象正常过滤。这些标签不表示连接握手、连通或服务健康。
TCP 已连接客户端仍排除，macOS 的主动探测、进程核对和终止入口继续禁用。

实现与验收以 [ADR 0154](../adr/0154-darwin-udp-sockets.md) 及
[本批记录](../testing/records/2026-11-17-darwin-udp-sockets.md)为准；
专项、集中门禁、独立复核与真实 SSH 已通过，原生桌面与发行仍开放。
超过12项可分页查看全部缓存条目，翻页不采集；刷新后按实际条目数校正页码。
以下 TCP 与资源分节保留各自的历史实现范围。

## 2026-11-17 macOS TCP 监听端口

端口按钮新增远端 macOS 的只读 TCP LISTEN 列表，使用目标已有系统
`/usr/sbin/lsof`，不依赖资源采集所需的 Python，不提权或自动安装。
实现、集中工程门禁及真实 SSH 互操作已通过；原生桌面仍待验。
精确计数、独立复核和原失败见
[本批测试记录](../testing/records/2026-11-17-darwin-tcp-listeners.md)。

列表只描述当前账户可见的监听对象，不保证覆盖其他账户或整个主机。
空结果不表示全系统没有监听端口，TCP LISTEN 也不证明应用协议健康。
本片不列 UDP 和已连接 TCP 端点，不提供 macOS 的连接探测、进程核对或终止。
Linux 继续使用既有 `ss` TCP/UDP 读取与各自审核动作。

工具缺失、权限诊断、输出不完整或失败保留不可用原因；一个端口读取失败不清除
有效资源和进程列表。确认的负缓存仅在显式重新检测后重试。
暂停、退役任务或旧能力报告的迟到结果不得覆盖当前界面。
主题和语言切换只显示缓存，不重复执行远端采集。
设计与完整边界见 [ADR 0152](../adr/0152-darwin-tcp-listeners.md)。

## 2026-11-16 macOS 扩展

本批增加 macOS 远端只读资源及进程列表。真实 Mac SSH 六项、Linux 能力恢复
两项 opt-in、正常 GUI/MCP 构建及全部非作者范围复核通过；
最终集中工程门禁 r3 通过，713 项输入与 52 个新增默认 Rust 名已逐项核对。
真实远端监控不替代新卡片的桌面、键盘、IME 或辅助技术验收。

| 项目 | Linux | macOS |
| --- | --- | --- |
| CPU / 运行时间 / 负载 | `/proc` | Mach / 系统接口 |
| 物理内存 | 总量与内核 available 估计 | 总量与空闲页；used/available 估计未知 |
| 网络累计字节与采样速率 | `/proc/net/dev` | 系统接口实际计数 |
| 文件系统容量 | 可选 `df -Pk` | 可选 `df -Pk` |
| 进程列表 | 固定 `ps` 列 | 固定系统 `ps` 列，只读 |
| 磁盘 I/O / iowait | 独立采样，缺失时未知 | 未支持，不能显示成 0 |
| TCP 监听端口 | 显式读取 | 2026-11-17 新增账户可见只读列表 |
| UDP 端口 | 显式读取 | 2026-11-17 已提供账户可见的绑定地址／指定对端，只读 |
| TCP 探测 / 进程核对与终止 | 审核操作 | 未支持；动作入口不提供 |

macOS 资源与进程读取需要远端已有 Python 3；TCP 监听列表独立使用已有 lsof，
不依赖该解释器。不会自动安装。解释器缺失按连接负缓存，
用户显式重新检测后才重试。空闲页不是可用内存估计，界面单独标明，
内存趋势和 MCP used 字段不从空闲页推算。两平台计数器不能直接相减。
详见 [ADR 0143](../adr/0143-darwin-resource-monitoring.md)及
[本批记录](../testing/records/2026-11-16-host-monitor.md)。

## 用户行为

当前认证SSH连接中的CPU、内存、网络和磁盘信息来自真实采样。
文件系统容量、进程列表和监听端口分别依赖远端可用接口；
一个可选接口不可用时，保留其他可用信息，并说明不可用项及原因。
不能把权限不足、命令缺失、格式不支持或未知结果表示成零。

监控区域显示各项当前能力。只有证据充分时才区分命令缺失、选项不兼容、
权限受限和格式异常；无法确定时保留未知。连接/传输失败独立报告，
不从一次SSH故障推断远端工具不存在。

用户可显式重新检测。已确认不可用的可选命令不随每轮刷新重复执行；
重新检测后按实际结果恢复可用项。检测不安装软件、不提权、不改变远端配置。
旧数据保留时说明其年龄和状态，不能让旧值看起来是新的成功样本。

## 归属与资源

能力与采样都属于当前认证连接。新连接重新建立状态；
旧任务、暂停前任务及迟到回复不得覆盖新状态。
后台worker执行有界SSH操作，绘制和主题/语言切换只读取已有状态。
暂停后不自动检测或采集，显式操作的范围与反馈应在界面明确。

沿用霜白、曜石、雾紫注册表、语义token和GPUI Kit控件。
原因说明具备中英文文本，紧凑窗口中可以访问重新检测和采样控制。
CPU/内存趋势的未知值、时间轴和断段合同继续遵循[资源趋势](HOST_RESOURCE_TRENDS.md)。

## 验收

- `df`缺失、不兼容、失败时，可读的核心资源仍成功返回。
- `ps`、`ss`的能力分别处理，未知原因不误归类，缓存避免重复无效命令。
- 显式重新检测可以发现修复后的接口；重连、暂停ABA及迟到完成被隔离。
- 暂停、绘制和主题/语言切换期间无新增自动采集。
- 实际命令、模型测试、受控SSH、完整工程门禁和开发包原生观察分别留证。
