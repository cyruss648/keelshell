# 原生工作区

工作区按全局操作、连接导航、当前会话和工具区组织。霜白、曜石、雾紫共享同一布局；
主题家族、明暗模式与布局状态分别管理，增加主题不需要改业务视图。

## 连接和主机信息

连接后，左侧默认显示保存的 SSH 连接，按文件夹层级排列。搜索匹配连接的现有字段；
父文件夹保留，便于辨认结果。点击文件夹可折叠或展开；搜索临时展开匹配路径，
改变搜索重新展开，清空后恢复原浏览折叠状态。折叠偏好目前只保留在本次进程内。
“新建连接”打开连接编辑器；“管理连接”提供完整的收藏、回收站、导入导出等操作。
导航搜索与管理器复用查询文本，但管理器的收藏、回收站和文件夹过滤不会隐藏侧栏连接。

已有会话必须仍然存活且与当前保存的目标、跳板和信任绑定一致，才会显示为已连接并切换过去。
修改连接目的地不会改变已经打开的 SSH 会话；点击修改后的连接会进入正常认证和主机密钥审核。
被删除的旧连接行不能连接同名替代项。

搜索框按向下键进入连接树，Tab/Shift-Tab 可进入或离开。树内支持：

| 按键 | 操作 |
| --- | --- |
| 上 / 下 | 移动到上一个 / 下一个可见条目 |
| 左 | 折叠当前文件夹；已折叠或叶条目回到父级 |
| 右 | 展开当前文件夹；已展开则进入第一子项 |
| Home / End | 选择并显露首项 / 末项 |
| Enter / Space | 松键后展开文件夹，或连接 / 切换所选会话 |

移动选择不会发起连接或发送命令。查询、删除、隐藏导航或打开弹窗后，
旧按键不能激活替代条目；从树开始长按的键不会随鼠标切换流入另一 SSH 会话。
同时按住 Enter 和 Space 会取消这次激活，需松开后重新操作。
删除或过滤当前项会选择仍可见的原父级，必要时继续回到上层祖先。
当前会话文字与键盘选择分别表达，浏览其它连接不会切走会话。

“主机信息”显示当前会话的既有监控与诊断面板。页面切换保留这些实体和原始会话身份，
不会凭保存的连接生成在线状态，也不会自动执行命令或发送 AI 上下文。

## 会话和工具

会话标签位于终端上方的独立栏，支持水平滚动、前后切换、新建和关闭。
窗口尺寸或侧栏变化后，活动标签的关闭入口重新显露；正常渲染不打断用户的手动滚动。
全局设置和主题按钮保留在最上方。

终端下方保留多行命令草稿、准确的审核目标、执行按钮和独立补全目录。
紧凑补全只调整布局，不把补全目录当作远程 shell 的当前目录，也不因切换面板自动查询。
文件、命令和隧道入口标明当前选择；隐藏后重新显示使用原来的面板和草稿。

顶部侧栏按钮可收起连接区。窗口宽度不足 1280 时，显示 AI 助手会让出左侧空间；
此时主动打开连接区会收起 AI，保留 AI 实体和草稿。侧栏被窗口调整隐藏时，
其中的输入焦点回到工作区背景，避免继续编辑不可见搜索框或把后续按键送入终端。
侧栏显示偏好和选中的导航页目前只属于本次应用进程。
