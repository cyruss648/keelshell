# KeelShell

更新：2026-10-03。目标是跨平台的原生 **远程 SSH 管理工具**。使用 GPUI Kit；本地终端管理、RDP 和串口不属于当前产品范围。

## 用户确定的方向

- 覆盖远程 SSH 的日常与进阶使用场景：连接组织、认证、会话、文件传输与编辑、监控、隧道和诊断；不能以已有基础连接能力宣称目标已完整实现。
- 主界面采用紧凑、高信息密度的远程运维工作区，操作路径清晰，视觉现代。AI 设置与对话行为参考 DBX。应用图标采用白色底板、蓝青几何 K 和外部透明。
- 简体中文为首次启动及旧配置迁移的默认语言，支持英文并保留扩展其他语言的结构。界面切换不重新建立连接或丢失输入。
- 用户已于 2026-10-03 授权创建公开 GitHub 仓库、推送，以及通过版本标签构建各平台产物并发布；实际验收与未完成范围必须随版本记录。

## 工作区布局

浅灰工具栏和白色文件表格，深色远程终端；紧凑控件、细边框、单行会话标签。顶部提供连接管理器、会话标签、新会话、分屏和 AI 入口。空状态显示可搜索的 SSH 连接列表；不会启动任何本地 shell。

左侧约 260 px 是当前远程主机的系统、CPU、内存、Swap、进程、网络和磁盘监控；中央是远程终端。命令输入栏紧贴终端下缘，展示实际执行目标；成功加入发送队列的命令可进入当前会话的短期历史，便于重新填入并再次审阅；命令栏有本次记录开关，变量片段展开后默认不记录。底部默认远程文件区，包含路径栏、目录导航、密集属性表格；命令与隧道作为同一工具区标签。AI 侧栏按需打开；窗口小于 1280 px 时，打开 AI 会收起左侧监控栏以保留终端空间。无会话时使用完整连接列表。

连接管理器采用目录/分组树、搜索和连接表格，创建 SSH 表单按名称、主机与端口、分组、认证组织。只有完成后端接通的操作才能展示为可用。

## 参数片段与批量命令

片段变量模式需要明确开启，旧正文不会自动转成模板。使用 `{{name}}` 后填写本次值，区分尚未填写与明确空值，先看完整只读预览，再填入命令栏；输入和预览本身不执行、不联网，也不保存本次值。目标、来源或原命令变化时拒绝旧审核并保留填写值。

批量任务显式选择当前已认证的 SSH 会话，先编辑共同命令、并发、超时和失败策略，再审核所有目标后确认。执行使用各自的 SSH exec 通道，不复用交互终端的目录或临时环境。逐目标展示退出码、输出和未知结果；隐藏面板后可以继续查看同一批次，取消不意味着远端进程已停止。结果不自动进入终端历史或持久化审计库。具体范围见 [ADR 0016](../adr/0016-parameterized-snippets-and-batch-exec.md)。

## AI 方向

独立管理多套命名服务配置，支持默认项、供应商预设、协议、认证引用、端点、模型、代理、Token 限额和连接测试；聊天栏只保留配置/模型选择、绑定目标、上下文和问题。

- 解释终端选区与报错，区分输入证据、推断和待验证项。
- 自然语言生成命令，绑定目标后放入可编辑命令栏，由用户执行。
- 分析明确选定的主机指标、进程和日志，逐步诊断。
- 辅助修改远程配置文件，展示差异、验证和回退建议后写回。
- 将已验证操作整理成命令片段和运行手册。

命令历史只保存在当前进程、按 SSH 会话隔离，并限制为最近 200 条；连续重复项会合并。清空历史不会影响连接配置、远端 shell 或命令片段。

Ask 只提出建议；未来的诊断 Agent 使用窄化工具和明确的每次执行边界。SSH 的“读取”可能包含命令替换、网络访问或脚本副作用，不能照搬数据库只读 SQL 分类。远端输出始终当作数据，不能提升为系统指令。发送前由用户选择和预览上下文；不后台采集或自动调用模型。
