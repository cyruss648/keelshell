# 传输队列入口与结果汇总

Files 面板保留一个固定的传输入口，不需要先滚动文件操作工具。摘要显示当前 SSH 会话的活动、完成、失败、取消和未知数量。准备、排队、暂停、继续和取消中的任务仍计入活动；未知结果不能计入完成、失败或已取消。

- 默认按钮为“传输队列 / Transfer queue”。打开后显示同一个面板中已存在的队列结果，结果行优先于并发设置和隔离说明。原暂停、取消、并发和只读隔离检查控制保持。
- “返回文件 / Back to files”只切换视图，保留本地和远端目录、已选路径、输入草稿、所选任务和正在运行的队列；没有重复读取、重试或写入。详情中保留本面板的历史任务，固定数量仅统计当前会话。
- 紧凑摘要使用固定高度；窄宽度时数量区可以水平滚动，入口本身保持可见。其颜色使用应用已有语义调色板，并同时使用文字区分结果。
- 待审核正文和确认、取消、展开动作继续固定在队列视图外。展开审核优先于队列详情；切换队列不能创建审批或替代审批。按钮绑定绘制时的原 SSH 会话标识，过期绘制入口不能改变新会话的视图。

本功能不改变传输实现、结果判定、隔离、SSH 生命周期或对外 MCP 权限。数量和界面可达性需要工程回归与同源原生复核各自通过，不能由传输字节相等替代。
