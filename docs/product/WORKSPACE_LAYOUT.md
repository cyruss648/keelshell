## 已定义的布局能力

同一窗口的面板可以按左右或上下组合，每个叶面板有独立的有序标签和当前标签。
每窗最多 32 个叶面板，根深度为 0、最大节点深度为 8；单个分割比例为 10%–90%。
最多保存 8 个窗口、每面板 32 个标签，总计 128 个标签。
这些是数据上限，不代表最小窗口中能同时舒适展示同样数量的面板。

标签与窗口使用稳定身份；重排不依赖下标。分割保留原面板身份，
关闭面板保留兄弟子树和其中的标签关系；模型拒绝关闭最后一个叶面板。
领域模型只管理几何；调用方须同步更新该叶的标签集合，再保存完整工作区。
无效的组合不会覆盖已有配置。

## 保存与恢复边界

保存数据仅包含布局、选择与已保存连接的 UUID。一次性连接不保存目标地址，
未保存的标签恢复为无连接占位；被删除或移入回收站的连接显示为缺失。
配置中可以保留多个引用同一连接的标签，不能因此恢复旧会话。

读取布局不会连接服务器、执行命令、恢复传输或启动隧道。模型没有保存凭据、
命令草稿、终端输出、运行实例或审核授权的字段。用户明确发起连接时，
仍需按当前连接配置经过正常认证与主机密钥验证。

缺少布局字段的旧配置保持兼容；读取不重写配置内容，既有锁文件机制保持。坏布局或未知版本拒绝加载，
不以默认值覆盖原件。布局使用同一份配置文件的并发保存与显式备份恢复机制，
连接导出/导入不会传播或替换本机布局。

## 当前原生候选的交互

- 左右/上下分屏在同一认证 SSH 连接上打开独立 Shell 通道，原面板保持活动。
  已展开的工具区和收起选择保持；新连接仍默认打开文件区。
- 每叶标签独立选择，上方会话栏仍覆盖全部会话；隐藏叶的 SSH 不随聚焦关闭。
- 拖动分隔条，或按 Tab 聚焦后使用对应轴的方向键，每次调整目标比例 5%；
  叶内大小按钮可快捷调整直接父分隔条。各层分隔条独立提供比例和辅助操作语义。
  空间不足时只显示活动叶，放大窗口恢复布局；隐藏控件的焦点回到惰性工作区。
- 合并保留所有会话，容量不足时保留原布局并提示；关闭最后标签留下空工作区。
- 重连保持原面板位置与稳定标签 ID，新运行实体不继承原审核授权。
- “保存布局”显式写入本机元数据。保存本身不连接或重放操作。

## 单窗启动恢复候选

应用启动从已加载的 state 选择保存的活动窗口，在真实原生面板树中恢复其分割轴、
比例、叶 UUID、逐叶标签 UUID/顺序/选择和连接引用。多个空叶和空活动叶保持；
没有保存布局时沿用原来的空工作区。未选保存窗口的元数据继续保留，再次保存只更新
当前窗口的记录。本轮不会创建其他 OS 窗口；版本一布局没有 OS 外框尺寸、坐标或显示器字段，
这些不存在的字段也不在本轮恢复声明中。

每个恢复标签显示以下一种状态，文字和 AX 随中英文更新，三主题共用语义 token：

- **可用，未连接**：显示当前保存连接名，提供显式连接、管理连接和关闭标签。
- **未保存连接占位**：没有原地址或凭据，提供管理连接和关闭标签。
- **连接缺失或在回收站**：保留原 UUID 引用，提供管理连接检查和关闭标签；
  原 profile 从回收站恢复后可再次变为可用。

启动仅恢复视图，不启动 SSH/AI/隧道/任务，不恢复凭据、草稿、输出、旧会话或审核授权。
连接按钮每次按当前 profile 重新解析路线，走正常认证和逐跳主机密钥核实。
即使已有相同 profile 的实时会话，也只替换用户选择的原占位标签；保留其稳定布局身份。
认证中连接变化、删除/回收、取消或原标签失效时拒绝迟到结果。已有实时会话、
工具选择和审核目标保持各自实体身份；新传输不继承旧授权，命令仍需重新审核。

占位选择、空叶和紧凑显示沿用工作区焦点隔离，布局保存仍是显式动作。
本轮有界专项包含真实生产启动绘制与隔离 loopback 路线，合计 61 个不同测试通过；
编译和夹具的首次失败及修复证据保留。最终520输入完整门禁通过，
同输入新包另取得六对离线保存/重启原生AX/JPEG：两叶、67%、中文及缺失标签选择保持；
完整预期布局与两次保存摘要匹配，未选窗口内容和顺序保持。
两应用与监督exec退出0/reaped，原600秒TTL内清理。
这些原生结果只覆盖霜白浅色的限定中英文，不代签真实认证、完整外观或输入矩阵。
决定见 [ADR 0104](../adr/0104-single-window-startup-restore.md)，
当前证据见[启动恢复记录](../testing/records/2026-11-05-workspace-startup-restore.md)。
