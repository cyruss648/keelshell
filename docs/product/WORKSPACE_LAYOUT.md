# 工作区布局与恢复

2026-11-05 已合入领域模型与配置持久化。当前独立原生候选接入嵌套分屏、
拖动/键盘比例、逐叶标签、合并、聚焦、紧凑显示和显式保存；源码检查与原生
验收分别见[接入记录](../testing/records/2026-11-05-native-pane-layout.md)。
多窗口与重启恢复入口尚未实现。

## 已定义的布局能力

同一窗口的面板可以按左右或上下组合，每个叶面板有独立的有序标签和当前标签。
每窗最多 32 个叶面板，根深度为 0、最大节点深度为 8；单个分割比例为 10%–90%。
最多保存 8 个窗口、每面板 32 个标签，总计 128 个标签。
这些是数据上限，不代表最小窗口中能同时舒适展示同样数量的面板。

标签与窗口使用稳定身份；重排不依赖下标。分割保留原面板身份，
关闭面板保留兄弟子树和其中的标签关系；模型拒绝关闭最后一个叶面板。
领域模型只管理几何；调用方须同步更新该叶的标签集合，再保存完整工作区。
无效的组合不会覆盖已有配置。

## 保存与恢复边界

保存数据仅包含布局、选择与已保存连接的 UUID。一次性连接不保存目标地址，
未保存的标签恢复为无连接占位；被删除或移入回收站的连接显示为缺失。
配置中可以保留多个引用同一连接的标签，不能因此恢复旧会话。

读取布局不会连接服务器、执行命令、恢复传输或启动隧道。模型没有保存凭据、
命令草稿、终端输出、运行实例或审核授权的字段。未来用户明确发起连接时，
仍需按当前连接配置经过正常认证与主机密钥验证。

缺少布局字段的旧配置保持兼容；读取不重写配置内容，既有锁文件机制保持。坏布局或未知版本拒绝加载，
不以默认值覆盖原件。布局使用同一份配置文件的并发保存与显式备份恢复机制，
连接导出/导入不会传播或替换本机布局。

## 当前原生候选的交互

- 左右/上下分屏在同一认证 SSH 连接上打开独立 Shell 通道，原面板保持活动。
  已展开的工具区和收起选择保持；新连接仍默认打开文件区。
- 每叶标签独立选择，上方会话栏仍覆盖全部会话；隐藏叶的 SSH 不随聚焦关闭。
- 拖动分隔条，或按 Tab 聚焦后使用对应轴的方向键，每次调整目标比例 5%；
  叶内大小按钮可快捷调整直接父分隔条。各层分隔条独立提供比例和辅助操作语义。
  空间不足时只显示活动叶，放大窗口恢复布局；隐藏控件的焦点回到惰性工作区。
- 合并保留所有会话，容量不足时保留原布局并提示；关闭最后标签留下空工作区。
- 重连保持原面板位置与稳定标签 ID，新运行实体不继承原审核授权。
- “保存布局”显式写入本机元数据。保存本身不连接或重放操作；恢复入口仍待接入。
