# 工作区窗口切换器

工作区顶部的“工作区 N”入口用于管理当前进程中的 KeelShell 原生窗口。数字表示
当前共享配置组中的窗口数量。打开入口后，每个窗口显示进程生命周期内稳定的序号、会话数和当前主机；
没有 SSH 会话的窗口显示“快速连接”。

点击窗口条目会激活对应的原生窗口。窗口之间的 SSH 会话、终端输入、文件草稿、AI
审核、远程面板和后台 worker 继续保持独立；切换窗口只改变用户当前看到的原生窗口。
窗口不可用时，当前窗口显示失败状态，不会重建或迁移目标窗口的运行态。

窗口列表使用工作区统一的 modal 生命周期。打开后，工作区背景仍作为上下文保留，
全屏遮罩阻止底层控件接收鼠标和键盘输入，列表内容拥有 Dialog 语义和 focus trap。
按 Escape、关闭按钮或选择窗口后关闭列表；关闭后焦点回到当前工作区原来的交互面。

“新建窗口”按钮继续使用工作区既有的新窗口流程。配置写入、配置维护、关闭审核、
不确定清理、显式重新加载和最多八个运行窗口的规则保持有效；配置闸门被占用时按钮
会禁用。

组件使用当前主题的语义 Palette、组件圆角、chrome 尺寸和 GPUI Kit 控件。三套内置
主题 Frost「霜白」、Graphite「曜石」、Lavender「雾紫」共用同一窗口切换器视图，
新增主题只需注册自己的 token。中文和英文分别提供可见文案与完整无障碍标签。

GPUI 定向回归覆盖窗口摘要、真实窗口激活、稳定序号、modal 隔离、Escape、焦点恢复、
主题、语言和配置闸门。当前源码提交 `373d4157ae816a29a74aa72cf490f688e3563457`
已通过作者完整工程门禁；独立只读复核正在以该 SHA 为基线执行。
原生 macOS 多窗口、多显示器几何、Windows/Linux 桌面、IME 和 VoiceOver 仍需单独验收。
