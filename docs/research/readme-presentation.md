# README 呈现方式

核验日期：2026-10-03。参考公开仓库首页的信息组织方式，文案、截图与能力描述均以 KeelShell 自身为准。

| 参考 | 可借鉴的结构 | 本项目采用方式 |
| --- | --- | --- |
| [Ghostty](https://github.com/ghostty-org/ghostty#readme) | 产品定位后提供下载、文档、贡献入口，并单独说明路线与状态 | 顶部导航、功能概览、源码运行、路线图和贡献入口 |
| [Zed](https://github.com/zed-industries/zed#readme) | 简洁介绍，分开安装、开发与贡献信息 | 用户先了解产品和运行方式，工程细节转入专门文档 |
| [Alacritty](https://github.com/alacritty/alacritty#readme) | 明示当前成熟度，提供功能、安装和配置入口 | 保留开发预览说明和平台验证链接，不把规划写成已实现能力 |

首页使用白底图标、双语入口、CI 状态及真实隔离环境截图。功能按连接、终端、文件、监控、转发和 AI 六类工作流展示，避免在首页堆积开发过程和测试日志。尚未实现的能力、验收范围与历史失败分别放在能力清单、路线图和测试记录中。

中文与英文 README 应在同一功能提交中同步更新。新增功能先核对代码与验收记录；没有正式发布产物时保留源码运行入口，不能把流水线存在当成安装包已经发布。
