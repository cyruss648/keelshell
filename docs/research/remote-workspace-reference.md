# 远程工作区观察摘记

整理日期：2026-10-03。本文是历史匿名研究的通用观察摘记，服务于 KeelShell 自身远程 SSH 工作区设计。原始来源索引与研究原文已保留在 ignored 私有研究备份中；本文件不再提供外部产品的商标、厂商或下载入口，也不把匿名摘要表述成可独立核验的官方事实。

## 观察方式与证据限制

历史研究包含两条证据路径：主任务实际查看了本机参考应用的首页、连接管理器与 SSH 新建配置表单；补充研究读取公开网页的文字、图片链接和邻近说明。两者必须分开记录。本机截图可能含用户连接树，保留在私有工作区，不进入仓库，也未导入个人连接、凭据或服务器资料。

本机无障碍树定位与真实控件不一致，终端、代理和隧道设置子页没有可靠的成功导航证据，不能记为已观察。网页补充工具当时没有返回可供逐像素分析的原图，因此根据网页文字归纳的图片标签不能算作控件视觉验收。历史图片的资源日期也不能证明当前界面版本。

## 可转化为自主设计的观察

| 任务 | 通用观察与设计启发 | KeelShell 的实施与验证边界 |
| --- | --- | --- |
| 管理连接 | 连接管理器集中组织名称、主机、端口、分组与认证字段 | 保存、搜索、分组与导入导出分别验收；字段外观不证明持久化 |
| 操作远程会话 | 会话标签、主机监控、终端和下方工具区可减少页面切换 | 终端必须绑定实际 SSH 会话，监控显示真实状态或明确未知 |
| 浏览与编辑文件 | 路径栏、目录列表、文件属性和文本编辑器可共享工作区 | SFTP 权限、准确目标、覆盖确认、取消及原子替换独立测试 |
| 提高输入效率 | 命令历史、路径选择和命令辅助输入可减少重复输入 | 作为后续需求追踪；未接通的功能不显示为可用入口 |
| 搜索与主题 | 终端搜索、高亮、字体和编码是长期使用体验的一部分 | 仍需完整选项、中文输入法、宽字符、键鼠映射和主题对比验证 |
| 连接路由 | 端口映射、代理与中继属于不同能力，不能互相代替 | 本地/远程/动态转发分别测试；代理协议、认证字段与加速收益单独验证 |

网页历史说明曾涉及 SFTP、远端执行通道、权限、可用命令及编码一致性等环境前提。这些只作为调查线索，不能证明任何客户端内部连接结构，也不能代替本项目对真实服务器的协议兼容测试。

## 当前设计决定

KeelShell 只管理远程 SSH 连接，默认简体中文并支持英文。浅色工具栏和文件表格围绕深色终端，左侧为主机监控，底部为文件、命令和隧道工具区；连接管理器独立打开。视觉要求现代、清晰、紧凑，具体尺寸与自适应规则以[产品设计](../product/PRODUCT.md)为准。

终端设置、代理协议、自动重连、传输队列及完整文件操作继续在[能力要求](remote-ssh-requirements.md)和[路线图](../ROADMAP.md)追踪。导航失败、缺少文档或历史版本差异都不应被解释为能力不存在；同样不能在缺少数据路径时宣称已实现。
