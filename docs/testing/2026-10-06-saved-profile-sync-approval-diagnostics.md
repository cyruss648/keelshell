# Saved-profile approval diagnostics

This test-only candidate improves failure evidence for the combined saved-profile synchronization and scheduled-command probe. It does not change encryption, synchronization review, storage conflict detection, SSH authority, captured routes, or scheduling behavior.

The original Linux CI run at commit `7f50d60` failed while waiting for approved saved metadata. Its complete log identifies the 18-second predicate wait but contains no completed background result or control-admission state. The exact trigger remains unverified. A successful local controlled test does not resolve that historical Linux failure, and earlier successful CI runs cannot be substituted for this commit.

The probe now records the actual modal stages, background admission, reviewed choices, effects acknowledgement, password length without its value, UI control bounds, workspace/store snapshot observations, and controlled SSH request counts. After delivering UI completion events, it distinguishes a completed unsuccessful approval from a still-pending background operation. Its existing 18-second deadline and 45-second absolute schedule remain unchanged. Successful metadata replacement, retained authenticated connection and captured route, exact parameter command, deferred SSH execution, non-persistence checks, and appearance/localization assertions remain required.

A separate temporary controlled counterexample used a second `StateStore` to change the same saved profile after review. With the prior predicate wait, the production operation correctly rejected stale review and became idle, while the test reported only the later 18-second timeout. With the candidate, the same operation promptly reports its completed stale-review state and zero remote requests. Both deliberately failing runs and their complete source inputs are retained privately. This counterexample proves the predicate's diagnostic gap; it does not establish that concurrent metadata caused the original CI failure. The injected edit is absent from the candidate.

The complete review and terminal evidence was read back by the main integrator.
