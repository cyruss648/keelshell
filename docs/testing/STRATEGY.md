# 验证策略

- 单元：连接校验、状态转换、路径/命令构造、脱敏、上下文预算、版本迁移。
- 集成：隔离目录的持久化往返与损坏恢复；远程终端输入输出/resize/退出；loopback SSH 主机信任、认证、SFTP 和隧道；loopback AI HTTP 成功/失败/超时/恶意响应。
- UI：真实 GPUI 窗口启动、输入焦点、快捷键、中文输入、终端颜色和调整窗口、连接编辑、文件与 AI 流程。
- 平台：macOS arm64 本机验收；Windows x64/arm64、Linux x64/arm64 分别原生验证。CI 文件存在不代表任务已运行。
- 门禁：格式、Clippy、单元与集成、依赖版本策略；功能提交应包含测试记录。

外部服务和真实凭据未提供时，使用隔离 loopback fixture；不凭 mock 结果声称生产互通。所有测试有明确超时，避免挂住工作。
