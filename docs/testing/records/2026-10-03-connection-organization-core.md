新增领域集成测试使用临时数据，不连接真实 SSH 主机、不使用真实凭据：

| 验证点 | 证据 |
| --- | --- |
| 旧数据迁移 | 中文及含分隔符分组保留原名；重复解析同一旧文档得到稳定目录 ID；原连接 ID、认证路径、凭据引用、收藏和标签不变 |
| 显式空树 | 空目录数组不会重新激活旧分组；`null` 拒绝 |
| 磁盘持久化 | 旧文件通过真实 `StateStore` 读取迁移，软删除保存后重开、恢复再保存重开，目录及连接身份保持一致 |
| 目录操作 | 树预序与后代匹配；自指、子孙循环、缺失父、同级重名、过长路径与 33 层嵌套拒绝且状态不变 |
| 兼容路径 | 改名/移动目录同步活动与回收站连接的 `group`；移根清空 |
| 删除与恢复 | 有子目录、活动成员或回收站成员时不得删目录；软删除移除最近记录；恢复原身份/凭据/收藏但不伪造成功；活动 ID、DNS 或等价 IPv6 端点冲突不覆盖 |
| 最近连接 | 53 个成功事件保留最后 50 个，重复成功置顶去重，时钟回拨不影响调用顺序；未知和已删除连接拒绝 |
| 复制 | 新身份继承目录映射并清除凭据引用，不复制最近记录 |
| 导入导出 | 嵌套与空目录 roundtrip，导入分配本地新身份；重新导入幂等；零新增连接时仍导入并持久化空目录；旧格式兼容；回收站端点不会自动恢复；循环、悬空映射、路径不一致时整次失败 |
| 导出边界 | 排除回收站、最近历史、凭据引用、主机信任；保留明确的认证方式与私钥路径元数据 |

独立只读审阅发现应用层曾按 `report.added == 0` 丢弃候选状态，导致仅含空目录的导入无法保存。已通知应用层改为比较完整候选状态是否变化；本记录新增空目录专用领域回归，证明即使新增连接数为零，目录仍改变快照并可持久化。UI 修复及回归由应用层另行记录。

第二项独立审阅反馈指出应用层先改名后移动可能因中间状态拒绝合法最终树。新增 `update_folder` 原子接口及两项回归：原父目录存在目标名称时允许移至其它目录，移动到短路径时允许较长新名称；真正的最终路径超限及循环仍保持整次失败。

## 未由本记录证明

本记录只证明领域 API、序列化与本机临时文件持久化；不证明 GPUI 目录交互、真实 SSH 登录成功判定、已有保存期间的事件合并、跨平台原生行为或加密凭据清理。应用层必须仅在认证及会话建立完成后记录最近成功，并遵守 `StateStore` 的快照冲突规则。所有 Git 写操作由主任务统一完成。
