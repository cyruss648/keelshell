# 凭据维护、AI 解锁与目录传输集成验收

日期：2026-10-03。范围：凭据库维护、AI 加密密钥、递归 SFTP 上传下载及 SSH 通道取消清理。所有本机交互使用独立配置目录、合成密钥和回环测试服务。

## 实现和独立审查

- 工作区维护弹窗独占配置保存通道；保存、连接、待写入最近记录及其他草稿存在时不能打开。回收站及所有 AI 引用均计入使用中条目。异步关闭携带最终结果，避免隐藏主密码变更是否生效。
- AI 保存和解锁只更新草稿；应用才更新助手。取消设置保留原已应用配置，解除关联后应用才清除助手中的密钥。
- 目录传输沿用单 worker FIFO，扫描审核后再次检查同一连接和源快照。确认正文允许受限高度滚动，确认/取消按钮保留固定空间。
- 维护实现经独立复审关闭三项 P2：旧磁盘引用累积、缺失文件误创建竞态、等待关闭丢失操作结果。详见 [维护专项](2026-10-03-vault-maintenance.md)。
- AI 凭据与工作区接入经过独立只读复审；目录传输及 SSH 通道清理分别通过受控协议测试。完整边界见 [AI 专项](2026-10-03-ai-encrypted-credentials.md) 与 [目录专项](2026-10-03-recursive-transfer.md)。

## 证据边界

先前构建与专项通过不能替代最终整合验证。受控 SSH 服务仅回显终端输入，SFTP 仅操作临时目录；模型服务仅在本机返回固定响应。它们不证明生产服务器互通、真实模型质量、Windows/Linux 桌面交互或跨平台签名分发。远程 Quality 按提交运行，六平台 Release 的旧演练结果不能代替本轮版本构建。
