# 2026-10-03 — 远程文件面板接入传输队列

## 变更范围

远程文件面板的上传和下载现在通过 `keelshell-session::sftp::TransferQueue` 执行。面板继续使用已验证的远程目录和显式目标路径，队列只接受单个本地文件与单个远程路径，不引入目录递归或本地终端行为。

面板工作线程通过有界消息通道把队列事件转换为中英文状态：

- 开始时显示已传字节与已知总大小；
- 每个分块更新上传中/下载中的进度；
- 完成时显示传输字节数并提示刷新目录；
- 失败时保留安全的传输错误；
- 取消按钮先请求队列取消，再等待队列的完成、取消或失败终态后关闭 SFTP。

上传确认文案明确说明同名远端文件可能被替换，取消可能留下部分文件。下载继续使用不覆盖已有本地文件的策略。

## 验证

```text
cargo check -p keelshell-app
cargo test -p keelshell-app
cargo test -p keelshell-session
cargo clippy -p keelshell-session --all-targets -- -D warnings
```

本次应用测试为 58 项通过；新增测试覆盖已知/未知总大小下的中英文上传与下载进度文案。会话层队列测试覆盖真实 SFTP 分块进度、排队取消、下载内容和终态事件。

## 未验证边界

本次切片未实现并行传输、暂停/恢复、断点续传、目录递归、速率限制、传输历史持久化或跨面板共享队列。尚未在真实生产 SSH 主机上执行大文件 UI 传输验收；回环 SFTP 夹具证明的是事件顺序和取消边界，不等同于所有服务器的兼容性。
