## 真实采集与计算语义

后端通过认证后的 `SshSession::exec_limited` 执行固定只读脚本，采集 `/proc/stat`、`/proc/meminfo`、`/proc/loadavg`、`/proc/uptime`、`/proc/net/dev` 和 `df -Pk`。不安装远端代理，不根据模型回复构造脚本。非 Linux 目标返回明确的 `Unsupported`；不支持所需 `ps` 字段的环境也返回能力错误。

- 单次采集输出上限为 2 MiB，进程上限为 20,000；SSH 已有连接/命令时限约束。无退出状态、非零状态、缺失段落、溢出或非有限数值均拒绝作为有效结果。
- CPU 使用前后采样的前八项累计计数差值，避免重复计算已包含在 user/nice 中的 guest 时间；busy 排除 idle 和 iowait。
- 网络速率使用远端 uptime 差值。重启、计数回退、新接口和相同采样时间返回“不可用”，不会伪装为零。
- 内存 used 是 `MemTotal - MemAvailable`。缺少 `MemAvailable` 时不以 `MemFree` 冒充可用内存。容量统一转换为字节。
- `df` 显示文件系统容量，不宣称测量磁盘 I/O。进程 CPU 是 `ps` 报告的生命周期占比，不是面板间隔内的瞬时使用率；多核进程可超过 100%。
- UI 每五秒尝试一次读取，可暂停与手动刷新；同一面板不重叠采集。失败后保留旧值并标记未完整更新，显示采样年龄。进程每页最多绘制 100 项。

## 进程终止边界

选择进程只进行读取。第一次点击会重新读取 `/proc/PID/stat` 和固定 `ps` 行，验证 PID、用户、命令和内核启动 tick，再显示单独的确认区。确认始终显示创建面板时冻结的 `username@host:port`、PID、用户与完整命令，不取终端可被 OSC 修改的标题。

只有确认区的“Send SIGTERM”会调用一次终止操作。身份凭据不实现 Clone，绑定实际 SSH 连接，60 秒过期；PID 必须大于 1 且不超过有符号 32 位范围。远端脚本仅插入验证过的数字，再次检查启动 tick 后发送 SIGTERM。不自动使用 SIGKILL、不提权、不重试未知结果。

启动 tick 检查与 `kill` 之间仍存在很窄的 PID 重用竞争窗口；本实现没有 pidfd 辅助程序，因此不能声称从协议层彻底消除该竞争。成功仅说明信号请求返回成功，不证明进程已退出。用户需要刷新验证；超时明确视为结果未知。

所有监控任务登记在应用 worker registry。释放面板会取消尚未开始的操作，并阻止下一段读取；已经开始的 SSH exec 等待其有界结果和通道清理。已发送的 SIGTERM 不会因为视图关闭而丢弃 future 或自动重试。应用退出阶段等待这些登记任务。

## 测试覆盖及未执行边界

解析测试覆盖完整样本、容量单位、带空格挂载点、guest/iowait、网络速率、重启和计数回退、相同时间、缺失可用内存、截断/溢出/NaN、非 Linux、含空格命令、多核 CPU、非法 PID、进程名中的括号、缺失退出状态。

SSH 回环测试通过真实加密传输发送固定命令，由受控服务器返回内存中的 Linux 样本；验证采集/检查过程没有 `kill`，仅显式确认后发送数值 PID 的 SIGTERM。测试服务器**不会执行**收到的终止脚本。后续新增的回归验证错误连接、过期确认和 PID 1 均不发送任何终止命令。

Linux 本机采集验收测试默认 `ignore`，需在 `/proc` 与所有本地挂载响应正常的受控 Linux 环境显式运行；这样自动化测试不会被无响应的网络挂载永久阻塞。它尚未在本次 macOS 执行。真实远端 Linux 上的采集命令兼容性、真实信号效果、UI 与真实服务器的连续采样、Windows/Linux 原生 UI、休眠恢复和网络中断后的交互验收均未由以上回环证据证明。
