# 远程工作区参考审查 — 2026-10-04

## 证据与范围

本记录用于落实远程 SSH 工作区的视觉和交互参考审查。审查通过本机已启动的远程连接管理应用完成，截图保存在本地忽略目录 `work/ui-audit-2026-10-04/01-reference-workspace.png`，没有将其中的主机名、地址、用户名或连接树提交到仓库。该截图仅代表一次本机版本和窗口状态，不证明任何第三方功能的完整清单，也不替代 KeelShell 的原生跨平台验收。

## 观察结果

- 主窗口把顶部标签栏、中央快速连接列表和左侧主机状态栏放在同一工作区；空状态仍保留稳定的标签入口和连接入口。
- 快速连接表使用主机、路径和用户的平行列，列表区域有独立清空操作，连接管理器通过文件夹入口打开，避免把管理操作塞入终端区域。
- 左侧状态栏按“同步状态/身份、系统信息、负载、资源、网络、磁盘”的顺序组织信息；暂无远端数据时显示明确的空值，而不是伪造指标。
- 连接管理器采用独立窗口，顶部提供新建连接、新建目录、删除/恢复显示、搜索和字段筛选，底部固定窗口行为选项；搜索和筛选位于内容区上方，便于在连接规模增长后继续定位目标。
- 整体视觉是浅色、紧凑、低装饰的运维工作区；KeelShell 在此结构基础上使用更高对比度的卡片、明确的主次按钮、键盘可达标签和中英文文案，保持现代感与可读性。

## KeelShell 对照要求

后续 UI 变更必须保留以下交互约束：标签栏不承载凭据或敏感值；快速连接和已保存连接必须区分一次性会话与持久化配置；左侧监控在没有会话时折叠为空状态；连接管理器的搜索、筛选、删除/恢复和新建动作要独立于终端命令；窄窗口优先保证会话、连接目标和审核按钮可见；所有异步状态需要显示忙碌、失败和可继续操作的原因。

## 未覆盖边界

本次只读审查没有连接真实远程主机、编辑或删除用户连接，也没有把第三方窗口作为 KeelShell 的验收证据。Windows/Linux 原生窗口、字体回退、缩放、键盘导航和屏幕阅读器验证继续由跨平台验收记录追踪。
