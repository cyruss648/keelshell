## 夹具行为

- 每个原预算迭代记录适配器、取消标志、自有监听 PID/端口、单调相对时间与实际 Ask 错误。PID 来自仅由该夹具写入的临时 metadata，不代表内核出生身份。
- 自有监听进程接受连接并返回固定四字节 PID。准备阶段核对真实应答；缺失或错误应答先取消并等待同一个 Ask 收尾，再拒绝诊断，不在新增诊断路径先 panic 并遗留任务。
- 返回后立即执行原 TCP 连接判断且仅执行一次；保存该结果后，成功连接上的可选应答只用于分类。不会重连或等待套接字关闭后改写原 verdict。
- 读取最多四字节，在原操作/结果等待绝对期限内逐次检查余量，每次读取另限 100 毫秒；不会因部分输入重置总期限。额外接受循环不创建线程。所有监听、临时目录和固定回复仅为自有夹具。
- 两种适配器各增加一个真实监听但不发送 PID 的场景。应答失败触发取消，必须先得到 `Cancelled`、立即连接被拒绝及 scratch 清空；该回归不弱化原 timeout/cancel 场景。
