## 新增的同资料 ID 批准回归

原组合正例只导入无关资料。本轮新增
`sync_combination/saved_profile_review.rs`，通过真实共享密文与两个隔离 StateStore，
实际填写目录及短时密码、检查差异、接受同 ID 的新主机与名称、确认路线影响、
再次输入密码并点击批准；不替换生产 API 或直接调用后台 Apply 代替面板批准。
夹具预先将受控保存资料绑定到一个真实认证的自有 TCP-SSH 会话；这些元数据
标签用于权限比较，测试没有访问标签中的 DNS 主机。

批准后实际磁盘及工作区资料都变为新主机与名称；原 SSH `same_connection`、
捕获的名称/路线描述、资料 ID 与模板 host 仍为原值，旧保存路线的
`binding_current` 为 false，因此新重连不能复用失效资料。批准本身及原 45 秒
UTC 到期之前远端均零请求。到期后，仅原会话收到含中文、单引号、换行和
元数据的精确审核命令，第二会话零请求。参数、展开命令、输出、密码不落盘，
不写 PTY；中文/英文 × System/Light/Dark 的 900×580 模态与重开成功回执通过。
SSH 夹具记录协议 exec 并返回受控输出，不执行目标 shell 命令。
