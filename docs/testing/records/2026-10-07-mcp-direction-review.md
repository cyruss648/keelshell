## 两个入口

- **在 KeelShell 中使用 AI**：用户选择 API 或本地 Claude Code/Codex CLI 配置，明确选择上下文，审阅后发送问题。应用内 Agent 的每轮请求与远程操作分别审阅。本地 CLI 的 MCP/工具配置保持关闭，不载入任意用户 MCP 服务。
- **让外部智能体使用 KeelShell**：用户先在应用内建立 SSH 会话，在 MCP 面板选择会话、工具、终端片段和目录范围并授权，把临时启动配置交给外部智能体。外部智能体启动 `keelshell-mcp` 伴随程序，经受认证的本机 IPC 请求正在运行的桌面应用；SSH 连接、权限与批准留在 KeelShell。

## 已实现的工具范畴

八项工具分为三组：读取授权会话、明确捕获的终端片段、限定目录/UTF-8 文件及已有监控缓存；提出命令或既存 UTF-8 文件完整替换；查询这些提案的状态。读取有明确范围和大小限制；提案只进入桌面待审队列，外部智能体没有自行批准、登录 SSH、解锁凭据或直接写文件的接口。

没有授权时可发现工具，但操作默认拒绝。关闭或替换原 SSH 会话、重连、撤销/重新授权会废除旧能力；已经发出的远程操作仍可能结果未知，不承诺自动回滚。关闭 MCP 面板本身不等于撤权，需使用明确的撤销操作。
