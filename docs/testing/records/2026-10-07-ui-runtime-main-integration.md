本地文件测试隔离采用 v5：同一真实 GPUI App 的多窗口共享弱组引用，实际 panel 和传输 future 保有许可；最后的组释放后，等待队列引用结束并调用生产队列的 `close().await`，实际 scheduler Join 完成后才释放许可。失败、超时和未知资源终态保持关闭。相关字段及准入逻辑仅在测试配置中存在，不修改生产文件注册表或权限规则。

a4 的精确三平台 CI 为 macOS／Windows 成功、Linux 唯一目录同步 `MutationBusy` 失败，零写入且原字节保持；历史具体竞争 owner 未识别。旧 Ask 超时和配置同步超时不是同一已证实原因。新组合只有在提交推送后才会产生自己的 CI，当前不存在可引用的新提交结果。
