# Rust 1.100.0 工具链与 Cargo 版本声明记录 — 2026-11-14

## 结论

本记录确认当前本机项目命令已经默认使用更新后的 Rust toolchain。当前
`rustup` 的 active/default toolchain 是 `stable-aarch64-apple-darwin`，实际读回
为 Rust `1.100.0`；Cargo 也是 `1.100.0`。

项目根 `Cargo.toml` 和 5 个 workspace crate manifest 都没有 `rust-version`，
仓库也没有 `rust-toolchain.toml` 或 `.cargo/config*` 覆盖。这个状态是有意保持的：
Cargo 的 `rust-version` 表示最低支持版本，不负责选择“最新”编译器。把本机当前
版本写成 `rust-version = "1.100"` 会把一次环境升级误写成项目 MSRV 约束，因此本轮
不修改 `Cargo.toml`。

响应式工作区切片。它们不代替 Windows/Linux 原生编译，也不把本机 active toolchain
解释成 Cargo.toml 的版本选择器。

## 后续规则

如果未来需要声明机器可读的 MSRV，应根据源码使用的最低语言/API、依赖的支持范围
和 CI 验证结果确定一个最低版本，并单独记录决策；不要把每次开发机升级后的
`rustc --version` 直接写入 `rust-version`。当前仓库继续由开发环境或 CI runner
提供 Rust toolchain。
