## 实际原生路径

十组未经编辑的 2880×1866 JPEG 与完整 AX 配对，按动作顺序封存。
本轮没有拖动滚动条。

| 原图 | 动作 | 实得结果 |
| --- | --- | --- |
| 01 | 文件提案待审，主面板位于前部 | 原文件未被提案写入 |
| 02 | 正文坐标 `down` 一页 | 前部无位移 |
| 03 | 同坐标 `up` 一页 | 后部及完整审核按钮可见 |
| 04 | 同坐标 `down` 一页 | 返回前部 |

| 07 | diff 内 `down` 四页 | 返回 diff 前部，操作区固定 |
| 08 | 原生拒绝文件修改 | Rejected，待审动作数为 0 |
| 09 | 关闭 MCP 并撤销全部授权 | 临时启动复制禁用，授权全部撤销 |
| 10 | 退出应用 | 关闭审核可见，随后确认；原进程自然退出 |

因此，历史“`down` 输入未位移”的观察仍成立，但不足以推论滚轮处理缺失。
